### **題目 1-9：物件導向基本概念答案**

**1. B** - 物件是類別的實例
- **解釋**：類別是建立物件的藍圖或模板，物件是根據類別創建的具體實例
- **類比**：類別像房屋設計圖，物件像根據設計圖建造的實際房子

**2. B** - `String name = new String("John");`
- **解釋**：正確的物件建立語法是 `new 類別名稱(參數)`
- **補充**：字串也可以直接賦值：`String name = "John";`

**3. C** - 點號 (.)
- **解釋**：Java 使用點記法 (dot notation) 來呼叫物件的方法
- **範例**：`object.method()`, `string.length()`

**4. B** - 參數是方法定義中的變數，引數是呼叫時傳入的值
- **解釋**：
  - **參數 (Parameters)**：方法定義中的變數
  - **引數 (Arguments)**：實際呼叫時傳入的值
- **範例**：
  ```java
  public void print(String message) { // message 是參數
      System.out.println(message);
  }
  print("Hello"); // "Hello" 是引數
  ```

**5. B** - `Integer`
- **解釋**：包裝類別將基本資料型別包裝成物件
- **對應關係**：
  - `int` → `Integer`
  - `double` → `Double`
  - `boolean` → `Boolean`

**6. C** - 非 void 方法必須回傳對應型別的值
- **解釋**：
  - `void` 方法不回傳值
  - 非 `void` 方法必須使用 `return` 回傳指定型別的值

**7. B** - `.equals()` 方法
- **解釋**：
  - `==` 比較物件參照（記憶體位址）
  - `.equals()` 比較物件內容
- **重要性**：字串比較必須使用 `.equals()`

**8. B** - `Math.abs()`
- **解釋**：`Math.abs()` 回傳數值的絕對值
- **範例**：`Math.abs(-5)` 回傳 `5`

**9. B** - 自動將基本型別轉換為對應的包裝類別
- **解釋**：
  - **Autoboxing**：`int` → `Integer`
  - **Unboxing**：`Integer` → `int`

### **題目 19：字串處理應用 (15分)**

**完整解答：**
```java
import java.util.Scanner;

public class TextAnalyzer {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("請輸入要分析的文字：");
        String text = scanner.nextLine();
        
        // 計算各項統計
        int totalLength = text.length();
        int lengthNoSpaces = text.replace(" ", "").length();
        int upperCount = 0;
        int lowerCount = 0;
        int digitCount = 0;
        int specialCount = 0;
        
        // 逐字元分析
        for (int i = 0; i < text.length(); i++) {
            char ch = text.charAt(i);
            if (Character.isUpperCase(ch)) {
                upperCount++;
            } else if (Character.isLowerCase(ch)) {
                lowerCount++;
            } else if (Character.isDigit(ch)) {
                digitCount++;
            } else {
                specialCount++;
            }
        }
        
        // 輸出分析結果
        System.out.println("\n=== 文字分析結果 ===");
        System.out.println("總長度（含空格）：" + totalLength);
        System.out.println("長度（不含空格）：" + lengthNoSpaces);
        System.out.println("大寫字母數量：" + upperCount);
        System.out.println("小寫字母數量：" + lowerCount);
        System.out.println("數字字元數量：" + digitCount);
        System.out.println("特殊字元數量：" + specialCount);
        
        // 格式轉換
        System.out.println("\n=== 格式轉換 ===");
        System.out.println("全部大寫：" + text.toUpperCase());
        System.out.println("全部小寫：" + text.toLowerCase());
        
        // 首字母大寫處理
        String[] words = text.split(" ");
        StringBuilder titleCase = new StringBuilder();
        for (int i = 0; i < words.length; i++) {
            if (words[i].length() > 0) {
                titleCase.append(Character.toUpperCase(words[i].charAt(0)));
                if (words[i].length() > 1) {
                    titleCase.append(words[i].substring(1).toLowerCase());
                }
            }
            if (i < words.length - 1) {
                titleCase.append(" ");
            }
        }
        System.out.println("首字母大寫：" + titleCase.toString());
        
        scanner.close();
    }
}
```

- **字元分類 (4分)**：正確使用 Character 類別方法

        this.score = score;

        return name;
    }
    
    public int getAge() {
        return age;
    }

        return score;
    }
    
    // Setter 方法
    public void setStudentId(String studentId) {
        this.studentId = studentId;
    }
    
    public void setName(String name) {
        this.name = name;
    }
    
    public void setAge(int age) {
        this.age = age;
    }
    
    public void setScore(double score) {
        this.score = score;
    }
    
    // 成績等級判定方法
    public String getGradeLevel() {
        if (score >= 90) {
            return "A";
        } else if (score >= 80) {
            return "B";
        } else if (score >= 70) {
            return "C";
        } else if (score >= 60) {
            return "D";
        } else {
            return "F";
        }
    }
    
    // toString 方法
    @Override
    public String toString() {
        return String.format(
            "學號：%s\n姓名：%s\n年齡：%d\n成績：%.1f\n等級：%s",
            studentId, name, age, score, getGradeLevel()
        );
    }
}
