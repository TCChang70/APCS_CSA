### **題目 1-8：基本概念答案**

**1. C** - 「Write Once, Run Anywhere」跨平台特性
- **解釋**：Java 的主要特色是跨平台特性，通過 JVM 實現一次編譯，到處執行
- **錯誤選項分析**：
  - A) Java 可在多個作業系統執行
  - B) Java 有自動垃圾回收機制
  - D) Java 是純物件導向語言

**2. C** - `student_name`
- **解釋**：有效的 Java 識別符必須以字母、底線或 $ 開頭，不能以數字開頭或使用關鍵字
- **錯誤選項分析**：
  - A) 不能以數字開頭
  - B) `class` 是 Java 關鍵字
  - D) 不能使用連字號

**3. C** - -2,147,483,648 到 2,147,483,647
- **解釋**：`int` 是 32 位元有符號整數，範圍為 -2^31 到 2^31-1
- **記憶技巧**：約 ±21 億

**4. B** - `double price = 99.99;`
- **解釋**：正確的 double 變數宣告和初始化
- **錯誤選項分析**：
  - A) 變數名不能以數字開頭
  - C) boolean 值應該是 true/false，不是字串
  - D) char 使用單引號，不是雙引號

**5. B** - 3
- **解釋**：整數除法會截斷小數部分，15/4 = 3 (餘數被忽略)
- **重要概念**：整數除法 vs 浮點數除法

**6. B** - `x += 5;` (將 x + 5 的結果賦值給 x)
- **解釋**：`+=` 是複合賦值運算子，等同於 `x = x + 5`
- **錯誤選項分析**：
  - A) `=+` 不是有效的運算子
  - C) `++` 是遞增運算子，語法錯誤
  - D) `==` 是比較運算子

**7. A** - `int` 可以自動轉換成 `double`
- **解釋**：小範圍資料型別可以自動轉換為大範圍型別 (widening conversion)
- **轉換順序**：byte → short → int → long → float → double

**8. B** - `nextInt()`
- **解釋**：Scanner 類別使用 `nextInt()` 方法讀取整數
- **其他方法**：`nextDouble()`, `nextLine()`, `nextBoolean()`

### **題目 9-16：程式碼分析答案**

**9. C** - 1
- **解釋**：`7 % 3 = 1` (7 除以 3 的餘數是 1)
- **餘數運算**：a % b 返回 a 除以 b 的餘數

**10. C** - 16
- **詳細計算**：
  ```java
  int x = 5;     // x = 5
  x += 3;        // x = 5 + 3 = 8
  x *= 2;        // x = 8 * 2 = 16
  ```

**11. B** - 19
- **解釋**：顯式型別轉換 `(int)` 會截斷小數部分，19.99 變成 19
- **重要概念**：強制型別轉換不是四捨五入

**12. C** - 第 5 行
- **解釋**：不能直接將 double (average) 與 int (count) 相加並賦值給 int
- **修正方法**：需要明確型別轉換或改變變數型別

**13. C** - x = 11, y = 11
- **解釋**：前置遞增 `++x` 先增加再使用，所以 x 先變成 11，然後 y 得到 11
- **比較**：後置遞增 `x++` 是先使用再增加

**14. C** - 3.75
- **解釋**：`(double) a` 將 a 轉換為浮點數，所以進行浮點數除法
- **計算**：15.0 / 4 = 3.75

**15. A** - 8
- **詳細計算**：
  ```java
  int a = 8, b = 3;
  a / b = 8 / 3 = 2      // 整數除法
  a / b * b = 2 * 3 = 6  // 先除後乘
  a % b = 8 % 3 = 2      // 餘數
  c = 6 + 2 = 8
  ```

**16. B** - MAX_SIZE 是常數，不可重新賦值
- **解釋**：`final` 關鍵字宣告常數，一旦初始化就不能修改
- **命名慣例**：常數通常使用全大寫字母

### **題目 17：基本計算程式 (15分)**

**完整解答：**
```java
import java.util.Scanner;

public class GradeCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        // 讀取學生資料
        System.out.print("請輸入學生姓名：");
        String name = scanner.nextLine();
        
        System.out.print("請輸入第一次考試成績：");
        double exam1 = scanner.nextDouble();
        
        System.out.print("請輸入第二次考試成績：");
        double exam2 = scanner.nextDouble();
        
        System.out.print("請輸入第三次考試成績：");
        double exam3 = scanner.nextDouble();
        
        System.out.print("請輸入期末專案成績：");
        double project = scanner.nextDouble();
        
        // 計算最終成績 (每項佔 25%)
        double finalGrade = (exam1 + exam2 + exam3 + project) * 0.25;
        
        // 判斷及格狀態
        String result = (finalGrade >= 60) ? "及格" : "不及格";
        
        // 輸出結果
        System.out.println("\n=== 成績報告 ===");
        System.out.println("學生姓名：" + name);
        System.out.printf("最終成績：%.1f\n", finalGrade);
        System.out.println("結果：" + result);
        
        scanner.close();
    }
}
```

- **及格判斷 (3分)**：正確實作條件判斷 (≥60分)

### **題目 18：資料型別轉換與計算 (15分)**

**完整解答：**
```java
import java.util.Scanner;

public class TemperatureConverter {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.println("=== 溫度轉換程式 ===");
        System.out.print("請輸入溫度值：");
        double temp = scanner.nextDouble();
        
        System.out.print("請輸入原始單位 (C/F/K)：");
        char fromUnit = scanner.next().charAt(0);
        
        System.out.print("請輸入目標單位 (C/F/K)：");
        char toUnit = scanner.next().charAt(0);
        
        double result = 0.0;
        
        // 轉換邏輯
        if (fromUnit == 'C') {
            if (toUnit == 'F') {
                result = temp * 9.0 / 5.0 + 32;
            } else if (toUnit == 'K') {
                result = temp + 273.15;
            } else {
                result = temp; // C to C
            }
        } else if (fromUnit == 'F') {
            if (toUnit == 'C') {
                result = (temp - 32) * 5.0 / 9.0;
            } else if (toUnit == 'K') {
                result = (temp - 32) * 5.0 / 9.0 + 273.15;
            } else {
                result = temp; // F to F
            }
        } else if (fromUnit == 'K') {
            if (toUnit == 'C') {
                result = temp - 273.15;
            } else if (toUnit == 'F') {
                result = (temp - 273.15) * 9.0 / 5.0 + 32;
            } else {
                result = temp; // K to K
            }
        }
        
        System.out.printf("\n轉換結果：%.1f°%c = %.1f°%c\n", 
                         temp, fromUnit, result, toUnit);
        
        scanner.close();
    }
}
```

**評分要點：**
- **輸入處理 (3分)**：正確讀取溫度值和單位
- **轉換公式 (8分)**：所有轉換公式實作正確
- **單位判斷 (2分)**：正確的條件判斷邏輯
- **輸出格式 (2分)**：適當的輸出格式和精度

### **題目 19：綜合應用程式 (15分)**

**完整解答：**
```java
import java.util.Scanner;

public class ShoppingCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.println("=== 購物計算器 ===");
        System.out.print("請輸入商品單價：");
        double unitPrice = scanner.nextDouble();
        
        System.out.print("請輸入購買數量：");
        int quantity = scanner.nextInt();
        
        System.out.print("請輸入稅率 (%)：");
        double taxRate = scanner.nextDouble();
        
        System.out.print("請輸入付款金額：");
        double payment = scanner.nextDouble();
        
        // 計算過程
        double subtotal = unitPrice * quantity;
        double tax = subtotal * taxRate / 100.0;
        double total = subtotal + tax;
        double change = payment - total;
        
        // 輸出詳細明細
        System.out.println("\n=== 購物明細 ===");
        System.out.printf("商品單價：$%.2f\n", unitPrice);
        System.out.printf("購買數量：%d\n", quantity);
        System.out.printf("小計：$%.2f\n", subtotal);
        System.out.printf("稅率：%.1f%%\n", taxRate);
        System.out.printf("稅額：$%.2f\n", tax);
        System.out.printf("總計：$%.2f\n", total);
        System.out.printf("付款金額：$%.2f\n", payment);
        System.out.printf("找零：$%.2f\n", change);
        
        scanner.close();
    }
}
```

**評分要點：**
- **輸入處理 (3分)**：正確宣告變數並讀取所有輸入
- **小計計算 (2分)**：`unitPrice * quantity`
- **稅額計算 (3分)**：`subtotal * taxRate / 100`
- **總計與找零 (4分)**：正確計算總計和找零
- **輸出格式 (3分)**：完整的明細格式，適當的小數位數

   - 類型：邏輯錯誤 (變數名稱不一致)
   - 修正：統一使用 `age` (駝峰命名法)

3. **第18行：變數作用域錯誤**
   - 錯誤：在 if 區塊內宣告的 `category` 無法在區塊外使用
   - 類型：語法錯誤 (變數作用域)
   - 修正：在 if 語句前宣告 `category` 變數

**修正後的完整程式碼 (7分)：**
```java
import java.util.Scanner;

public class VariableDemo {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        
        System.out.print("請輸入您的年齡：");
        int age = input.nextInt();  // 修正：統一變數名稱
        
        System.out.print("請輸入您的身高（公尺）：");
        double height = input.nextDouble();
        
        System.out.print("請輸入您的體重（公斤）：");
        double weight = input.nextDouble();
        
        // 計算 BMI
        double bmi = weight / (height * height);
        
        // 年齡分類
        if (age >= 18) {
            System.out.println("您是成年人");
        } else {
            System.out.println("您是未成年人");
        }
        
        // BMI 分類 - 修正：在 if 前宣告 category
        String category;
        if (bmi < 18.5) {
            category = "體重過輕";
        } else if (bmi < 24.0) {
            category = "正常範圍";
        } else if (bmi < 30.0) {
            category = "過重";
        } else {
            category = "肥胖";
        }
        
        System.out.println("您的 BMI：" + bmi);
        System.out.println("BMI 分類：" + category);
        
        input.close();
    }
}
```
