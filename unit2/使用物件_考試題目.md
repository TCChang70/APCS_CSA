## 🎯 學習重點提醒

### **物件導向基礎：**
1. **類別與物件**：類別是藍圖，物件是實例
2. **方法呼叫**：`物件名稱.方法名稱(參數)`
3. **參數與引數**：定義時是參數，呼叫時是引數
4. **回傳值**：方法執行後回傳的結果

### **字串處理重點：**
1. **String 類別**：不可變性 (immutable)
2. **常用方法**：`length()`, `charAt()`, `substring()`, `indexOf()`
3. **字串比較**：使用 `.equals()` 而不是 `==`
4. **字串轉換**：`toUpperCase()`, `toLowerCase()`, `trim()`

### **Math 類別重點：**
1. **基本數學**：`abs()`, `max()`, `min()`, `round()`
2. **進階數學**：`pow()`, `sqrt()`, `ceil()`, `floor()`
3. **三角函數**：`sin()`, `cos()`, `tan()`, `toRadians()`
4. **對數函數**：`log()`, `log10()`

### **物件使用模式：**
1. **物件創建**：使用 `new` 關鍵字
2. **方法鏈接**：可以連續呼叫方法
3. **null 檢查**：避免 NullPointerException
4. **包裝類別**：Integer, Double, Boolean 等

### **常見陷阱：**
1. **字串索引**：從 0 開始，最大索引是 length()-1
2. **角度轉換**：三角函數需要弧度制
3. **浮點數比較**：精度問題
4. **null 物件**：呼叫方法前需檢查
