### **🔵 單元 2：使用物件 (Using Objects)**

**學習目標：**
- 理解類別與物件的關係
- 學會使用預定義的類別和方法
- 掌握字串處理與數學運算

**課程內容：**

#### **2.1 Objects: Instances of Classes**
- 物件導向程式設計概念
- 類別與物件的關係
- 實例與類別的區別
- 物件的屬性與行為

#### **2.2 Creating and Storing Objects (Instantiation)**
- 物件的建立與初始化
- `new` 關鍵字的使用
- 物件參考與記憶體管理
- 物件變數的儲存方式

#### **2.3 Overloading**
- 方法多載的概念
- 建構子多載
- 參數列表的差異識別
- 多載解析機制

#### **2.4 Calling a Void Method**
- void 方法的特性
- 方法呼叫語法
- 方法執行流程
- 副作用與狀態改變

#### **2.5 Calling a Void Method with Parameters**
- 參數傳遞機制
- 實際參數與形式參數
- 傳值呼叫概念
- 參數類型匹配

#### **2.6 Calling a Non-void Method**
- 回傳值的處理
- 方法的傳回型別
- 回傳值的使用方式
- 方法鏈結概念

#### **2.7 String Objects**
- String 類別的特性
- 字串的不可變性 (Immutability)
- 字串常數池 (String Pool)
- 字串的建立方式

#### **2.8 String Methods**
- 常用字串方法：`length()`, `charAt()`, `substring()`
- 字串比較：`equals()`, `compareTo()`
- 字串搜尋：`indexOf()`, `contains()`
- 字串轉換：`toUpperCase()`, `toLowerCase()`

#### **2.9 Wrapper Classes: Integers and Doubles**
- 包裝類別的概念與用途
- Integer 和 Double 類別
- 自動裝箱與拆箱 (Autoboxing/Unboxing)
- 包裝類別的方法應用

#### **2.10 Using the Math Class**
- Math 類別的靜態方法
- 數學運算：`pow()`, `sqrt()`, `abs()`
- 隨機數生成：`random()`
- 三角函數與對數函數

#### **2.11 Using Objects Quiz**
- 物件使用綜合測驗
- 方法呼叫技能檢核
- 字串與數學運算驗證
