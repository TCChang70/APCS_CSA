### **題目 1-8：Java 語言基礎答案**

**1. B** - .java 檔案編譯成 .class 檔案，再由 JVM 執行
- **解釋**：Java 的執行過程：原始碼(.java) → 編譯器(javac) → 位元組碼(.class) → JVM 執行
- **關鍵概念**：「Write Once, Run Anywhere」的實現原理

**2. C** - `public static void main(String[] args)`
- **解釋**：標準的 main 方法宣告格式
- **詳細分析**：
  - `public`：公開存取，JVM 可以呼叫
  - `static`：靜態方法，不需要建立物件實例
  - `void`：無回傳值
  - `String[] args`：命令列參數陣列

**3. D** - `//`、`/* */` 和 `/** */` 文件註解
- **解釋**：Java 支援三種註解類型
- **使用時機**：
  - `//`：單行註解，簡短說明
  - `/* */`：多行註解，較長的解釋
  - `/** */`：JavaDoc 文件註解，API 文件生成

**4. C** - `main`
- **解釋**：`main` 是方法名稱，不是 Java 關鍵字
- **Java 關鍵字**：`public`, `static`, `class`, `void`, `int`, `double` 等都是保留字

**5. D** - 可以使用連字號 (-)
- **解釋**：Java 識別符不能包含連字號
- **正確規則**：
  - 可用：字母、數字、底線(_)、美元符號($)、Unicode字元
  - 不可用：連字號(-)、空格、其他特殊符號

**6. C** - Java 先編譯成位元組碼，再由 JVM 解釋執行
- **解釋**：Java 是混合型語言，結合編譯和解釋的優點
- **執行流程**：javac 編譯 → 位元組碼 → JVM 解釋/JIT 編譯執行

**7. A** - `package java.util`
- **解釋**：package 宣告語法，通常放在檔案最開始
- **錯誤選項**：
  - B) import 是匯入套件，不是宣告
  - C) using 是 C# 語法
  - D) include 是 C/C++ 語法

**8. C** - package → import → class
- **解釋**：Java 檔案的標準結構順序
- **詳細結構**：
  1. package 宣告（可選）
  2. import 陳述句（可選）
  3. 類別宣告

### **題目 9-16：資料型別與變數答案**

**9. A** - `byte` 佔 1 位元組，`short` 佔 2 位元組
- **解釋**：正確的記憶體大小配置
- **完整對照表**：
  - `byte`: 1 位元組 (-128 到 127)
  - `short`: 2 位元組 (-32,768 到 32,767)
  - `int`: 4 位元組 (約 ±21 億)
  - `long`: 8 位元組 (約 ±922 兆)

**10. D** - `boolean flag = 1;`
- **解釋**：boolean 型別只能接受 true 或 false
- **正確選項分析**：
  - A) 正確的 int 宣告
  - B) float 可以自動轉換為 double
  - C) char 可以接受 ASCII 數值

**11. C** - `char` 可以儲存 Unicode 字元，範圍 0 到 65535
- **解釋**：char 是 16 位元 Unicode 字元
- **重要特性**：
  - 支援國際化字元（中文、日文等）
  - 可以進行數學運算
  - 使用單引號宣告

**12. C** - 13.5，float 型別
- **解釋**：int + float = float（較大精度型別）
- **型別提升規則**：
  - byte/short/char → int
  - int + float → float
  - float + double → double

**13. B** - `final double PI = 3.14159;`
- **解釋**：Java 使用 `final` 關鍵字宣告常數
- **錯誤選項**：
  - A) `const` 是 JavaScript/C++ 語法
  - C) `static` 只是靜態修飾符
  - D) `readonly` 是 C# 語法

**14. D** - `int dec = 0d123;` (十進位)
- **解釋**：Java 沒有 0d 前綴表示十進位
- **正確進位制表示**：
  - 十六進位：0x 或 0X (如 0xFF)
  - 八進位：0 (如 0777)
  - 二進位：0b 或 0B (如 0b1010)

**15. B** - 在方法內宣告的變數只能在該方法內使用
- **解釋**：區域變數的作用域限制在宣告的區塊內
- **作用域層級**：
  - 類別變數：整個類別
  - 方法變數：方法內
  - 區塊變數：區塊內

**16. C** - 編譯錯誤
- **解釋**：同一作用域內不能重複宣告相同名稱的變數
- **Java 規則**：內層區塊不能重新宣告外層區塊已存在的變數名稱

### **題目 17-18：運算子與表達式答案**

**17. A** - true
- **解釋**：`true && false || true` = `false || true` = `true`
- **運算順序**：&& 優先於 ||

**18. A** - "大"
- **解釋**：三元運算子 `條件 ? 值1 : 值2`，5 > 3 為 true，所以回傳 "大"

### **題目 19：資料型別轉換應用 (15分)**

**完整解答：**
```java
import java.util.Scanner;

public class NumberSystemConverter {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.println("=== 數值系統轉換器 ===");
        System.out.print("請輸入一個十進位整數 (0-255)：");
        int number = scanner.nextInt();
        
        // 輸入驗證
        if (number < 0 || number > 255) {
            System.out.println("錯誤：請輸入 0-255 範圍內的數值！");
            scanner.close();
            return;
        }
        
        System.out.println("\n=== 轉換結果 ===");
        System.out.println("十進位：" + number);
        System.out.println("二進位：" + Integer.toBinaryString(number));
        System.out.println("八進位：" + Integer.toOctalString(number));
        System.out.println("十六進位：" + Integer.toHexString(number).toUpperCase());
        
        // ASCII 字元轉換
        if (number >= 32 && number <= 126) {
            System.out.println("ASCII 字元：" + (char)number);
        } else if (number >= 0 && number <= 31) {
            System.out.println("ASCII 字元：控制字元 (不可顯示)");
        } else {
            System.out.println("ASCII 字元：擴展字元");
        }
        
        System.out.println("\n=== 資料型別分析 ===");
        
        // 型別轉換和顯示
        byte byteValue = (byte) number;
        short shortValue = (short) number;
        int intValue = number;
        long longValue = number;
        char charValue = (char) number;
        
        System.out.println("byte 值：" + byteValue + " (佔用 " + Byte.BYTES + " 位元組)");
        System.out.println("short 值：" + shortValue + " (佔用 " + Short.BYTES + " 位元組)");
        System.out.println("int 值：" + intValue + " (佔用 " + Integer.BYTES + " 位元組)");
        System.out.println("long 值：" + longValue + " (佔用 " + Long.BYTES + " 位元組)");
        System.out.println("char 值：" + charValue + " (佔用 " + Character.BYTES + " 位元組)");
        
        System.out.println("\n=== 範圍檢查 ===");
        
        // byte 範圍檢查 (-128 到 127)
        boolean inByteRange = (number >= Byte.MIN_VALUE && number <= Byte.MAX_VALUE);
        System.out.println("是否在 byte 範圍內 (" + Byte.MIN_VALUE + " 到 " + 
                          Byte.MAX_VALUE + ")：" + (inByteRange ? "是" : "否"));
        
        // 可顯示 ASCII 範圍檢查 (32 到 126)
        boolean displayable = (number >= 32 && number <= 126);
        System.out.println("是否在 char 可顯示範圍內 (32 到 126)：" + (displayable ? "是" : "否"));
        
        // 額外資訊
        System.out.println("\n=== 額外資訊 ===");
        if (number > 127) {
            System.out.println("注意：此數值轉為 byte 時會變成負數 (" + byteValue + ")");
        }
        
        // 位元表示
        System.out.println("二進位詳細分析：");
        String binaryString = String.format("%8s", Integer.toBinaryString(number)).replace(' ', '0');
        System.out.println("8位元表示：" + binaryString);
        
        scanner.close();
    }
}
```

```java
import java.util.Scanner;

public class OperatorCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.println("=== 多功能運算器 ===");
        System.out.print("請輸入第一個數值：");
        double num1 = scanner.nextDouble();
        
        System.out.print("請輸入第二個數值：");
        double num2 = scanner.nextDouble();
        
        // 算術運算
        performArithmeticOperations(num1, num2);
        
        // 比較運算
        performComparisonOperations(num1, num2);
        
        // 邏輯運算
        performLogicalOperations(num1, num2);
        
        // 位元運算 (僅限整數)
        if (isInteger(num1) && isInteger(num2)) {
            performBitwiseOperations((int)num1, (int)num2);
        } else {
            System.out.println("\n=== 位元運算 ===");
            System.out.println("位元運算僅適用於整數，跳過此部分。");
        }
        
        // 三元運算子
        performTernaryOperations(num1, num2);
        
        // 運算優先順序示例
        demonstrateOperatorPrecedence(num1, num2);
        
        scanner.close();
    }
    
    public static void performArithmeticOperations(double a, double b) {
        System.out.println("\n=== 算術運算 ===");
        System.out.println("加法：" + a + " + " + b + " = " + (a + b));
        System.out.println("減法：" + a + " - " + b + " = " + (a - b));
        System.out.println("乘法：" + a + " × " + b + " = " + (a * b));
        
        if (b != 0) {
            System.out.println("除法 (浮點)：" + a + " ÷ " + b + " = " + (a / b));
            
            // 整數除法示例
            if (isInteger(a) && isInteger(b)) {
                int intA = (int) a;
                int intB = (int) b;
                System.out.println("除法 (整數)：" + intA + " ÷ " + intB + " = " + (intA / intB));
                System.out.println("餘數：" + intA + " % " + intB + " = " + (intA % intB));
            }
        } else {
            System.out.println("除法：錯誤 - 不能除以零");
            System.out.println("餘數：錯誤 - 不能除以零");
        }
    }
    
    public static void performComparisonOperations(double a, double b) {
        System.out.println("\n=== 比較運算 ===");
        System.out.println(a + " > " + b + "：" + (a > b));
        System.out.println(a + " < " + b + "：" + (a < b));
        System.out.println(a + " >= " + b + "：" + (a >= b));
        System.out.println(a + " <= " + b + "：" + (a <= b));
        System.out.println(a + " == " + b + "：" + (a == b));
        System.out.println(a + " != " + b + "：" + (a != b));
    }
    
    public static void performLogicalOperations(double a, double b) {
        System.out.println("\n=== 邏輯運算 (非零為 true) ===");
        
        boolean boolA = (a != 0);
        boolean boolB = (b != 0);
        
        System.out.println(a + " && " + b + "：" + (boolA && boolB));
        System.out.println(a + " || " + b + "：" + (boolA || boolB));
        System.out.println("!" + a + "：" + (!boolA));
        System.out.println("!" + b + "：" + (!boolB));
        
        // 短路評估示例
        System.out.println("\n短路評估示例：");
        System.out.println("false && (任何表達式)：" + (false && (1/0 == 0))); // 不會執行 1/0
        System.out.println("true || (任何表達式)：" + (true || (1/0 == 0)));   // 不會執行 1/0
    }
    
    public static void performBitwiseOperations(int a, int b) {
        System.out.println("\n=== 位元運算 (整數部分) ===");
        
        int andResult = a & b;
        int orResult = a | b;
        int xorResult = a ^ b;
        int notA = ~a;
        int notB = ~b;
        
        System.out.println(a + " & " + b + " = " + andResult + 
                          "   (" + toBinaryString(a) + " & " + toBinaryString(b) + 
                          " = " + toBinaryString(andResult) + ")");
        
        System.out.println(a + " | " + b + " = " + orResult + 
                          "   (" + toBinaryString(a) + " | " + toBinaryString(b) + 
                          " = " + toBinaryString(orResult) + ")");
        
        System.out.println(a + " ^ " + b + " = " + xorResult + 
                          "   (" + toBinaryString(a) + " ^ " + toBinaryString(b) + 
                          " = " + toBinaryString(xorResult) + ")");
        
        System.out.println("~" + a + " = " + notA + 
                          "    (~" + toBinaryString(a) + " = " + toBinaryString(notA) + ")");
    }
    
    public static void performTernaryOperations(double a, double b) {
        System.out.println("\n=== 三元運算子 ===");
        
        double max = (a > b) ? a : b;
        double min = (a < b) ? a : b;
        
        System.out.println("最大值：" + a + " > " + b + " ? " + a + " : " + b + " = " + max);
        System.out.println("最小值：" + a + " < " + b + " ? " + a + " : " + b + " = " + min);
        
        // 複合三元運算子
        String comparison = (a > b) ? (a + " 大於 " + b) : 
                          (a < b) ? (a + " 小於 " + b) : 
                          (a + " 等於 " + b);
        System.out.println("關係判斷：" + comparison);
    }
    
    public static void demonstrateOperatorPrecedence(double a, double b) {
        System.out.println("\n=== 運算優先順序示例 ===");
        
        // 範例 1：算術運算子優先順序
        double result1 = a + b * 2 - 1;
        System.out.println("表達式：" + a + " + " + b + " * 2 - 1");
        System.out.println("結果：" + result1 + " (先乘除後加減)");
        System.out.println("計算過程：" + a + " + " + (b * 2) + " - 1 = " + 
                          (a + (b * 2)) + " - 1 = " + result1);
        
        // 範例 2：比較和邏輯運算子
        boolean result2 = a > 0 && b > 0 || a < 0;
        System.out.println("\n表達式：" + a + " > 0 && " + b + " > 0 || " + a + " < 0");
        System.out.println("結果：" + result2);
        System.out.println("優先順序：比較運算子 > && > ||");
        
        // 範例 3：使用括號改變優先順序
        double result3 = (a + b) * 2 - 1;
        System.out.println("\n使用括號：(" + a + " + " + b + ") * 2 - 1 = " + result3);
    }
    
    // 輔助方法：檢查是否為整數
    public static boolean isInteger(double value) {
        return value == (int) value;
    }
    
    // 輔助方法：轉換為二進位字串（8位元）
    public static String toBinaryString(int value) {
        return String.format("%8s", Integer.toBinaryString(value & 0xFF)).replace(' ', '0');
    }
}
```

### **題目 21：變數與常數管理系統 (14分)**

**完整解答：**
```java
import java.util.Scanner;

public class PersonalDataManager {
    // 常數定義
    public static final int ADULT_AGE = 18;
    public static final int MIN_AGE = 1;
    public static final int MAX_AGE = 120;
    
    public static final double MIN_HEIGHT = 0.5;  // 公尺
    public static final double MAX_HEIGHT = 3.0;  // 公尺
    
    public static final float MIN_WEIGHT = 1.0f;   // 公斤
    public static final float MAX_WEIGHT = 500.0f; // 公斤
    
    // BMI 分類常數
    public static final double BMI_UNDERWEIGHT = 18.5;
    public static final double BMI_NORMAL = 24.9;
    public static final double BMI_OVERWEIGHT = 29.9;
    
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.println("=== 個人資料管理系統 ===");
        System.out.println("請輸入以下資料：\n");
        
        // 讀取個人資料
        System.out.print("姓名：");
        String name = scanner.nextLine();
        
        System.out.print("年齡：");
        int age = scanner.nextInt();
        
        System.out.print("身高 (公尺)：");
        double height = scanner.nextDouble();
        
        System.out.print("體重 (公斤)：");
        float weight = scanner.nextFloat();
        
        System.out.print("性別 (M/F)：");
        char gender = scanner.next().charAt(0);
        
        System.out.print("是否已婚 (true/false)：");
        boolean isMarried = scanner.nextBoolean();
        
        // 資料驗證
        boolean[] validationResults = validateData(age, height, weight);
        boolean allValid = validationResults[0] && validationResults[1] && validationResults[2];
        
        if (!allValid) {
            System.out.println("\n❌ 資料驗證失敗，請檢查輸入的數值範圍！");
            displayValidationResults(validationResults);
            scanner.close();
            return;
        }
        
        // 計算 BMI 和分析
        double bmi = calculateBMI(height, weight);
        String healthStatus = getHealthStatus(bmi);
        String healthAdvice = getHealthAdvice(bmi);
        
        // 顯示分析結果
        displayPersonalData(name, age, height, weight, gender, isMarried);
        displayHealthAnalysis(bmi, healthStatus, healthAdvice);
        displayValidationResults(validationResults);
        displayConstants();
        
        scanner.close();
    }
    
    public static double calculateBMI(double height, float weight) {
        return weight / (height * height);
    }
    
    public static String getHealthStatus(double bmi) {
        if (bmi < BMI_UNDERWEIGHT) {
            return "過輕";
        } else if (bmi <= BMI_NORMAL) {
            return "正常範圍";
        } else if (bmi <= BMI_OVERWEIGHT) {
            return "過重";
        } else {
            return "肥胖";
        }
    }
    
    public static String getHealthAdvice(double bmi) {
        if (bmi < BMI_UNDERWEIGHT) {
            return "建議增加營養攝取，適度運動增加肌肉量";
        } else if (bmi <= BMI_NORMAL) {
            return "請維持目前的健康狀態，繼續均衡飲食和規律運動";
        } else if (bmi <= BMI_OVERWEIGHT) {
            return "建議控制飲食攝取量，增加有氧運動";
        } else {
            return "建議諮詢醫師或營養師，制定健康的減重計畫";
        }
    }
    
    public static boolean[] validateData(int age, double height, float weight) {
        boolean ageValid = (age >= MIN_AGE && age <= MAX_AGE);
        boolean heightValid = (height >= MIN_HEIGHT && height <= MAX_HEIGHT);
        boolean weightValid = (weight >= MIN_WEIGHT && weight <= MAX_WEIGHT);
        
        return new boolean[]{ageValid, heightValid, weightValid};
    }
    
    public static void displayPersonalData(String name, int age, double height, 
                                         float weight, char gender, boolean isMarried) {
        System.out.println("\n=== 資料分析結果 ===");
        System.out.println("基本資料：");
        System.out.println("- 姓名：" + name);
        
        String ageStatus = (age >= ADULT_AGE) ? "成年" : "未成年";
        System.out.println("- 年齡：" + age + " 歲 (" + ageStatus + ")");
        
        System.out.printf("- 身高：%.1f 公分\n", height * 100);
        System.out.println("- 體重：" + weight + " 公斤");
        
        String genderText = (gender == 'M' || gender == 'm') ? "男性" : "女性";
        System.out.println("- 性別：" + genderText);
        
        String marriageStatus = isMarried ? "已婚" : "未婚";
        System.out.println("- 婚姻狀況：" + marriageStatus);
    }
    
    public static void displayHealthAnalysis(double bmi, String status, String advice) {
        System.out.println("\n健康分析：");
```

**錯誤分析 (3分)：**

**F 行錯誤：** `System.out.println("F: " + blockVar);`
- **錯誤類型**：編譯錯誤 (變數作用域錯誤)
- **原因**：`blockVar` 是在區塊 `{}` 內宣告的變數，其作用域僅限於該區塊內。在區塊外無法存取此變數。
- **解決方法**：將 `blockVar` 宣告移到區塊外，或在需要的地方重新宣告。

**I 行錯誤：** `System.out.println("I: " + localVar);`
- **錯誤類型**：編譯錯誤 (變數作用域錯誤)  
- **原因**：`localVar` 是在 `main` 方法內宣告的區域變數，無法在其他方法 (`methodDemo`) 中存取。
- **解決方法**：將 `localVar` 作為參數傳遞給 `methodDemo` 方法，或將其宣告為類別變數。

### **題目 23：型別轉換除錯 (8分)**

**錯誤識別 (4分)：**

1. **情況 1：數值範圍問題**
   - **錯誤**：`byte smallNumber = 200;`
   - **問題**：200 超出 byte 範圍 (-128 到 127)
   - **修正**：使用顯式轉型或改用 int 型別

2. **情況 2：精度遺失**
   - **錯誤**：`int result1 = intValue + floatValue;`
   - **問題**：float + int 結果是 float，無法自動轉換為 int
   - **修正**：使用顯式轉型或改用 float 型別

3. **情況 4：布林轉換**
   - **錯誤**：`int boolToInt = flag;`
   - **問題**：boolean 無法直接轉換為 int
   - **修正**：使用條件判斷轉換

4. **情況 6：常數重新賦值**
   - **錯誤**：`PI = 3.14159265;`
   - **問題**：final 變數只能賦值一次
   - **修正**：移除第二次賦值

**修正後的程式碼 (4分)：**
