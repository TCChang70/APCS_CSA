### Question 1 — Switch supported types

Which of the following types can be used as a `switch` statement expression? (Choose three)

A. `double`  
B. `String`  
C. `char`  
D. `Object`  
E. `Integer`  
F. `long`

<details>
<summary>Answer</summary>
**B, C, E**

`switch` supports `int`, `char`, `byte`, `short`, `String`, `enum`, and their wrapper classes (`Integer`, `Character`, `Byte`, `Short`).  
`double`, `Object`, and `long` are NOT permitted.
</details>

### Question 2 — Switch with enum

Given:

```java
enum Color { RED, GREEN, BLUE }

public class Test {
    public static void main(String[] args) {
        Color c = Color.GREEN;
        switch (c) {
            case RED:
                System.out.print("red ");
            case GREEN:
                System.out.print("green ");
            default:
                System.out.print("default ");
            case BLUE:
                System.out.print("blue ");
        }
    }
}
```

What is the result?

A. `green`  
B. `green default blue`  
C. `green blue`  
D. `green default`  
E. Compilation fails

<details>
<summary>Answer</summary>
**B. `green default blue`**

No `break` statements — fall-through occurs. Matches `GREEN`, then falls through to `default`, then falls through to `BLUE`.
</details>

### Question 3 — Switch expression (Java 14+)

```java
public class Test {
    public static void main(String[] args) {
        int x = 2;
        String result = switch (x) {
            case 1 -> "A";
            case 2 -> "B";
            case 3 -> "C";
            default -> "D";
        };
        System.out.println(result);
    }
}
```

What is the result?

A. `A`  
B. `B`  
C. `C`  
D. `D`  
E. Compilation fails because `default` is missing a value

<details>
<summary>Answer</summary>
**B. `B`**

`x = 2` matches `case 2`, which returns `"B"`. Arrow syntax has no fall-through.
</details>

### Question 4 — Pre- and post-increment

```java
int a = 1;
int b = 2;
int c = a++ + ++b - --a + b--;
System.out.println(a + "," + b + "," + c);
```

What is the result?

A. `1,2,5`  
B. `2,2,5`  
C. `1,2,6`  
D. `2,3,5`  
E. `1,3,6`

<details>
<summary>Answer</summary>
**C. `1,2,6`**

Tracing left-to-right:
- `a++`: value=1, then a=2
- `++b`: b=3, value=3
- `--a`: a=1, value=1
- `b--`: value=3, then b=2
- `c = 1 + 3 - 1 + 3 = 6`
- Final: a=1, b=2, c=6
</details>

### Question 5 — for loop with multiple terms

```java
for (int i = 0, j = 10; i < j; i++, j--) {
    System.out.print((i + j) + " ");
}
```

What is the result?

A. `10 10 10 10 10`  
B. `10 9 8 7 6`  
C. `10 10 10 10`  
D. `0 10 0 10 0`  
E. Nothing is printed

<details>
<summary>Answer</summary>
**A. `10 10 10 10 10`**

Each iteration: i + j = 0+10 = 10, then 1+9=10, 2+8=10, 3+7=10, 4+6=10. Loop ends when i=5, j=5 (not less than).
</details>

### Question 6 — Labeled break

```java
outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i * j == 4) break outer;
        System.out.print(i + "" + j + " ");
    }
}
```

What is the result?

A. `11 12 13 21`  
B. `11 12 13`  
C. `11 12 13 21 22`  
D. `11 12 13 21 22 23 31 32 33`  
E. `11 12 21 22 31 32`

<details>
<summary>Answer</summary>
**A. `11 12 13 21`**

Tracing:
- i=1: j=1 → 1*1=1, no break → print "11 "
       j=2 → 1*2=2, no break → print "12 "
       j=3 → 1*3=3, no break → print "13 "
- i=2: j=1 → 2*1=2, no break → print "21 "
       j=2 → 2*2=4 → break outer (exit both loops)
</details>

### Question 7 — Labeled continue

```java
outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i == j) continue outer;
        System.out.print(i + "" + j + " ");
    }
}
```

What is the result?

A. `12 13 21 23 31 32`  
B. `21 31 32`  
C. `11 22 33`  
D. `12 21 23 31 32`  
E. `12 13 23 31 32`

<details>
<summary>Answer</summary>
**A. `12 13 21 23 31 32`**

When `i == j`, `continue outer` skips the rest of the inner loop and continues with the next outer iteration:
- i=1: j=1 → skip; j=2→print "12 "; j=3→print "13 "
- i=2: j=1→print "21 "; j=2→skip; j=3→print "23 "
- i=3: j=1→print "31 "; j=2→print "32 "; j=3→skip
</details>

### Question 8 — do-while loop variation

```java
int x = 0;
do {
    System.out.print(x + " ");
} while (++x < 5);
System.out.print(x);
```

What is the result?

A. `1 2 3 4 5`  
B. `0 1 2 3 4 5`  
C. `1 2 3 4 4`  
D. `0 1 2 3 4 4`  
E. `0 1 2 3 4 5 5`

<details>
<summary>Answer</summary>
**E. `0 1 2 3 4 5 5`**

Tracing:
- x=0: print "0 ", ++x → x=1, 1<5 → continue
- x=1: print "1 ", ++x → x=2, 2<5 → continue
- x=2: print "2 ", ++x → x=3, 3<5 → continue
- x=3: print "3 ", ++x → x=4, 4<5 → continue
- x=4: print "4 ", ++x → x=5, 5<5 → exit
- After loop: print x → "5"

Result: "0 1 2 3 4 5 5"
</details>

### Question 9 — Ternary operator

```java
int a = 5, b = 10;
int max = (a > b) ? a + 1 : b - 1;
System.out.println(max);
```

What is the result?

A. `5`  
B. `6`  
C. `9`  
D. `10`  
E. `11`

<details>
<summary>Answer</summary>
**C. `9`**

`a > b` is `false`, so the second expression is evaluated: `b - 1 = 10 - 1 = 9`.
</details>

### Question 10 — for-each with array

```java
int[] nums = {1, 2, 3, 4, 5};
for (int n : nums) {
    if (n % 2 == 0) continue;
    System.out.print(n + " ");
}
```

What is the result?

A. `1 3 5`  
B. `2 4`  
C. `1 2 3 4 5`  
D. `1 3 5 0`  
E. `0`

<details>
<summary>Answer</summary>
**A. `1 3 5`**

`continue` skips even numbers. Only odd numbers are printed.
</details>
