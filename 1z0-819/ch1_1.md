### Question 1 — Primitive widening and method overloading

```java
public class Test {
    public void print(byte b) { System.out.println("byte"); }
    public void print(short s) { System.out.println("short"); }
    public void print(int i) { System.out.println("int"); }
    public void print(long l) { System.out.println("long"); }

    public static void main(String[] args) {
        byte b = 5;
        new Test().print(b);
        new Test().print(5);
        new Test().print(5L);
    }
}
```

What is the output?

A. `byte` / `byte` / `long`  
B. `byte` / `int` / `long`  
C. `int` / `int` / `long`  
D. `byte` / `int` / `int`  
E. Compilation fails

<details>
<summary>Answer</summary>
**B. `byte` / `int` / `long`**

`print(b)` — exact match with `byte`.  
`print(5)` — integer literal is `int`.  
`print(5L)` — long literal matches `print(long)`.
</details>

### Question 2 — Lambda parameter rules

Which statement about lambda parameter declarations is true?

```java
Comparator<String> c1 = (var a, var b) -> a.compareTo(b);
Comparator<String> c2 = (var a, b) -> a.compareTo(b);
Comparator<String> c3 = (String a, var b) -> a.compareTo(b);
Comparator<String> c4 = (final var a, final var b) -> a.compareTo(b);
```

A. All four compile.  
B. Only c1 and c4 compile.  
C. Only c1, c2, and c4 compile.  
D. Only c1 compiles.  
E. None compile.

<details>
<summary>Answer</summary>
**B. Only c1 and c4 compile.**

`c1`: valid — `var` used consistently.  
`c2`: invalid — mixing `var` with omitted type.  
`c3`: invalid — mixing explicit type with `var`.  
`c4`: valid — `final var` used consistently.
</details>

### Question 3 — static and final field initialization

```java
public class Airplane {
    static int start = 2;
    final int end;

    public Airplane(int x) {
        end = x;
    }

    public void fly(int distance) {
        System.out.print(end - start + " ");
        System.out.print(distance);
    }

    public static void main(String... start) {
        Airplane a = new Airplane(10);
        a.fly(5);
    }
}
```

What is the result?

A. `2 5`  
B. `8 5`  
C. `10 5`  
D. `0 5`  
E. None of the above

<details>
<summary>Answer</summary>
**B. `8 5`**

`end = 10` (parameter passed directly). `start` (static) = 2. `end - start = 10 - 2 = 8`. `distance = 5`.
</details>

### Question 4 — Copying StringBuilder content

```java
StringBuilder sb = new StringBuilder("ABCDE");
sb.replace(1, 3, "XYZ");
sb.delete(2, 5);
System.out.println(sb);
```

What is the result?

A. `AXYE`  
B. `AXDE`  
C. `AYZDE`  
D. `AXYZE`  
E. `ABCDE`

<details>
<summary>Answer</summary>
**A. `AXYE`**

1. `sb = "ABCDE"`
2. `replace(1,3,"XYZ")`: replace indices 1-2 ("BC") with "XYZ" → `"AXYZDE"`, length=7
3. `delete(2,5)`: remove indices 2-4 ("YZD") → `"AXYE"`
</details>

### Question 5 — StringBuilder method chaining

```java
StringBuilder sb = new StringBuilder("ab");
sb.append("cd").insert(2, "12").delete(1, 3);
```

What is the result?

<details>
<summary>Answer</summary>

### Question 6 — StringBuilder and static/instance access

```java
public class StrBldr {
    static StringBuilder sb1 = new StringBuilder("yo ");
    StringBuilder sb2 = new StringBuilder("hi ");

    public static void main(String[] args) {
        sb1 = sb1.append(new StrBldr().foo(new StringBuilder("hey")));
        System.out.println(sb1);
    }

    StringBuilder foo(StringBuilder s) {
        System.out.print(s + " oh " + sb2);
        return new StringBuilder("ey");
    }
}
```

What is printed first?

A. `yo ey`  
B. `hey oh hi`  
C. `hey oh hi yo ey`  
D. `yo hey oh hi ey`  
E. `ey`

<details>
<summary>Answer</summary>
**B. `hey oh hi`**

Inside `foo()`, `System.out.print(s + " oh " + sb2)` executes first (before the append), printing `"hey oh hi"`. Then the append happens, resulting in the full output `"hey oh hi yo ey"`.
</details>

### Question 7 — Numeric Promotion with compound assignment

```java
byte b = 10;
b = b + 1;
```

```java
byte c = 10;
c += 1;
```

Which statement is true?

A. Both code fragments compile.  
B. Neither compiles.  
C. The first compiles, the second does not.  
D. The first does not compile, the second does.  
E. Both compile but throw an exception at runtime.

<details>
<summary>Answer</summary>
**D. The first does not compile, the second does.**

`b + 1` promotes to `int`, cannot assign to `byte` without explicit cast.  
`c += 1` uses compound assignment which includes an implicit cast back to `byte`.
</details>

### Question 8 — Binary numeric promotion

```java
public class Test {
    public void process(byte v) { System.out.println("Byte value " + v); }
    public void process(short v) { System.out.println("Short value " + v); }
    public void process(Object v) { System.out.println("Object value " + v); }

    public static void main(String[] args) {
        byte x = 12;
        short y = 13;
        new Test().process(x + y);
    }
}
```

What is the output?

A. `Object value 25`  
B. `Byte value 25`  
C. `Short value 25`  
D. Compilation fails

<details>
<summary>Answer</summary>
**A. `Object value 25`**

`byte` + `short` → binary numeric promotion to `int`. `int` autoboxes to `Integer`, which matches `process(Object v)`.
</details>

### Question 9 — Integer and String concatenation

```java
System.out.println(1 + 2 + "3");
System.out.println("1" + 2 + 3);
```

What is the result?

A. `33` / `123`  
B. `123` / `123`  
C. `12` / `15`  
D. `33` / `15`  
E. `33` / `6`

<details>
<summary>Answer</summary>
**A. `33` / `123`**

`1 + 2 + "3"` → `3 + "3"` → `"33"` (left-to-right, addition first, then concatenation).  
`"1" + 2 + 3` → `"12" + 3` → `"123"` (left-to-right, string concatenation throughout).
</details>

### Question 10 — Wrapper class immutability

```java
Integer a = 100;
Integer b = 100;
Integer c = 200;
Integer d = 200;

System.out.println(a == b);
System.out.println(c == d);
```

What is the result?

A. `true` / `true`  
B. `true` / `false`  
C. `false` / `true`  
D. `false` / `false`

<details>
<summary>Answer</summary>
**B. `true` / `false`**

Java caches `Integer` values from -128 to 127. `a` and `b` both reference the same cached object (`==` is `true`). `200` is outside the cache range, so `c` and `d` are distinct objects (`==` is `false`).
</details>

### Question 11 — String immutability

```java
String s = "Hello";
s.toUpperCase();
System.out.println(s);

StringBuilder sb = new StringBuilder("Hello");
sb.append(" World");
System.out.println(sb);
```

What is the result?

A. `HELLO` / `Hello World`  
B. `Hello` / `Hello`  
C. `Hello` / `Hello World`  
D. `HELLO` / `Hello`

<details>
<summary>Answer</summary>
**C. `Hello` / `Hello World`**

`String` is immutable — `s.toUpperCase()` returns a new `String` but does not modify `s`.  
`StringBuilder` is mutable — `sb.append(" World")` modifies `sb` in place.
</details>

### Question 12 — var with array initializer

Which of these compile? (Choose all that apply.)

```java
var a = {1, 2, 3};                    // I
var b = new int[]{1, 2, 3};           // II
var c = new int[3];                   // III
var d = new int[]{1, 2, 3}[0];        // IV
```

A. I and II  
B. II and III  
C. II, III, and IV  
D. III and IV  
E. All of them

<details>
<summary>Answer</summary>
**C. II, III, and IV**

`var` cannot infer an array type from an anonymous array initializer (I fails).  
II, III, and IV all provide explicit type information on the right-hand side.
</details>
