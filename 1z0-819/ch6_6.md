### Question 1 — Stream.iterate() with limit

```java
import java.util.stream.*;

public class Test {
    public static void main(String[] args) {
        Stream.iterate(1, n -> n + 2)
              .limit(5)
              .forEach(n -> System.out.print(n + " "));
    }
}
```

What is the result?

A. `1 2 3 4 5`  
B. `1 3 5 7 9`  
C. `2 4 6 8 10`  
D. `1 3 5 7 9 11`  
E. Compilation fails

<details>
<summary>Answer</summary>
**B. `1 3 5 7 9`**

`Stream.iterate(1, n -> n + 2)` generates odd numbers. `.limit(5)` takes the first 5.
</details>

### Question 2 — reduce with identity

```java
import java.util.stream.*;

public class Test {
    public static void main(String[] args) {
        int result = Stream.of(2, 4, 6)
                           .reduce(10, (a, b) -> a + b);
        System.out.println(result);
    }
}
```

What is the result?

A. `12`  
B. `22`  
C. `10`  
D. `2`  
E. Compilation fails

<details>
<summary>Answer</summary>
**B. `22`**

`reduce(10, (a,b) -> a + b)` starts with 10, then: 10+2=12, 12+4=16, 16+6=22.
</details>

### Question 3 — flatMap vs map

```java
import java.util.*;
import java.util.stream.*;

public class Test {
    public static void main(String[] args) {
        List<List<String>> nested = List.of(
            List.of("a", "b"),
            List.of("c", "d")
        );
        nested.stream()
              .flatMap(List::stream)
              .forEach(s -> System.out.print(s + " "));
    }
}
```

What is the result?

A. `[a, b] [c, d]`  
B. `a b c d`  
C. `a b`  
D. Compilation fails  
E. `a c`

<details>
<summary>Answer</summary>
**B. `a b c d`**

`flatMap(List::stream)` flattens the nested lists into a single stream of elements.
</details>

### Question 4 — Collectors.toMap with duplicate keys

```java
import java.util.*;
import java.util.stream.*;

public class Test {
    public static void main(String[] args) {
        var result = Stream.of("a", "bb", "ccc", "dd")
                           .collect(Collectors.toMap(
                               s -> s.length(),
                               s -> s
                           ));
        System.out.println(result);
    }
}
```

What is the result?

A. `{1=a, 2=bb, 3=ccc, 2=dd}`  
B. `{1=a, 2=bb, 3=ccc}`  
C. `{1=a, 2=dd, 3=ccc}`  
D. Compilation fails  
E. An `IllegalStateException` is thrown at runtime

<details>
<summary>Answer</summary>
**E. An `IllegalStateException` is thrown at runtime**

`"bb"` and `"dd"` both have length 2, producing duplicate keys. `Collectors.toMap()` throws `IllegalStateException` on duplicate keys unless a merge function is provided.
</details>

### Question 5 — Primitive stream range

```java
import java.util.stream.*;

public class Test {
    public static void main(String[] args) {
        int sum = IntStream.rangeClosed(1, 5)
                           .filter(n -> n % 2 == 0)
                           .sum();
        System.out.println(sum);
    }
}
```

What is the result?

A. `6`  
B. `9`  
C. `15`  
D. `4`  
E. `0`

<details>
<summary>Answer</summary>
**A. `6`**

`rangeClosed(1, 5)` → 1,2,3,4,5. Filter evens: 2,4. Sum = 6.
</details>

### Question 6 — Stream terminal operation consumption

```java
import java.util.stream.*;

public class Test {
    public static void main(String[] args) {
        Stream<String> s = Stream.of("A", "B", "C");
        s.forEach(System.out::print);
        s.forEach(System.out::print);
    }
}
```

What is the result?

A. `ABCABC`  
B. `ABC`  
C. `A`  
D. An `IllegalStateException` is thrown at runtime  
E. Compilation fails

<details>
<summary>Answer</summary>
**D. An `IllegalStateException` is thrown at runtime**

A stream can only be consumed once. The first `forEach` is a terminal operation. The second `forEach` throws `IllegalStateException` because the stream is already closed.
</details>

### Question 7 — allMatch / noneMatch / anyMatch

```java
import java.util.stream.*;

public class Test {
    public static void main(String[] args) {
        var nums = Stream.of(2, 4, 6, 8);
        boolean r1 = nums.allMatch(n -> n % 2 == 0);
        System.out.print(r1 + " ");

        var nums2 = Stream.of(2, 4, 6, 8);
        boolean r2 = nums2.noneMatch(n -> n % 2 == 0);
        System.out.println(r2);
    }
}
```

What is the result?

A. `true false`  
B. `true true`  
C. `false true`  
D. `false false`  
E. An `IllegalStateException` is thrown

<details>
<summary>Answer</summary>
**A. `true false`**

All elements are even, so `allMatch` returns `true`. Since all elements are even, `noneMatch` for the even test returns `false`.
</details>

### Question 8 — Stream pipeline short-circuit with limit

```java
import java.util.stream.*;

public class Test {
    public static void main(String[] args) {
        Stream.of("cat", "dog", "bird", "fish")
              .peek(s -> System.out.print(s + " "))
              .filter(s -> s.length() == 3)
              .limit(1)
              .forEach(s -> System.out.print("!" + s));
    }
}
```

What is the result?

A. `cat !cat`  
B. `cat dog !cat`  
C. `cat dog bird fish !cat`  
D. `!cat`  
E. `cat !cat dog !dog`

<details>
<summary>Answer</summary>
**A. `cat !cat`**

`limit(1)` short-circuits after one element passes the filter. `"cat"` passes `filter` (length 3), reaches `forEach`. No more elements are processed. `"dog"`, `"bird"`, `"fish"` are never consumed.
</details>

### Question 9 — groupingBy with mapping

```java
import java.util.*;
import java.util.stream.*;

public class Test {
    public static void main(String[] args) {
        var result = Stream.of("apple", "ant", "banana", "bee")
                           .collect(Collectors.groupingBy(
                               s -> s.charAt(0),
                               Collectors.mapping(
                                   s -> s.length(),
                                   Collectors.toList()
                               )
                           ));
        System.out.println(result);
    }
}
```

What is the result?

A. `{a=[5, 3], b=[6, 3]}`  
B. `{a=[apple, ant], b=[banana, bee]}`  
C. `{a=2, b=2}`  
D. `{a=apple/ant, b=banana/bee}`  
E. Compilation fails

<details>
<summary>Answer</summary>
**A. `{a=[5, 3], b=[6, 3]}`**

Groups by first character, then maps each string to its length, collecting results into a list.
</details>

### Question 10 — Collectors.partitioningBy

```java
import java.util.*;
import java.util.stream.*;

public class Test {
    public static void main(String[] args) {
        var result = Stream.of(1, 2, 3, 4, 5)
                           .collect(Collectors.partitioningBy(
                               n -> n > 3
                           ));
        System.out.println(result);
    }
}
```

What is the result?

A. `{false=[1, 2, 3], true=[4, 5]}`  
B. `{false=[4, 5], true=[1, 2, 3]}`  
C. `{1=[1, 2, 3], 0=[4, 5]}`  
D. `[1, 2, 3, 4, 5]`  
E. `{false=3, true=2}`

<details>
<summary>Answer</summary>
**A. `{false=[1, 2, 3], true=[4, 5]}`**

`partitioningBy` splits into two groups based on a `Predicate`. `n > 3` is `false` for 1,2,3 and `true` for 4,5.
</details>
