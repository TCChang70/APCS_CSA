### Question 1

Which of the following are considered locales? (Choose three)

A. Culture region  
B. Local address  
C. City  
D. Time zone region  
E. Political region  
F. Geographical region

<details>
<summary>Answer</summary>
**A, E, F**

A Java `Locale` represents a specific cultural/geographical/political region (language + country/region). Time zone and city address are not part of a `Locale`.
</details>

### Question 2

When localizing an application, which type of data varies in presentation depending on locale?

A. Currencies  
B. Dates  
C. Both  
D. Neither

<details>
<summary>Answer</summary>
**C. Both**

Both currencies (symbol, formatting) and dates (format, order of day/month/year) vary by locale.
</details>

### Question 3

Given the code fragment:

```java
Locale locale = Locale.US;
// Line 1
double currency = 1_00.00;
System.out.println(formatter.format(currency));
```

You want to display the value of currency as `$100.00`.

Which code inserted on line 1 will accomplish this?

A) `NumberFormat formatter = NumberFormat.getInstance(locale).getCurrency();`  
B) `NumberFormat formatter = NumberFormat.getInstance(locale);`  
C) `NumberFormat formatter = NumberFormat.getCurrency(locale);`  
D) `NumberFormat formatter = NumberFormat.getCurrencyInstance(locale);`

<details>
<summary>Answer</summary>
**D) `NumberFormat formatter = NumberFormat.getCurrencyInstance(locale);`**

`NumberFormat.getCurrencyInstance(locale)` returns a `NumberFormat` configured for currency formatting. A returns a `Currency` object (not a `NumberFormat`). B returns a general number formatter. C is not a valid method.
</details>

### Question 4

Which code fragment does a service use to load the service provider with a `Print` interface?

A) `private java.util.ServiceLoader<Print> loader = ServiceLoader.load(Print.class);`  
B) `private Print print = com.service.Provider.getInstance();`  
C) `private java.util.ServiceLoader<Print> loader = new java.util.ServiceLoader<>();`  
D) `private Print print = new com.service.PrintImpl();`

<details>
<summary>Answer</summary>
**A) `private java.util.ServiceLoader<Print> loader = ServiceLoader.load(Print.class);`**

`ServiceLoader.load(Class)` is the standard way to load service providers. `ServiceLoader` has a private constructor, so `new ServiceLoader<>()` does not compile.
</details>
