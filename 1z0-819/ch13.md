### Question 1

What keyword is used to mark an annotation element as optional?

A. `optional`  
B. `default`  
C. `required`  
D. `value`  
E. `case`  
F. None of the above

<details>
<summary>Answer</summary>
**B. `default`**

The `default` keyword in an annotation declaration specifies a default value for an element, making it optional for the annotation user.
</details>

### Question 2

Fill in the blank with the correct annotation usage that allows the code to compile without any warnings.

```java
@Deprecated(since = "5.0")
public class ProjectPlanner<T> {
    ProjectPlanner create(T t) { return this; }
}

@SuppressWarnings(________)
class SystemPlanner {
    ProjectPlanner planner = new ProjectPlanner().create("TPS");
}
```

A) `value = ignoreAll`  
B) `value = "deprecation", "unchecked"`  
C) `"unchecked", "deprecation"`  
D) `{"deprecation", "unchecked"}`  
E) `"deprecation"`  
F) None of the above

<details>
<summary>Answer</summary>
**D) `{"deprecation", "unchecked"}`**

`@SuppressWarnings` takes a `String[]`. The array initializer syntax `{"deprecation", "unchecked"}` is required to suppress multiple warnings. The raw type `ProjectPlanner` causes an "unchecked" warning and the deprecated class use causes a "deprecation" warning.
</details>

### Question 3

Given the declaration:

```java
@interface Resource {
    String[] value();
}
```

Examine this code fragment:

```java
/** Loc1 **/
class ProcessOrders { ... }
```

Which two annotations may be applied at Loc1?

A) `@Resource()`  
B) `@Resource(value={{}})`  
C) `@Resource`  
D) `@Resource({"Customer1", "Customer2"})`  
E) `@Resource("Customer1")`

<details>
<summary>Answer</summary>
**D, E**

`value()` is a required element with type `String[]`.  
D provides a two-element array. E provides a single-element shorthand.  
A provides an empty array (no actual strings). B has invalid nested array syntax. C omits the required value.
</details>
