### Question 1 — Locale category

Which `Locale.Category` enum value is used to format currency by default?

A. `Locale.Category.DISPLAY`  
B. `Locale.Category.FORMAT`  
C. `Locale.Category.CURRENCY`  
D. `Locale.Category.NUMBER`  
E. `Locale.Category.DEFAULT`

<details>
<summary>Answer</summary>
**B. `Locale.Category.FORMAT`**

`Locale.Category.FORMAT` controls locale-sensitive formatting such as numbers, dates, and currencies. `DISPLAY` controls locale display names.
</details>

### Question 2 — ResourceBundle lookup

Given the following resource bundles in the classpath:

- `Messages.properties`
- `Messages_en.properties`
- `Messages_en_US.properties`
- `Messages_fr.properties`

With `Locale.setDefault(Locale.UK)`, which bundle is loaded for `new Locale("fr", "CA")`?

A. `Messages.properties`  
B. `Messages_en.properties`  
C. `Messages_en_US.properties`  
D. `Messages_fr.properties`  
E. `Messages_fr_CA.properties`

<details>
<summary>Answer</summary>
**D. `Messages_fr.properties`**

The lookup for `fr_CA` first looks for `Messages_fr_CA`, then `Messages_fr`, then `Messages_en` (matching the default locale), and finally `Messages` (base). Since `Messages_fr` exists, it is selected.
</details>

### Question 3 — ResourceBundle with ListResourceBundle

```java
import java.util.*;

public class MyResources extends ListResourceBundle {
    protected Object[][] getContents() {
        return new Object[][] {
            {"hello", "Hello"},
            {"bye", "Goodbye"}
        };
    }
}
```

Which code correctly loads this resource bundle?

A. `ResourceBundle.getBundle("MyResources", Locale.US)`  
B. `ResourceBundle.getBundle("MyResources.class", Locale.US)`  
C. `ResourceBundle.load("MyResources")`  
D. `new MyResources()`  
E. `ResourceBundle.getBundle("my.MyResources")`

<details>
<summary>Answer</summary>
**A. `ResourceBundle.getBundle("MyResources", Locale.US)`**

`getBundle` with the fully qualified class name (or base name) locates the `ListResourceBundle` subclass. The `.class` extension is not needed.
</details>

### Question 4 — NumberFormat pattern

```java
import java.text.*;

public class Test {
    public static void main(String[] args) {
        NumberFormat nf = NumberFormat.getPercentInstance(Locale.US);
        System.out.println(nf.format(0.75));
    }
}
```

What is the output?

A. `0.75`  
B. `75%`  
C. `75 %`  
D. `0.75%`  
E. `%75`

<details>
<summary>Answer</summary>
**B. `75%`**

`NumberFormat.getPercentInstance()` multiplies the value by 100 and appends a `%` symbol in the locale-appropriate position. For `Locale.US`, the output is `75%`.
</details>

### Question 5 — Locale.Builder

```java
import java.util.*;

public class Test {
    public static void main(String[] args) {
        Locale loc = new Locale.Builder()
            .setLanguage("en")
            .setRegion("US")
            .build();
        System.out.println(loc);
    }
}
```

What is the output?

A. `en`  
B. `US`  
C. `en_US`  
D. `en-US`  
E. `English (United States)`

<details>
<summary>Answer</summary>
**C. `en_US`**

`Locale.toString()` returns the language and region separated by an underscore, e.g., `en_US`.
</details>

### Question 6 — DateFormat.SHORT

```java
import java.text.*;
import java.util.*;

public class Test {
    public static void main(String[] args) {
        Date now = new Date(124, 5, 15); // June 15, 2024
        DateFormat df = DateFormat.getDateInstance(DateFormat.SHORT, Locale.UK);
        System.out.println(df.format(now));
    }
}
```

What is the most likely output?

A. `06/15/24`  
B. `15/06/2024`  
C. `Jun 15, 2024`  
D. `15 June 2024`  
E. `2024-06-15`

<details>
<summary>Answer</summary>
**B. `15/06/2024`**

`DateFormat.SHORT` uses a short numeric pattern. For `Locale.UK`, the format is day/month/year, so `15/06/2024`.
</details>

### Question 7 — MessageFormat

```java
import java.text.*;

public class Test {
    public static void main(String[] args) {
        String pattern = "Welcome {0}, you have {1} new messages.";
        String msg = MessageFormat.format(pattern, "Alice", 5);
        System.out.println(msg);
    }
}
```

What is the output?

A. `Welcome {0}, you have {1} new messages.`  
B. `Welcome Alice, you have 5 new messages.`  
C. `Welcome 0, you have 1 new messages.`  
D. `Welcome {0} Alice, you have {1} 5 new messages.`  
E. Compilation fails

<details>
<summary>Answer</summary>
**B. `Welcome Alice, you have 5 new messages.`**

`MessageFormat.replace()` replaces `{0}` with the first argument (`"Alice"`) and `{1}` with the second (`5`).
</details>

### Question 8 — DateTimeFormatter

```java
import java.time.*;
import java.time.format.*;

public class Test {
    public static void main(String[] args) {
        LocalDate date = LocalDate.of(2024, 6, 15);
        DateTimeFormatter fmt = DateTimeFormatter.ofPattern("dd/MM/yyyy");
        System.out.println(date.format(fmt));
    }
}
```

What is the output?

A. `15/06/2024`  
B. `06/15/2024`  
C. `2024/06/15`  
D. `15-06-2024`  
E. `June 15, 2024`

<details>
<summary>Answer</summary>
**A. `15/06/2024`**

The custom pattern `dd/MM/yyyy` produces day/two-digit-month/four-digit-year.
</details>
