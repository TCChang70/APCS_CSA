### Question 1 — PECS (Producer Extends, Consumer Super)

```java
public class Test {
    public static void addNumbers(List<? super Integer> list) {
        list.add(10);
        list.add(20);
    }

    public static void main(String[] args) {
        List<Number> nums = new ArrayList<>();
        addNumbers(nums);
        System.out.println(nums);
    }
}
```

What is the result?

A. `[10, 20]`  
B. Compilation fails — `Number` is not a supertype of `Integer`  
C. Compilation fails — `? super Integer` cannot be used with `add`  
D. `[]`  
E. A `ClassCastException` is thrown at runtime

<details>
<summary>Answer</summary>
**A. `[10, 20]`**

`List<? super Integer>` accepts `Integer` or any supertype (`Number`, `Object`). `List<Number>` matches `? super Integer`. Adding `Integer` values is valid.
</details>

### Question 2 — Iterator.remove() vs Collection.remove()

```java
import java.util.*;

public class Test {
    public static void main(String[] args) {
        List<String> list = new ArrayList<>(List.of("A", "B", "C", "D"));
        Iterator<String> it = list.iterator();
        while (it.hasNext()) {
            String s = it.next();
            if (s.equals("B")) {
                it.remove();
            }
        }
        System.out.println(list);
    }
}
```

What is the result?

A. `[A, C, D]`  
B. `[A, B, C, D]`  
C. A `ConcurrentModificationException` is thrown  
D. `[A, D]`  
E. Compilation fails

<details>
<summary>Answer</summary>
**A. `[A, C, D]`**

`Iterator.remove()` is the safe way to remove elements during iteration — it does NOT throw `ConcurrentModificationException`. Element `"B"` is removed.
</details>

### Question 3 — Arrays.asList() and structural modification

```java
import java.util.*;

public class Test {
    public static void main(String[] args) {
        String[] arr = {"A", "B", "C"};
        List<String> list = Arrays.asList(arr);
        list.add("D");
        System.out.println(list);
    }
}
```

What is the result?

A. `[A, B, C, D]`  
B. `[A, B, C]`  
C. An `UnsupportedOperationException` is thrown  
D. Compilation fails  
E. `arr` is modified to include `D`

<details>
<summary>Answer</summary>
**C. An `UnsupportedOperationException` is thrown**

`Arrays.asList()` returns a fixed-size list backed by the original array. Structural modifications (`add`, `remove`) are not supported.
</details>

### Question 4 — List.of() and null elements

```java
import java.util.*;

public class Test {
    public static void main(String[] args) {
        List<String> list = List.of("A", null, "C");
        System.out.println(list);
    }
}
```

What is the result?

A. `[A, null, C]`  
B. `[A, C]`  
C. A `NullPointerException` is thrown at runtime  
D. Compilation fails  
E. `[A, , C]`

<details>
<summary>Answer</summary>
**C. A `NullPointerException` is thrown at runtime**

`List.of()` and `Set.of()` do not allow `null` elements. Passing `null` throws `NullPointerException`.
</details>

### Question 5 — HashSet and equals/hashCode contract

```java
import java.util.*;

class Item {
    String name;
    Item(String name) { this.name = name; }
    public boolean equals(Object o) {
        return ((Item) o).name.equals(this.name);
    }
}

public class Test {
    public static void main(String[] args) {
        Set<Item> set = new HashSet<>();
        set.add(new Item("A"));
        set.add(new Item("A"));
        System.out.println(set.size());
    }
}
```

What is the result?

A. `1`  
B. `2`  
C. Compilation fails  
D. A runtime exception is thrown  
E. `0`

<details>
<summary>Answer</summary>
**B. `2`**

`equals()` is overridden but `hashCode()` is NOT. Two different `Item` objects will have different default `hashCode()` values, so `HashSet` treats them as distinct entries even though `equals()` returns `true`.
</details>

### Question 6 — TreeSet with Comparator

```java
import java.util.*;

public class Test {
    public static void main(String[] args) {
        Set<String> set = new TreeSet<>((a, b) -> b.compareTo(a));
        set.addAll(List.of("B", "D", "A", "C"));
        System.out.println(set);
    }
}
```

What is the result?

A. `[A, B, C, D]`  
B. `[D, C, B, A]`  
C. `[A, C, B, D]`  
D. `[B, D, A, C]`  
E. Compilation fails

<details>
<summary>Answer</summary>
**B. `[D, C, B, A]`**

`TreeSet` uses the provided `Comparator`. `b.compareTo(a)` reverses natural order, producing descending order.
</details>

### Question 7 — List sorting with Comparator.naturalOrder()

```java
import java.util.*;

public class Test {
    public static void main(String[] args) {
        var list = new ArrayList<>(List.of("banana", "Apple", "cherry"));
        list.sort(String::compareToIgnoreCase);
        System.out.println(list);
    }
}
```

What is the result?

A. `[Apple, banana, cherry]`  
B. `[Apple, banana, cherry]` — same order as natural  
C. `[banana, Apple, cherry]`  
D. `[cherry, banana, Apple]`  
E. Compilation fails — method reference cannot be used here

<details>
<summary>Answer</summary>
**A. `[Apple, banana, cherry]`**

`String::compareToIgnoreCase` sorts case-insensitively. `"Apple"` comes before `"banana"` and `"cherry"`.
</details>

### Question 8 — List.copyOf() and immutability

```java
import java.util.*;

public class Test {
    public static void main(String[] args) {
        List<String> original = new ArrayList<>(List.of("A", "B", "C"));
        List<String> copy = List.copyOf(original);
        original.add("D");
        System.out.println(copy.size());
    }
}
```

What is the result?

A. `4`  
B. `3`  
C. An `UnsupportedOperationException` is thrown  
D. Compilation fails  
E. `2`

<details>
<summary>Answer</summary>
**B. `3`**

`List.copyOf()` creates an immutable copy of the original list. Subsequent modifications to the original list do not affect the copy.
</details>

### Question 9 — ArrayList remove by index vs by object

```java
import java.util.*;

public class Test {
    public static void main(String[] args) {
        List<Integer> list = new ArrayList<>(List.of(1, 2, 3, 2, 4));
        list.remove(2);
        System.out.println(list);
    }
}
```

What is the result?

A. `[1, 3, 2, 4]`  
B. `[1, 2, 3, 4]`  
C. `[1, 2, 2, 4]`  
D. `[1, 3, 4]`  
E. Compilation fails

<details>
<summary>Answer</summary>
**A. `[1, 3, 2, 4]`**

`list.remove(2)` removes the element at **index** 2 (the value `3`), not the object `Integer(2)`. To remove by object, use `list.remove(Integer.valueOf(2))`.
</details>

### Question 10 — Collections.binarySearch

```java
import java.util.*;

public class Test {
    public static void main(String[] args) {
        List<Integer> list = new ArrayList<>(List.of(10, 20, 30, 40, 50));
        int index = Collections.binarySearch(list, 35);
        System.out.println(index);
    }
}
```

What is the result?

A. `2`  
B. `3`  
C. `-3`  
D. `-4`  
E. `-5`

<details>
<summary>Answer</summary>
**D. `-4`**

`binarySearch` returns `(-(insertion point) - 1)` when the element is not found. Insertion point for `35` is index 3 (between 30 and 40). `-(3) - 1 = -4`.
</details>
