### Question 1

What is the most likely outcome of this code if the bunnies table is empty?

```java
var url = "jdbc:derby:bunnies";
var sql = "insert into bunny(name,color) values(?,?)";
try (var conn = DriverManager.getConnection(url);
     var stmt = conn.createStatement()) {
    stmt.setString(1, "Hoppy");
    stmt.setString(2, "Brown");

    stmt.executeUpdate(sql);
}
```

A. One row is in the table.  
B. Two rows are in the table.  
C. The code does not compile.  
D. The code throws a `SQLException`

<details>
<summary>Answer</summary>
**C. The code does not compile.**

`createStatement()` returns a `Statement`, not a `PreparedStatement`. The `setString()` method is not available on `Statement` — it belongs to `PreparedStatement`.
</details>

### Question 2

What must be the first characters of a database URL?

A. `db,`  
B. `db:`  
C. `jdbc,`  
D. `jdbc:`  
E. None of the above

<details>
<summary>Answer</summary>
**D. `jdbc:`**

All JDBC database URLs begin with `jdbc:`, followed by the database vendor-specific subprotocol (e.g., `jdbc:mysql://`, `jdbc:derby:`).
</details>

### Question 3

Assuming the user credentials are correct, which expression will create a `Connection`?

A) `DriverManager.getConnection("jdbc:derby:com");`  
B) `DriverManager.getConnection("jdbc.derby.com");`  
C) `DriverManager.getConnection("http://database.jdbc.com", "J_SMITH", "dt12%2f3");`  
D) `DriverManager.getConnection();`  
E) `DriverManager.getConnection("J_SMITH","dt12%2f3");`

<details>
<summary>Answer</summary>
**A) `DriverManager.getConnection("jdbc:derby:com");`**

JDBC URLs must start with `jdbc:`. Only option A has a valid JDBC URL format.
</details>

### Question 4

Given:

```java
String url = "jdbc:mysql://localhost:3306/classicmodels";
String sql = "select * from Coffees";
Connection cn = DriverManager.getConnection(url, user, password);
Statement st = cn.createStatement();
boolean b = st.execute(sql);
ResultSet rs = null;
if (b) {
    rs = st.getResultSet();
}
while (rs.next()) {
    String name = rs.getString("COF_NAME");
    int sid = rs.getInt("SUP_ID");
    double price = rs.getDouble("Price");
    int sales = rs.getInt("SALES");
    int total = rs.getInt("Total");
    System.out.printf("%s %d %.2f %d %d\n", name, sid, price, sales, total);
}
```

When would a `NullPointerException` be thrown?

A) When the table `Coffees` does not exist  
B) When `st.execute(sql)` returns `false`  
C) When the database connection fails  
D) The code never throws a `NullPointerException`

<details>
<summary>Answer</summary>
**B) When `st.execute(sql)` returns `false`**

If `st.execute(sql)` returns `false` (e.g., for an update or DDL statement), `rs` stays `null`. Then `rs.next()` throws a `NullPointerException`.
</details>

### Question 5

```java
String url = "jdbc:mysql://localhost:3306/classicmodels";
String sql = "insert into Bunnies(name,color)values(?,?)";
Connection cn = DriverManager.getConnection(url, user, password);
PreparedStatement st = cn.prepareStatement(sql);
st.setString(1, "Ted");
st.setString(2, "Yellow");
boolean b = st.execute();
System.out.println(b);
cn.close();
System.out.println("Successful");
```

What is printed if the `INSERT` succeeds?

A) `true` / `Successful`  
B) `false` / `Successful`  
C) A `SQLException` is thrown  
D) The code does not compile

<details>
<summary>Answer</summary>
**B) `false` / `Successful`**

`PreparedStatement.execute()` returns `false` for INSERT, UPDATE, DELETE statements (no `ResultSet`). After a successful insert, `"Successful"` is also printed.
</details>
