# Java 資料型別（Data Type）主要分為兩大類：
## 基本資料型別（Primitive Data Types） 與 參考資料型別（Reference Data Types）。
### 基本型別直接儲存數值，而參考型別儲存的是指向物件的記憶體位置。
以下為您整理 Java 完整的資料型別架構與規格：一、基本資料型別（Primitive Data Types）共有 8 種內建型別，用於儲存簡單數值：
### 1. 整數型別 (Integers)型別大小描述 / 範圍預設值  byte -128 ~ 127
### short 2 bytes -32,768 ~ 32,767
### int 4 bytes 約 -21 億 ~ 21 億
### long 8 bytes 極大整數範圍 0L
### 2. 浮點數型別 (Floating-point)型別大小描述 / 範圍預設值
### float 4 bytes 儲存 6 到 7 位有效小數點 0.0f
### double 8 bytes 儲存 15 位有效小數點（小數預設型別） 0.0d
### 3. 其他基本型別型別大小描述 / 範圍預設值
### boolean 1 bit 僅有兩種值：true 或 false false
### char 2 bytes 儲存單一字元 / Unicode '\u0000'
