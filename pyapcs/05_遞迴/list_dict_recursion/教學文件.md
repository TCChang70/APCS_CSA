# 【APCS 遞迴教學】List 與 Dict 的遞迴操作

## 為什麼要用遞迴處理 List 和 Dict？

在 APCS 實作題中，資料**不總是平坦的一維陣列**。很多時候你會遇到：

- **巢狀 List**：`[1, [2, 3], [[4, 5], 6]]`
- **巢狀 Dict**：`{"a": {"b": {"c": 1}}}`
- **混合結構**：`[{"name": "A", "children": [...]}, ...]`

巢狀結構的「深度」不固定，用巢狀 for 迴圈無法處理（你不知道要寫幾層）。
而遞迴能**自然對應**巢狀結構的定義 — 每個子結構就是一個更小的相同問題。

---

## Part 1：遞迴與 List

### 1.1 List 的遞迴本質

一個 List 可以看作：
```
list = 第一個元素 + 剩下的 list
```

這本身就是遞迴定義。基底條件是**空的 list**。

### 1.2 巢狀 List 的遞迴

巢狀 List 的每個元素可能是：
1. **數字**（或字串等葉節點）→ 直接處理
2. **List** → 遞迴處理（因為它跟原問題是同一種結構）

```
[1, [2, 3], 4]
 ├── 1         → 數字，直接處理
 ├── [2, 3]    → List，遞迴呼叫
 └── 4         → 數字，直接處理
```

### 範例：巢狀 List 求和

```python
def nested_sum(lst):
    total = 0
    for elem in lst:
        if isinstance(elem, list):
            total += nested_sum(elem)  # 遞迴處理子 list
        else:
            total += elem              # 葉節點，直接加
    return total

print(nested_sum([1, [2, 3], [[4, 5], 6]]))  # 21
```

| 層級 | 輸入 | 處理 | 回傳 |
|------|------|------|------|
| 1 | `[1, [2,3], [[4,5],6]]` | 1 + recursive([2,3]) + recursive([[4,5],6]) | 21 |
| 2 | `[2, 3]` | 2 + 3 | 5 |
| 2' | `[[4,5], 6]` | recursive([4,5]) + 6 | 15 |
| 3 | `[4, 5]` | 4 + 5 | 9 |

## Part 2：遞迴與 Dict

### 2.1 Dict 的遞迴模式

巢狀 Dict 的每個 value 可能是：
1. **葉節點**（int, str 等）→ 直接處理
2. **Dict** → 遞迴處理
3. **List**（包含 Dict）→ 迭代 + 遞迴

### 範例：Dict 深度走訪

```python
data = {
    "name": "root",
    "value": 1,
    "child": {
        "name": "level1",
        "value": 2,
        "child": {
            "name": "level2",
            "value": 3
        }
    }
}

def print_all_values(d):
    for key, val in d.items():
        if isinstance(val, dict):
            print_all_values(val)    # 遞迴處理子 dict
        else:
            print(f"{key}: {val}")
```

## Part 3：List + Dict 混合結構（APCS 最常考）

APCS 中高級題目中，最常見的是 **List of Dicts** 結構，
例如樹狀選單、組織架構、JSON 格式資料。

### 範例結構：組織架構樹

```python
org = {
    "name": "CEO",
    "subordinates": [
        {
            "name": "CTO",
            "subordinates": [
                {"name": "Engineer A", "subordinates": []},
                {"name": "Engineer B", "subordinates": []}
            ]
        },
        {
            "name": "CFO",
            "subordinates": [
                {"name": "Accountant", "subordinates": []}
            ]
        }
    ]
}
```

這是一個遞迴結構：每個員工的 `subordinates` 又是一群同樣格式的員工。

### 遞迴遍歷組織樹

```python
def print_org(node, depth=0):
    prefix = "  " * depth
    print(f"{prefix}- {node['name']}")
    for sub in node['subordinates']:
        print_org(sub, depth + 1)
```

輸出：
```
- CEO
  - CTO
    - Engineer A
    - Engineer B
  - CFO
    - Accountant
```

## Part 4：深度優先搜尋（DFS）在巢狀結構中

### 4.0 資料結構定義

在走訪巢狀結構之前，先定義我們要處理的資料型別：

```python
# 巢狀 List 資料結構
# 每個元素是 int 或 list（list 內的元素又是 int 或 list…）
nested_list: list = [1, [2, 3], [[4, 5], 6]]

# 巢狀 Dict 資料結構
# 每個 value 是 int、str、list 或 dict
nested_dict: dict = {
    "name": "root",
    "value": 1,
    "child": {
        "name": "level1",
        "tags": ["python", "recursion"],
        "child": {
            "name": "level2",
            "value": 42
        }
    }
}

# 混合結構（List + Dict）
# 最常見的 APCS 巢狀資料型態 — 類似 JSON
mixed_structure: list = [
    {"id": 1, "items": [{"x": 10}, {"x": 20}]},
    {"id": 2, "items": [{"x": 30}]}
]
```

從資料科學角度看，這三種結構可統一定義為：

```
Node = int | str | list[Node] | dict[str, Node]
```

也就是一個節點（Node）可能是：
- **葉節點**：`int` 或 `str` 等基本型別
- **分支節點**：`list[Node]` — 子節點組成的列表
- **分支節點**：`dict[str, Node]` — 有名稱的子節點集合

這個定義本身就是遞迴的，因此用遞迴處理最自然。

### 4.1 標準遞迴 DFS（可處理 List + Dict 混合）

```python
def dfs_nested(structure, path=""):
    if isinstance(structure, dict):
        for key, val in structure.items():
            dfs_nested(val, f"{path}.{key}" if path else key)
    elif isinstance(structure, list):
        for idx, val in enumerate(structure):
            dfs_nested(val, f"{path}[{idx}]")
    else:
        print(f"{path} = {structure}")
```

### 4.2 Stack 模擬遞迴（迭代 DFS）

### 4.2 Stack 模擬遞迴（迭代 DFS）

遞迴本質上就是用 Stack，你可以自己用 Stack 模擬：

```python
def dfs_nested_iterative(structure):
    stack = [(structure, "")]
    while stack:
        node, path = stack.pop()
        if isinstance(node, dict):
            for key, val in node.items():
                new_path = f"{path}.{key}" if path else key
                stack.append((val, new_path))
        elif isinstance(node, list):
            for idx, val in enumerate(node):
                stack.append((val, f"{path}[{idx}]"))
        else:
            print(f"{path} = {node}")
```

> **APCS 實戰提示**：當巢狀深度可能 > 1000 時，Stack 迭代版本不會遇到 Python 的遞迴深度限制。

## Part 5：常見遞迴操作模板

### 5.1 巢狀 List 扁平化

```python
def flatten(nested):
    result = []
    for elem in nested:
        if isinstance(elem, list):
            result.extend(flatten(elem))
        else:
            result.append(elem)
    return result
```

### 5.2 查找巢狀 Dict 中所有符合條件的值

```python
def find_all_keys(d, target_key):
    results = []
    for key, val in d.items():
        if key == target_key:
            results.append(val)
        if isinstance(val, dict):
            results.extend(find_all_keys(val, target_key))
        elif isinstance(val, list):
            for item in val:
                if isinstance(item, dict):
                    results.extend(find_all_keys(item, target_key))
    return results
```

### 5.3 修改巢狀 Dict 中的特定值

```python
def update_value(d, target_key, new_val):
    for key, val in d.items():
        if key == target_key:
            d[key] = new_val
        elif isinstance(val, dict):
            update_value(val, target_key, new_val)
        elif isinstance(val, list):
            for item in val:
                if isinstance(item, dict):
                    update_value(item, target_key, new_val)
```

## Part 6：遞迴深度估算（List/Dict 版）

```
巢狀深度 = 最大巢狀層數

Python 預設遞迴深度上限 = 1000

何時安全？
  人工輸入的 JSON：   通常深度 < 10   ✓ 安全
  APCS 測資：         通常深度 < 100  ✓ 安全
  程式自動生成的資料： 深度可能 > 1000 ✗ 需用迭代版
```

如何計算巢狀深度：

```python
def max_depth(structure):
    if not isinstance(structure, (list, dict)):
        return 0
    if isinstance(structure, list):
        if not structure:
            return 1
        return 1 + max(max_depth(item) for item in structure)
    if isinstance(structure, dict):
        if not structure:
            return 1
        return 1 + max(max_depth(val) for val in structure.values())
```

## 實戰流程：遇到巢狀結構時

```
看到題目有巢狀結構
  ├── 找出每個「節點」的欄位
  ├── 節點內是否有「子節點」欄位？
  │    ├── 有 → 這就是遞迴結構
  │    └── 無 → 可能是平坦結構，用迴圈
  ├── 你要做什麼操作？
  │    ├── 搜尋 → DFS / BFS
  │    ├── 求和/計數 → 遞迴遍歷
  │    ├── 轉換/修改 → 遞迴遍歷 + 原地修改
  │    └── 輸出 → 遞迴 +  depth 參數控制縮排
  └── 深度可能很大嗎？
       ├── 是 → 用 Stack 迭代版
       └── 否 → 用遞迴（更簡潔）
```
