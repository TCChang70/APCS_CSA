# P1.
最大公因數與最小公倍數（初級）

問題描述
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
給定兩個正整數 a 和 b，請使用遞迴實作輾轉相除法（Euclidean algorithm）
計算它們的最大公因數（GCD）和最小公倍數（LCM）。

LCM(a, b) = a × b ÷ GCD(a, b)

輸入格式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第一行：一個正整數 N，表示有 N 組測試資料
接下來 N 行：每行兩個正整數 a 和 b（1 ≤ a, b ≤ 10⁹）

輸出格式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
對每組測試資料輸出一行「GCD LCM」

範例輸入
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3
12 18
7 13
24 36

範例輸出
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
6 36
1 91

# p2
數位根（初級）

問題描述
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
數位根（Digital Root）是將一個正整數的所有位數相加，
若結果為個位數則停止，否則重複此過程直到得到個位數。

例如：
  98765 → 9+8+7+6+5 = 35
  35 → 3+5 = 8
  數位根為 8

請使用遞迴實作。

輸入格式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第一行：一個正整數 N，表示有 N 個數字
接下來 N 行：每行一個正整數 x（1 ≤ x ≤ 10¹⁸）

輸出格式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
對每個 x 輸出一行，表示它的數位根

範例輸入
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

98765
0
9999
12345

範例輸出
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
8
0
9

# p3
帕斯卡三角形（初級）

問題描述
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
帕斯卡三角形（Pascal's Triangle）是一個由組合數 C(n, k) 構成的三角形，
其中每一列的數字由上方的兩個數字相加得到：
  C(n, k) = C(n-1, k-1) + C(n-1, k)
  邊界條件：C(n, 0) = C(n, n) = 1

請使用遞迴實作：給定 N，輸出帕斯卡三角形的第 0 列到第 N 列。
N ≤ 30（注意：遞迴深度不深，但組合數可能很大，請使用 Python 大整數）

輸入格式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
一個正整數 N（0 ≤ N ≤ 30）

輸出格式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
輸出 N+1 列，第 i 列有 i+1 個數字，以空白間隔

範例輸入
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5

範例輸出
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
1 5 10 10 5 1

# p4

輸出所有排列，每行一個排列，數字以空白間隔。
