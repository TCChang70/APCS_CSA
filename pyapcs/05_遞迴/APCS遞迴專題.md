## 什麼是遞迴？

**遞迴（Recursion）** 是指一個函式呼叫自身來解決問題的方法。

核心思想：**將原問題分解為一個或多個規模更小的相同問題**，直到問題簡單到可以直接解決（基底條件）。

```
f(n) = f(n-1) + f(n-2)   ← 遞迴關係
f(0) = 0, f(1) = 1        ← 基底條件
```

---

## 遞迴三要素

| 要素 | 說明 | 錯誤範例 |
|------|------|----------|
| **1. 基底條件（Base Case）** | 最簡單的情況，直接回傳結果而不呼叫自身 | 缺少 → 無窮遞迴 → Stack Overflow |
| **2. 遞迴關係（Recurrence）** | 將問題拆解成更小的子問題 | 子問題沒變小 → 無窮遞迴 |
| **3. 收斂性（Convergence）** | 每次呼叫都要朝基底條件靠近 | 參數沒變化 → 無窮遞迴 |

## APCS 常見遞迴題型

### 初級～中級（常考）

| 題型 | 範例 | 考點 |
|------|------|------|
| 數學遞迴 | 階乘、費氏數列、最大公因數 | 直接代公式，最基本的遞迴 |
| 數位操作 | 數字反轉、數位和、轉二進位 | 利用整數除法收斂 |
| 字串操作 | 字串反轉、回文判斷 | 縮減字串長度 |
| 陣列/串列 | 陣列求和、最大值 | 縮減陣列範圍 |

### 中高級～高級（常考）

| 題型 | 範例 | 考點 |
|------|------|------|
| 遞迴窮舉（Backtracking） | 子集合、排列、組合 | 選擇/不選擇的分支 |
| 圖論遞迴 | DFS 走迷宮、連通區塊 | 四方向/八方向搜尋 |
| 分治法 | 二分搜尋、合併排序 | 分割→遞迴→合併 |
| 樹狀結構 | 二元樹遍歷、運算式樹 | 左子樹+右子樹遞迴 |
| DP 遞迴 + 記憶化 | 背包問題、費氏數列優化 | 遞迴 + 備忘錄避免重算 |

## 遞迴 vs 迴圈

| 比較 | 遞迴 | 迴圈 |
|------|------|------|
| 程式碼 | 簡潔、接近數學定義 | 通常較長 |
| 可讀性 | 高（對於遞迴思維熟練者） | 高（對於一般人） |
| 記憶體 | 每個呼叫佔用 stack 空間 | 通常 O(1) |
| 效能 | 函式呼叫有開銷 | 較快 |
| 適合場景 | 樹、圖、分治、回溯 | 單純重複操作 |

> **APCS 實戰建議**：若遞迴深度可能很大（如 N > 1000），Python 的遞迴深度限制預設為 1000，需用 `sys.setrecursionlimit()` 調整或用迴圈替代。

## 常見錯誤與陷阱

1. **忘記基底條件** → 無窮遞迴 → RecursionError
2. **基底條件永遠不會達到** → 參數沒正確變化
3. **重複計算** → 如樸素費氏數列，指數爆炸（O(2ⁿ)）
4. **遞迴深度過大** → Python 預設上限 1000
5. **可變物件作為預設參數** → `def f(x, lst=[])` 會共用同一個 list

---

## 實戰建議

1. **先寫基底條件**：再寫遞迴關係
2. **畫遞迴樹**：幫助理解呼叫過程
3. **確認收斂**：參數是否每次都在縮小
4. **考慮深度**：APCS 實作題若遞迴層級可能很深，優先考慮 memoization 或改迭代
5. **背模板**：Backtracking、DFS 有固定寫法，熟練可加快答題速度
