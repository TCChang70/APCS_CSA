本文件搭配 [背包問題_python語法說明.md](背包問題_python語法說明.md) 使用。
三題都是「背包問題的變形」，但各自考驗不同的 **Python 語法重點**：

| 題目 | 考驗的語法重點 |
|------|----------------|
| 題 1：湊滿容量最少物品數 | `[INF] * (W+1)` 串列重複、`range()`、`min()` |
| 題 2：有限數量背包 | 串列合併 `+`、`for x in 串列`、物品拆分 |
| 題 3：印出選了哪些物品 | 2D 串列 `[[0]*(W+1) for _ in range(N+1)]`、`while` 回溯 |

## 題目 1：湊滿容量最少物品數（Easy）

### 題目

有 N 件物品（每件最多用一次），每件有重量 weights[i]。背包容量 W。
問：**剛好湊滿容量 W**，最少需要幾件物品？若無法湊滿，回傳 -1。

> 注意：這題不考慮價值，只算「件數」。

### 輸入輸出範例

```
輸入：weights = [2, 3, 4, 5], W = 7
輸出：2（5 + 2，兩件）
```

```
輸入：weights = [3, 5], W = 7
輸出：-1（3+5=8 超過，無法湊出 7）
```

### 提示（先別急著看解答）

```
狀態：dp[w] = 湊到容量 w 最少需要幾件物品
轉移：dp[w] = min(dp[w], dp[w - weights[i]] + 1)
初始：dp[0] = 0，其餘 INF
迴圈：物品外層 + 容量倒序（跟 0/1 背包一樣，因為每件最多一次）
答案：dp[W] 若為 INF 則回傳 -1

語法重點：
  dp = [INF] * (W + 1)   ← 串列重複 + 不可達狀態
  min(dp[w], ...)        ← 取最小（和背包的 max 相反！）
```

### 逐步追蹤（weights=[2,3,4,5], W=7）

```
初始：dp = [0, INF, INF, INF, INF, INF, INF, INF]

物品0（wi=2）倒序：
  w=7: dp[7] = min(INF, dp[5]+1) = INF
  w=6: dp[6] = min(INF, dp[4]+1) = INF
  w=5: dp[5] = min(INF, dp[3]+1) = INF
  w=4: dp[4] = min(INF, dp[2]+1) = INF
  w=3: dp[3] = min(INF, dp[1]+1) = INF
  w=2: dp[2] = min(INF, dp[0]+1) = 1
  dp = [0, I, 1, I, I, I, I, I]

物品1（wi=3）倒序：
  w=7: dp[7] = min(INF, dp[4]+1) = INF
  w=6: dp[6] = min(INF, dp[3]+1) = INF
  w=5: dp[5] = min(INF, dp[2]+1) = 2
  w=4: dp[4] = min(INF, dp[1]+1) = INF
  w=3: dp[3] = min(INF, dp[0]+1) = 1
  dp = [0, I, 1, 1, I, 2, I, I]

物品2（wi=4）倒序：
  w=7: dp[7] = min(INF, dp[3]+1) = 2
  w=6: dp[6] = min(INF, dp[2]+1) = 2
  w=5: dp[5] = min(2, dp[1]+1) = 2
  w=4: dp[4] = min(INF, dp[0]+1) = 1
  dp = [0, I, 1, 1, 1, 2, 2, 2]

物品3（wi=5）倒序：
  w=7: dp[7] = min(2, dp[2]+1) = 2   ← 5+2，兩件
  w=6: dp[6] = min(2, dp[1]+1) = 2
  w=5: dp[5] = min(2, dp[0]+1) = 1
  dp = [0, I, 1, 1, 1, 1, 2, 2]

答案：dp[7] = 2 ✓
```

### 和 0/1 背包的差異對照

| 項目 | 0/1 背包 | 本題 |
|------|----------|------|
| 求什麼 | 最大價值 | 最少件數 |
| 轉移用 | `max(...)` | `min(...)` |
| 初始值 | 全部 0 | dp[0]=0，其餘 INF |
| 迴圈結構 | 物品外層 + 容量倒序 | **完全相同** |

### 常見錯誤

| 錯誤 | 後果 |
|------|------|
| 初始值全部設 0 | `min` 永遠是 0，答案全錯 |
| 忘了 `-1` 改成正序 | 同一物品可重複用（變無限背包） |
| 忘了最後 `== INF` 判斷 | 湊不出時回傳 INF 而不是 -1 |

## 題目 2：有限數量背包（Medium）

### 題目

有 N 種物品，每種物品有一個**最大可取數量** count[i]。背包容量 W。
求最大價值。

```
weights = [2, 3]      重量
values  = [3, 4]      價值
counts  = [2, 1]      數量上限（第0種最多2個，第1種最多1個）
W = 5
```

### 輸入輸出範例

```
輸入：weights=[2,3], values=[3,4], counts=[2,1], W=5
輸出：7（物品0取1個 + 物品1取1個 = 3+4；或 物品0取2個=6）
```

### 核心技巧：物品拆分

**語法重點**：有限數量背包的標準解法是「把每種物品複製成多件」，變成 0/1 背包。

```python
# 串列合併 + 重複語法
new_weights = []   # 空串列
new_values = []    # 空串列
for i in range(len(weights)):
    new_weights += [weights[i]] * counts[i]   # [2,2] + ... 串列加法
    new_values += [values[i]] * counts[i]     # [3,3] + ...
```

逐句拆解：

| 語法 | 意義 |
|------|------|
| `[]` | 空串列 |
| `[weights[i]] * counts[i]` | 把單一元素重複 counts[i] 次（如 `[2]*2` → `[2,2]`） |
| `+=` | 串列相加再指派（`new_weights = new_weights + [2,2]`） |


### 逐步追蹤

```
拆分過程：
  物品0：weight 2, value 3, count 2 → 複製成 2 件：[2, 2] 和 [3, 3]
  物品1：weight 3, value 4, count 1 → 複製成 1 件：[3] 和 [4]

拆分後的新物品：weights=[2,2,3], values=[3,3,4]

0/1 背包（容量5）：
  處理新物品0（w=2,v=3）：
    dp = [0,0,3,3,3,3]
  處理新物品1（w=2,v=3）：
    w=5: dp[5] = max(3, dp[3]+3) = 6   ← 選了2個物品0
    w=4: dp[4] = max(3, dp[2]+3) = 6
    w=3: dp[3] = max(3, dp[1]+3) = 3
    w=2: dp[2] = max(3, dp[0]+3) = 3
    dp = [0,0,3,3,6,6]
  處理新物品2（w=3,v=4）：
    w=5: dp[5] = max(6, dp[2]+4) = 7   ← 物品0x1 + 物品1x1
    w=4: dp[4] = max(6, dp[1]+4) = 6
    w=3: dp[3] = max(3, dp[0]+4) = 4
    dp = [0,0,3,4,6,7]

答案：dp[5] = 7 ✓
```

### 常見錯誤

| 錯誤 | 後果 |
|------|------|
| 直接把 counts 加進去迴圈 | 不是標準解法，容易寫錯 |
| 忘了 `[weights[i]]` 的中括號 | `[2] * 2` 是串列，`2 * 2` 是數字 |
| 拆完後用正序更新 | 又變回可以無限次取用 |

## 題目 3：印出選了哪些物品（Medium-Hard）

### 題目

0/1 背包除了回傳最大價值，還要**印出被選中的物品編號**。

```
輸入：weights=[2,3,4,5], values=[3,4,5,6], W=5
輸出：最大價值 7，選了物品 {0, 1}（w=2+3=5, v=3+4=7）
```

### 核心技巧：需要 2D 表格來回溯

**語法重點**：要回溯「選了誰」，必須保留完整的 2D 表 `dp[i][w]`，不能只用 1D 壓縮。

```python
# 2D 串列語法：N+1 列，每列 W+1 個 0
dp = [[0] * (W + 1) for _ in range(N + 1)]
```

逐句拆解：

| 語法 | 意義 |
|------|------|
| `[0] * (W+1)` | 一列：W+1 個 0 |
| `for _ in range(N+1)` | 重複 N+1 次（列數） |
| `[[0]*(W+1) for _ in range(N+1)]` | 產生 N+1 個列，組成 2D 表 |
| `_` | 迴圈變數，但用不到所以取名 `_` |

```
dp = [
  [0, 0, 0, 0, 0, 0],   ← 第 0 列（沒有物品）
  [0, 0, 0, 0, 0, 0],   ← 第 1 列（前 1 件）
  [0, 0, 0, 0, 0, 0],   ← 第 2 列（前 2 件）
  ...
]

dp[i][w] = 前 i 件物品、容量 w 的最大價值
```



| 條件 | 意義 |
|------|------|
| `dp[i][w] == dp[i-1][w]` | 拿不拿第 i-1 件結果一樣 → **沒選它** |
| `dp[i][w] != dp[i-1][w]` | 這列多出來的價值來自第 i-1 件 → **選了它** |

### 逐步追蹤（weights=[2,3], values=[3,4], W=5）

#### 填表結果

```
dp = [
         w:  0   1   2   3   4   5
  i=0(無):  0   0   0   0   0   0
  i=1(物0): 0   0   3   3   3   3
  i=2(物1): 0   0   3   4   4   7
]
```

#### 回溯過程

```
w = 5

i=2: dp[2][5]=7 vs dp[1][5]=3 → 不同！物品1被選 → result=[1], w=5-3=2
i=1: dp[1][2]=3 vs dp[0][2]=0 → 不同！物品0被選 → result=[1,0], w=2-2=0

result = [1, 0] → 選了物品1和物品0 → 價值 7 ✓
```

### 常見錯誤

| 錯誤 | 後果 |
|------|------|
| 用 1D 壓縮 dp | 回溯時資訊不足，無法判斷「誰被選」 |
| 忘了 `for _ in range(N+1)` | `[[0]*(W+1)] * (N+1)` 是**錯的**！全部列指向同一物件 |
| `if dp[i][w] != dp[i-1][w]` 寫成 `>` | 某些情況 dp 值相同但物品沒被選，判斷會錯 |

> **重要**：`[[0]*(W+1)] * (N+1)` 會建立 N+1 個「指向同一個串列」的參照，改一格全部一起變！
> 一定要用 `for _ in range(N+1)` 建立**獨立**的列。

```python
# 錯誤示範（列是同一物件）
dp = [[0] * (W + 1)] * (N + 1)   # ✗ 改 dp[0][1] 所有列都變

# 正確寫法（每列獨立）
dp = [[0] * (W + 1) for _ in range(N + 1)]   # ✓ 每列是新的串列
```
