## 函式定義語法

```python
def knapsack(weights, values, W):
    ...
```

### 逐詞拆解

| 關鍵字 | 意義 |
|--------|------|
| `def` | define 的縮寫，Python 宣告函式的關鍵字 |
| `knapsack` | 函式名稱（function name） |
| `(weights, values, W)` | 參數（parameters）：呼叫時要傳入的三個東西 |
| `:` | Python 的區塊開頭符號，表示「以下是函式內容」 |
| 縮排（4 空格） | Python 用縮排區分程式區塊，不是用 `{}` |

### 呼叫與參數對應

```python
knapsack(w, v, 5)
#    ↑   ↑  ↑
# weights=w  values=v  W=5
```

| 呼叫時 | 對應到函式內的參數 |
|--------|---------------------|
| `w`（重量串列） | `weights` |
| `v`（價值串列） | `values` |
| `5`（容量） | `W` |

## 變數與資料結構

### `N = len(weights)`

```python
N = len(weights)
```

| 語法 | 意義 |
|------|------|
| `len(x)` | 內建函式，回傳串列 x 的長度（元素個數） |
| `len(weights)` | weights 有幾個元素 = 物品數量 |

例：`weights = [2, 3, 4, 5]` → `len(weights)` = 4 → `N = 4`（4 件物品）

### `dp = [0] * (W + 1)`

```python
dp = [0] * (W + 1)
```

這行**很多人看不懂**，其實是兩個概念的組合：

```python
[0] * 5
```

意思是「把 `[0]` 重複 5 次」，結果是 `[0, 0, 0, 0, 0]`。

所以 `dp = [0] * (W + 1)`：

| 部分 | 意義 |
|------|------|
| `[0]` | 一個只有單一元素 0 的串列 |
| `* (W + 1)` | 重複 W+1 次 |
| 結果 | `[0, 0, 0, ..., 0]`，共有 W+1 個元素 |

例：`W = 5` → `[0] * 6` → `dp = [0, 0, 0, 0, 0, 0]`

### dp 陣列索引對照

```
dp = [0, 0, 0, 0, 0, 0]
       ↑  ↑  ↑  ↑  ↑  ↑
索引:  0  1  2  3  4  5
       ↓  ↓  ↓  ↓  ↓  ↓
      容量0 容量1 容量2 ... 容量5

dp[w] = 「容量 w 時能拿到的最大價值」
```

> **關鍵**：`dp[W]` 就是容量剛好 W 時的答案。

## range() 詳解（含倒序技巧）

range() 是 Python 產生數字序列的函式，有三種常見寫法：

### 寫法 1：`range(5)` → 0, 1, 2, 3, 4

```python
for i in range(5):
    print(i)
# 輸出：0 1 2 3 4
```

### 寫法 2：`range(1, 6)` → 1, 2, 3, 4, 5

```python
for i in range(1, 6):
    print(i)
# 輸出：1 2 3 4 5
```

| 參數 | 意義 |
|------|------|
| `1` | 起點（start）包含 |
| `6` | 終點（stop）**不包含**，只到 6-1=5 |

### 寫法 3：`range(5, 0, -1)` → 5, 4, 3, 2, 1 ← 倒序

```python
for i in range(5, 0, -1):
    print(i)
# 輸出：5 4 3 2 1
```

| 參數 | 意義 |
|------|------|
| `5` | 起點（start）包含 |
| `0` | 終點（stop）**不包含**，只到 0+1=1 |
| `-1` | 步長（step），每次 -1，也就是「倒著走」 |

### 三參數對照表

| 寫法 | 產生的數字 | 說明 |
|------|-----------|------|
| `range(5)` | 0,1,2,3,4 | 從 0 開始，5 個 |
| `range(1, 6)` | 1,2,3,4,5 | 1 到 5（不含 6） |
| `range(5, 0, -1)` | 5,4,3,2,1 | 5 到 1（不含 0），倒序 |
| `range(W, 1, -1)` | W,W-1,...,2 | W 到 2，倒序 |

## 0/1 背包逐行解析

```python
def knapsack(weights, values, W):        # 行 1：定義函式
    N = len(weights)                      # 行 2：N = 物品數量
    dp = [0] * (W + 1)                    # 行 3：dp 陣列，大小 W+1
    for i in range(N):                    # 行 4：外層，處理每一件物品
        for w in range(W, weights[i] - 1, -1):   # 行 5：內層，倒序
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])  # 行 6
    return dp[W]                          # 行 7：回傳答案
```

### 行 4 詳解：`for i in range(N)`

```
range(N) → 0, 1, 2, ..., N-1

i=0 → 處理第 0 件物品（weights[0]=2, values[0]=3）
i=1 → 處理第 1 件物品（weights[1]=3, values[1]=4）
i=2 → 處理第 2 件物品（weights[2]=4, values[2]=5）
i=3 → 處理第 3 件物品（weights[3]=5, values[3]=6）
```

### 行 5 詳解：`for w in range(W, weights[i] - 1, -1)`

這是**整個程式最難懂的一行**，拆成三塊看：

```
range( W,  weights[i] - 1,  -1  )
        ↑         ↑          ↑
      起點      終點       步長
  (從最大容量) (到 wi 為止) (倒著走)
```

**用實際數字代入**（i=0，weights[0]=2，W=5）：

```
range(5, 2 - 1, -1) = range(5, 1, -1)
→ 產生的數字：5, 4, 3, 2
→ 也就是 w = 5, 4, 3, 2
```

**為什麼起點是 W 終點是 wi-1？**

| 問題 | 答案 |
|------|------|
| 為什麼從 W 開始？ | 從最大容量開始算 |
| 為什麼到 weights[i]-1？ | 容量小於 wi 時根本放不下第 i 件，不用算 |
| 為什麼倒序（-1）？ | 避免同一件物品被重複選取（見下方說明） |

**倒序 vs 正序的差別**（假設物品 0：w=2, v=3）：

```
正序（錯誤）：w = 2, 3, 4, 5
  w=2: dp[2] = max(dp[2], dp[0]+3) = 3    ← 更新了 dp[2]
  w=4: dp[4] = max(dp[4], dp[2]+3) = 6    ← 用的 dp[2] 已含物品0！
  → 物品 0 被選了兩次 ✗

倒序（正確）：w = 5, 4, 3, 2
  w=5: dp[5] = max(dp[5], dp[3]+3) = 3    ← dp[3] 還是舊值 0
  w=2: dp[2] = max(dp[2], dp[0]+3) = 3    ← 最後才更新 dp[2]
  → 物品 0 最多被選一次 ✓
```

### 行 6 詳解：`dp[w] = max(dp[w], dp[w - weights[i]] + values[i])`

```
dp[w] = max(  dp[w],                dp[w - weights[i]] + values[i]  )
             ↑                        ↑
          不拿第 i 件                拿第 i 件
          （維持現狀）              （空出重量，加價值）
```

用實際數字代入（處理物品 1：w=3, v=4，當 w=5 時）：

```
dp[5] = max( dp[5],   dp[5 - 3] + 4  )
           = max( dp[5], dp[2] + 4   )

上一輪 dp[2] = 3（含物品 0）
所以：dp[5] = max(3, 3 + 4) = max(3, 7) = 7
```

#### `weights[i]` 和 `values[i]` 的索引對應

| i | weights[i] | values[i] | 說明 |
|---|-----------|-----------|------|
| 0 | 2 | 3 | 第 0 件物品重 2、值 3 |
| 1 | 3 | 4 | 第 1 件物品重 3、值 4 |
| 2 | 4 | 5 | 第 2 件物品重 4、值 5 |
| 3 | 5 | 6 | 第 3 件物品重 5、值 6 |

### 行 7 詳解：`return dp[W]`

`return` 把結果傳回給呼叫者。`dp[W]` = 容量 W 的最大價值 = 答案。

## 無限背包逐行解析

```python
def knapsack_unbounded(weights, values, W):   # 行 1
    """無限背包（每種物品可取無限次）"""          # 行 2：docstring
    dp = [0] * (W + 1)                         # 行 3
    for w in range(1, W + 1):                  # 行 4：外層是容量
        for i in range(len(weights)):          # 行 5：內層是物品
            if w >= weights[i]:                # 行 6：容量夠才考慮
                dp[w] = max(dp[w], dp[w - weights[i]] + values[i])  # 行 7
    return dp[W]                               # 行 8
```

### 與 0/1 背包的迴圈結構對比

| 項目 | 0/1 背包 | 無限背包 |
|------|----------|----------|
| 外層 | 物品（for i） | 容量（for w） |
| 內層 | 容量倒序（for w 大→小） | 物品正序（for i） |
| 更新方向 | 由大到小 | 由小到大 |
| 結果 | 每件最多 1 次 | 每件無限次 |

### 行 4：`for w in range(1, W + 1)`

```
range(1, 6) → 1, 2, 3, 4, 5
→ w = 1, 2, 3, 4, 5（容量由小到大）
```

### 行 5：`for i in range(len(weights))`

```
len(weights) = 4
range(4) → 0, 1, 2, 3
→ i = 0, 1, 2, 3（每一件物品都試）
```

### 行 6：`if w >= weights[i]`

| 語法 | 意義 |
|------|------|
| `if` | 條件判斷 |
| `w >= weights[i]` | 目前容量 w 是不是大於等於物品重量 |
| `:` | 條件成立就執行縮排內的程式 |

例：w=2 時：
- i=0（wi=2）：2>=2 ✓ 可以拿 → 執行
- i=1（wi=3）：2>=3 ✗ 放不下 → 跳過

### 行 7：轉移（同 0/1 背包）

```
dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
```

唯一差別是**正序**更新，讓 dp[w] 可以引用「本輪已更新」的小容量值 → 物品可重複。

## 主程式區塊

```python
if __name__ == '__main__':
    w = [2, 3, 4, 5]
    v = [3, 4, 5, 6]
    print(f"0/1 背包容量 5: {knapsack(w, v, 5)}")
    print(f"無限背包容量 5: {knapsack_unbounded(w, v, 5)}")
```

### `if __name__ == '__main__':`

| 部分 | 意義 |
|------|------|
| `__name__` | 一個隱藏的變數，Python 自動設定 |
| `'__main__'` | 當「直接執行這個檔案」時，`__name__` 的值 |
| `if __name__ == '__main__':` | 「如果我是被直接執行，不是被 import 的」 |

**為什麼要這樣寫？**

```
情境：別的程式 import 這支檔案的 knapsack 函式
  import 時不會執行 if 區塊的內容
  → 避免測試資料亂印

情境：直接執行 python ex3_背包問題.py
  __name__ == '__main__' 成立
  → 執行測試資料
```

### `w = [2, 3, 4, 5]` 語法

| 語法 | 意義 |
|------|------|
| `[2, 3, 4, 5]` | 串列（list）語法，四個元素 |
| `w = ...` | 把串列存進變數 w |

### `print(f"0/1 背包容量 5: {knapsack(w, v, 5)}")`

| 部分 | 意義 |
|------|------|
| `print(...)` | 印出內容到螢幕 |
| `f"..."` | f-string，可以在字串中放 `{運算式}` |
| `{knapsack(w, v, 5)}` | 執行函式，把回傳值塞進字串 |

```
執行順序：
  1. knapsack(w, v, 5) 先跑，回傳 7
  2. f-string 變成 "0/1 背包容量 5: 7"
  3. print 印出：0/1 背包容量 5: 7
```

## 實作驗證小抄

想自己動手驗證，複製以下程式到互動式環境試試：

```python
# 驗證 range 倒序
print(list(range(5, 1, -1)))   # [5, 4, 3, 2]

# 驗證串列重複
print([0] * 6)                 # [0, 0, 0, 0, 0, 0]

# 驗證 len
print(len([2, 3, 4, 5]))       # 4

# 驗證 f-string
print(f"答案: {3 + 4}")        # 答案: 7

# 驗證 max
print(max(3, 7))               # 7

# 自己跑 0/1 背包
def knapsack(weights, values, W):
    dp = [0] * (W + 1)
    for i in range(len(weights)):
        for w in range(W, weights[i] - 1, -1):
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
    return dp[W]

print(knapsack([2, 3, 4, 5], [3, 4, 5, 6], 5))  # 7
```

### 常見語法錯誤檢查表

| 錯誤 | 後果 | 修正 |
|------|------|------|
| 忘了 `:`（如 `for i in range(N)` 結尾沒冒號） | SyntaxError | 每行 `for/if/def` 結尾加 `:` |
| 縮排不齊 | IndentationError | 統一用 4 個空格 |
| `range(W, wi-1)` 忘了第三參數 `-1` | 變成正序，物品重複選 | 0/1 背包加 `, -1` |
| `dp = [0] * W`（少 1） | 少了 dp[W] 位置，索引錯誤 | 用 `[0] * (W+1)` |
| 把 `weights[i]` 寫成 `weights` | 用整個串列運算，TypeError | 記得加 `[i]` |
