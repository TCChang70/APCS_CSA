## 什麼是動態規劃？

**動態規劃（Dynamic Programming, DP）** 是一種將問題分解為重疊子問題，
並將子問題的答案儲存起來避免重複計算的方法。

### 核心概念

| 概念 | 說明 |
|------|------|
| **最優子結構（Optimal Substructure）** | 原問題的最優解可由子問題的最優解推導 |
| **重疊子問題（Overlapping Subproblems）** | 同一個子問題會被多次求解 |
| **狀態（State）** | 定義 dp[i] 或 dp[i][j] 代表的意義 |
| **轉移（Transition）** | 狀態之間的關係式，如 dp[i] = dp[i-1] + dp[i-2] |

### 何時用 DP？
- 求**最大值 / 最小值**（最優解）
- 求**方案數量**（計數）
- 求**可行性**（True / False）
- 問題可以分解成**重疊的子問題**

## DP 兩大實作方式

### Top-Down（遞迴 + 記憶化）
```
def f(n):
    if n in memo: return memo[n]
    if n <= 1: return n
    memo[n] = f(n-1) + f(n-2)
    return memo[n]
```
- 優點：直覺，從目標狀態出發
- 缺點：遞迴有深度限制

### Bottom-Up（迭代填表）
```
dp[0], dp[1] = 0, 1
for i in range(2, n+1):
    dp[i] = dp[i-1] + dp[i-2]
```
- 優點：無遞迴開銷，容易做空間壓縮
- 缺點：需要確定所有狀態的計算順序

> **APCS 建議優先 Bottom-Up**：無堆疊溢位風險，效能較好。

## APCS 常見 DP 題型

| 題型 | 狀態定義 | 難度 |
|------|----------|------|
| 費氏數列 / 爬樓梯 | dp[i] = 到第 i 階的方法數 | 初級 |
| 最大連續子陣列和（Kadane） | dp[i] = 以 i 結尾的最大和 | 中級 |
| 背包問題（0/1 Knapsack） | dp[i][w] = 前 i 物品容量 w 的最大價值 | 中級 |
| 最長共同子序列（LCS） | dp[i][j] = A[:i] 與 B[:j] 的 LCS | 中級 |
| 最長遞增子序列（LIS） | dp[i] = 以 i 結尾的最長遞增長度 | 中級 |
| 編輯距離（Edit Distance） | dp[i][j] = 轉換最少步數 | 中高級 |
| 硬幣組合（Coin Change） | dp[amt] = 湊到 amt 的最小硬幣數 | 中級 |
| 分割問題（Partition） | dp[s] = 能否湊出總和 s | 中級 |

## 時間複雜度比較

```
暴力法 vs DP 的差距：

費氏數列 F(50)
  純遞迴:        ~65 次運算   ✗ 指數爆炸
  DP Top-Down:   ~50 次運算   ✓ O(N)

背包問題 N=100, W=10000
  暴力窮舉:      2¹⁰⁰ 種組合  ✗ 不可能
  DP 0/1背包:    1,000,000 次  ✓ O(N·W)
```

## DP 解題步驟

1. **定義狀態**：`dp[i]` 或 `dp[i][j]` 代表什麼？
2. **找出轉移式**：如何從之前的狀態推到當前狀態？
3. **初始化**：邊界條件（base case）是什麼？
4. **計算順序**：從前往後？從後往前？
5. **優化空間**：能否只用幾個變數取代整個陣列？

---

## 實戰建議

1. **先確認是否為 DP 題**：求最值、計數、可行性 → 可能是 DP
2. **1D DP 先寫出來**，再想能不能壓縮空間
3. **2D DP 注意維度順序**：N×M 和 M×N 可能差很多
4. **APCS 中級 DP 常考**：爬樓梯、背包、LIS 一定要會
5. **背模板**：背包問題、LCS、LIS 的寫法高度固定
