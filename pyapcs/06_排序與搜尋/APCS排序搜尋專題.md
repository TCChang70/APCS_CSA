## 排序演算法概覽

排序是 APCS 最基礎也最常出現的技巧之一。Python 的 `list.sort()` 和 `sorted()` 採用 TimSort（O(N log N)），但理解經典排序演算法對解決變形題至關重要。

| 演算法 | 平均時間 | 最差時間 | 空間 | 穩定 |
|--------|----------|----------|------|------|
| 氣泡排序 | O(N²) | O(N²) | O(1) | ✓ |
| 選擇排序 | O(N²) | O(N²) | O(1) | ✗ |
| 插入排序 | O(N²) | O(N²) | O(1) | ✓ |
| 合併排序 | O(N log N) | O(N log N) | O(N) | ✓ |
| 快速排序 | O(N log N) | O(N²) | O(log N) | ✗ |
| 計數排序 | O(N + K) | O(N + K) | O(K) | ✓ |

## 各排序演算法詳解

### 氣泡排序（Bubble Sort）
相鄰兩兩比較，較大的往後浮。每輪至少確定一個最大值在正確位置。

### 選擇排序（Selection Sort）
每輪從未排序區選出最小值，放到已排序區末尾。

### 插入排序（Insertion Sort）
將元素逐個插入到已排序區的正確位置。當資料量小或近乎有序時很快。

### 合併排序（Merge Sort）
分治法：分割 → 遞迴排序 → 合併。保證 O(N log N)。

### 快速排序（Quick Sort）
選 pivot → 分割成小於/大於 pivot 兩區 → 遞迴排序。平均最快。

### 計數排序（Counting Sort）
非比較排序，適用於值域小的整數陣列（如成績 0~100）。

## 搜尋演算法

| 演算法 | 前提 | 時間 | 說明 |
|--------|------|------|------|
| 線性搜尋 | 無 | O(N) | 逐一檢查，最通用 |
| 二分搜尋 | 已排序 | O(log N) | 每次砍半 |
| 內建 `index()` | 無 | O(N) | Python list 方法 |

## 時間複雜度比較

```
N = 1000
  氣泡排序: ~500,000 次比較
  插入排序: ~250,000 次比較（平均）
  合併排序: ~10,000 次比較
  Python sort: ~10,000 次比較（TimSort，極度優化）

APCS 實作題中 N ≤ 10⁵ 時，一律用 Python 內建 sort。
絕對不要自己實作 O(N²) 排序，會 TLE。
```

## 實戰建議

1. **APCS 實戰中直接用 `list.sort()`**，不要自己寫排序（除非題目要求）
2. **自訂排序用 `key=lambda x: ...`**，可回傳 tuple 實作多欄位排序
3. **計數排序**適用於成績統計、字母頻率等值域小的情況
4. **二分搜尋**熟記 `bisect` 模組：`bisect_left`、`bisect_right`
5. **排序後搭配貪婪或雙指標**是 APCS 中級題常見套路
