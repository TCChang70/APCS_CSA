## 各題解法摘要

| 題目 | 核心演算法 | 時間複雜度 |
|---|---|---|
| 七言對聯 | 直接條件判斷 | O(n) |
| 裝飲料 | 體積↔高度轉換公式 | O(N) |
| 遊戲選角 | 排序取第二大 | O(n log n) |
| 特殊位置 | 曼哈頓距離暴力枚舉 | O(n·m·9²) |
| 蒐集寶石 | 方向模擬 | O(步數) |
| 字串解碼 | Deque 反向還原 | O(m·n) |
| 數字賓果 ⭐ | 計數陣列模擬 | O(N² + M) |
| 排隊買飲料 ⭐ | 佇列模擬 | O(總需求/K) |
| 成績排名 ⭐ | 排序 + 並列排名 | O(N log N) |
| 旋轉方陣 ⭐ | 矩陣座標轉換 | O(N²) |
| 矩陣路徑計數 ⭐ | DP 滾動陣列 | O(n·m) |
| 活動排程重疊 ⭐ | 掃描線演算法 | O(N log N) |
| 迷宮探訪 | 遞迴先序遍歷 | O(N) |
| 先加後乘與函數 | 遞迴下降解析器 | O(字串長度) |
| 連鎖反應 | 二分搜尋 + BFS 模擬 | O(log(M+N)·K·r²) |
| 美食博覽會 | 滑動視窗 + DP | O(n·k) |
| 低地距離 | 樹狀陣列（BIT） | O(n log n) |
| 平緩步道 | 二分搜尋 + BFS | O(n²·log(高度)) |
| 階乘與費氏 ⭐ | 數學遞迴 | O(2ⁿ)／O(N) |
| 數位操作 ⭐ | 數位遞迴（//10） | O(log N) |
| 字串回文 ⭐ | 字串縮減遞迴 | O(N) |
| 子集合 ⭐ | Backtracking | O(2ⁿ) |
| 迷宮DFS ⭐ | 圖論遞迴 DFS | O(N·M) |
| 二分搜尋 ⭐ | 分治法 | O(log N) |
| 合併排序 ⭐ | 分治法 | O(N log N) |
| 河內塔 ⭐ | 經典遞迴 | O(2ⁿ) |
| 記憶化費氏 ⭐ | DP + 記憶化 | O(N) |
| N皇后 ⭐ | Backtracking 剪枝 | O(N!) |
| 練習題1：最大公因數 ⭐ | 輾轉相除法遞迴 | O(log min(a,b)) |
| 練習題2：數位根 ⭐ | 數位和遞迴 | O(log n) |
| 練習題3：帕斯卡三角形 ⭐ | 組合數遞迴 + 記憶化 | O(N²) |
| 練習題4：排列生成 ⭐⭐ | Backtracking 排列 | O(N!) |
| 練習題5：連通區域數量 ⭐⭐ | DFS Flood Fill | O(N·M) |
| 練習題6：運算式求值 ⭐⭐ | 遞迴下降解析器 | O(len(s)) |
| 三大排序實作 ⭐⭐ | 氣泡/選擇/插入排序 | O(N²) |
| 自訂排序 ⭐⭐ | lambda key 排序 | O(N log N) |
| 計數排序 ⭐⭐ | 非比較排序 | O(N+K) |
| 區間合併 ⭐⭐ | 排序 + 掃描 | O(N log N) |
| 二分搜尋邊界 ⭐⭐ | lower/upper bound | O(log N) |
| 第K大元素 ⭐⭐ | Quick Select | O(N) 平均 |
| 括號匹配 ⭐⭐ | Stack 應用 | O(N) |
| 佇列模擬 ⭐⭐ | Deque 應用 | O(N) |
| BFS最短路徑 ⭐⭐ | Queue + BFS | O(N·M) |
| 單調堆疊 ⭐⭐ | Next Greater Element | O(N) |
| 單調佇列 ⭐⭐ | 滑動視窗最大值 | O(N) |
| 爬樓梯與零錢 ⭐⭐ | 1D DP | O(N) / O(N·C) |
| Kadane演算法 ⭐⭐ | 最大子陣列和 | O(N) |
| 背包問題 ⭐⭐ | 0/1 Knapsack DP | O(N·W) |
| 最長遞增子序列 ⭐⭐ | LIS (DP+二分) | O(N log N) |
| 最長共同子序列 ⭐⭐ | LCS (2D DP) | O(N·M) |
| 練習題1：成績排序與查詢 ⭐ | 排序 + 排名查詢 | O(N log N + Q) |
| 練習題2：數字頻率統計 ⭐ | 計數排序 + 自訂排序 | O(N + K log K) |
| 練習題3：二分搜尋查詢 ⭐ | bisect_left/right | O((N+Q) log N) |
| 練習題4：區間合併覆蓋長度 ⭐⭐ | 排序 + 掃描合併 | O(N log N) |
| 練習題5：最多同時活動 ⭐⭐ | 掃描線（Sweep Line） | O(N log N) |
| 練習題6：最接近三數和 ⭐⭐ | 排序 + 雙指標 | O(N²) |

## 專題學習路徑

依 APCS 各級別建議學習順序：

### 初級
`05_遞迴/` → 基礎遞迴概念（ex1~ex3）
`06_排序與搜尋/` → 排序與自訂排序（ex1~ex3）

### 中級
`07_堆疊與佇列/` → Stack/Queue/Deque（ex1~ex3）
`08_動態規劃/` → 基礎 DP（ex1~ex2）
`06_排序與搜尋/` → 區間合併、二分搜尋（ex4~ex5）

### 中高級～高級
`08_動態規劃/` → 背包、LIS、LCS（ex3~ex5）
`07_堆疊與佇列/` → 單調堆疊、單調佇列（ex4~ex5）
`05_遞迴/` → Backtracking（ex4, ex10）

每支程式都包含：完整的**問題描述**、**演算法說明**、以及可直接執行的範例。
