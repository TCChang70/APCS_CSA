## 模擬考的準備與紀律

模擬考要「像真的」才有效：

| 準備 | 做法 |
| --- | --- |
| 時間 | 定時 120 分鐘，時間到就停筆 |
| 環境 | 只開一個瀏覽器（ZeroJudge）＋編輯器，關掉聊天、音樂 |
| 對答案 | 上傳 ZJ 或看題解，**如實記錄每題分數** |
| 心態 | 不查筆記、不看題解、不打電話問人 |

> 分數難看不重要，重點是找出「弱點主題」，回到 Day 2～Day 9 對應章節補強。

## 考場時間分配表

| 時段 | 動作 | 分配 |
| --- | --- | --- |
| 前 5 分鐘 | 快速掃過 4 題，標記「會/猶豫/不會」 | 5 分 |
| 第 1 題 | 直接解完＋上傳 | ≤ 25 分 |
| 第 2 題 | 直接解完＋上傳 | ≤ 25 分 |
| 第 3 題 | 先暴力拿分，再想優化 | ≤ 35 分 |
| 第 4 題 | 同上，做多少算多少 | ≤ 35 分 |
| 最後 10 分鐘 | 只做「檢查與補救」，不再挑戰新題 | 10 分 |

> 心法：**第 3、4 題卡住超過 15 分鐘就跳去下一題**，回頭再戰。別為了想不出的一題，放棄後面能拿的分數。

## 作答順序策略

1. **先掃描**：把 4 題的「輸入/輸出」讀一遍，依信心分級。
2. **由簡單到難**：先拿穩第 1、2 題（這是級分的基本盤）。
3. **暴力優先**：第 3、4 題如果一下子想不到好算法，先寫暴力版拿部分分、先上傳。
4. **優化有空再說**：小測資分數到手後，再挑戰大測資的優化。

> 金句：**APCS 是比誰分數高，不是比誰解法帥。拿到手的分數才是真的。**

### 讀題 S.O.P.

```
輸入格式 → 輸出格式 → 測資範圍（推複雜度） → 範例測資（用手算一遍）
```

## 提交前檢查清單

每題上傳前，照這個清單快速過一遍：

- [ ] 輸出格式：換行、空格數量、要不要多印東西？
- [ ] 邊界測資：0、最大值、負數、相等時誰優先？
- [ ] 變數型別：大數字會不會溢位？Python 不用怕溢位，但要注意「除法變浮點」。
- [ ] 索引範圍：`dp[n]`、`grid[n-1]`、`diff[r+1]` 會不會超界？
- [ ] 迴圈：會不會無限迴圈（while）？終止條件對嗎？
- [ ] 越界檢查：矩陣走訪有沒有 `0 <= i < n`？
- [ ] 用範例測資跑一遍，對照題目給的輸出。

### 常見「差一點」掉分原因

| 原因 | 對策 |
| --- | --- |
| 多一個空格/少一個換行 | 檢查 print 用 `end` 的地方 |
| 忘了最後一筆要結算 | 迴圈結束後補最後處理（Day 7 學過） |
| 題目 1 起算、程式 0 起算 | 讀入就統一，輸出時才 +1 |
| 大測資 TLE | 檢查是不是多層迴圈；優先換演算法 |

## 考前一夜與當天

### 考前一夜

- [ ] 不要再挑戰新難題，把「錯誤檢查表」與各 Day 的自我評量筆記讀一遍。
- [ ] 睡飽。睡眠不足直接扣分。

### 當天

- [ ] 提早 20 分鐘到場、確認身分與座位。
- [ ] 進場後先深呼吸，把「讀題 S.O.P.」在腦中過一遍。
- [ ] 考場只有 120 分鐘：先搶基本盤，別跟難題賭氣。

### 你的「考場速查筆記」（建議考前抄成紙條帶進考場）

```
1. 讀題：輸入 → 輸出 → 測資範圍
2. 前 5 分鐘分級 4 題，由易到難
3. 每題先暴力拿分，再優化
4. 卡關 15 分鐘就跳，回頭再戰
5. 留 10 分鐘檢查格式/邊界
6. 區間和 → 前綴和；最小化最大值 → 二分；最短 → BFS；全部可能 → DFS；選或不選 → DP
7. 週期 → %；前後比 → 字串走訪；字母計數 → 長度26陣列
```
