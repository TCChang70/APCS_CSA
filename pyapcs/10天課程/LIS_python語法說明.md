## 函式一：lis_dp 逐行解析

```python
def lis_dp(nums):          # 行 1：定義函式
    n = len(nums)           # 行 2：n = 陣列長度
    dp = [1] * n            # 行 3：dp 陣列，每個初始為 1
    for i in range(n):      # 行 4：外層，處理每個位置
        for j in range(i):  # 行 5：內層，回頭看 i 之前的元素
            if nums[j] < nums[i]:        # 行 6：嚴格遞增才接
                dp[i] = max(dp[i], dp[j] + 1)  # 行 7：更新 dp[i]
    return max(dp)          # 行 8：回傳最大值
```

### 行 2：`n = len(nums)`

| 語法 | 意義 |
|------|------|
| `len(nums)` | 內建函式，回傳串列長度 |
| `n = len(nums)` | 把長度存進變數 n |

例：`nums = [10, 9, 2, 5]` → `len(nums)` = 4 → `n = 4`

### 行 3：`dp = [1] * n`

```
[1] * n = 把 [1] 重複 n 次

n=4 → [1, 1, 1, 1]
```

| 部分 | 意義 |
|------|------|
| `[1]` | 只有單一元素 1 的串列 |
| `* n` | 重複 n 次 |
| 結果 | dp 陣列每個值都是 1 |

**為什麼初始是 1 不是 0？**
每個元素「自己一個人」就是長度 1 的遞增子序列，所以最小的答案也是 1。

### 行 4：`for i in range(n)`

```
range(4) → 0, 1, 2, 3
i = 0, 1, 2, 3
```

| 參數 | 意義 |
|------|------|
| `i` | 迴圈變數，代表「目前以哪個位置當結尾」 |
| `range(n)` | 產生 0 到 n-1 的數字 |

### 行 5：`for j in range(i)`

```
i=3 時：range(3) → 0, 1, 2
→ j = 0, 1, 2（只看 i 前面的元素）
```

**這行的關鍵語法**：`range(i)` 的上限是**變數 i**，所以每次外層迴圈跑，內層的範圍都不一樣！

| i | range(i) | j 會跑的值 |
|---|----------|-----------|
| 0 | range(0) | （空的，不跑） |
| 1 | range(1) | 0 |
| 2 | range(2) | 0, 1 |
| 3 | range(3) | 0, 1, 2 |

> `range(i)` 自然保證了 `j < i`，這就是為什麼迴圈裡不用另外寫 `j < i` 的判斷。

### 行 6：`if nums[j] < nums[i]`

| 語法 | 意義 |
|------|------|
| `nums[j]` | 用索引 j 取出陣列元素（前面的元素） |
| `nums[i]` | 用索引 i 取出陣列元素（目前的元素） |
| `<` | 嚴格小於 |
| `if ... :` | 條件成立才執行縮排內容 |

**意義**：前面的數比目前小，才能「接在後面」形成遞增。

例（nums=[10,9,2,5]，i=3，nums[3]=5）：

| j | nums[j] | 5 比它大？ | 能接嗎？ |
|---|---------|-----------|----------|
| 0 | 10 | 5 < 10? 否 | ✗ |
| 1 | 9 | 5 < 9? 否 | ✗ |
| 2 | 2 | 5 < 2? 否 | ✓（2 < 5） |

### 行 7：`dp[i] = max(dp[i], dp[j] + 1)`

```
dp[i] = max( dp[i],   dp[j] + 1 )
             ↑           ↑
        之前的答案    接在 j 後面（長度+1）
```

用實際數字代入（i=5，nums[5]=7，j=3，nums[3]=5，dp[3]=2）：

```
dp[5] = max(dp[5], dp[3] + 1)
      = max(1, 2 + 1)
      = max(1, 3)
      = 3
```

### 行 8：`return max(dp)`

| 語法 | 意義 |
|------|------|
| `max(dp)` | 回傳串列 dp 中最大的元素 |
| `return ...` | 把結果傳回給呼叫者 |

例：`dp = [1, 1, 1, 2, 2, 3]` → `max(dp)` = 3

> 為什麼不是 `return dp[n-1]`？
> LIS 可以以**任何位置**結尾，dp 最後一格不一定最大。所以要用 `max(dp)` 取全部的最大值。

## 函式二：lis_bs 逐行解析

```python
def lis_bs(nums):        # 行 1：定義函式
    tails = []           # 行 2：空的輔助陣列
    for v in nums:       # 行 3：依序處理每個數字
        lo, hi = 0, len(tails)   # 行 4：二元搜尋的上下界
        while lo < hi:           # 行 5：二元搜尋迴圈
            mid = (lo + hi) // 2 # 行 6：中間點
            if tails[mid] < v:   # 行 7：比較
                lo = mid + 1     # 行 8：往右半邊找
            else:
                hi = mid         # 行 9：往左半邊找
        if lo == len(tails):     # 行 10：位置在最後
            tails.append(v)      # 行 11：追加（延伸）
        else:
            tails[lo] = v        # 行 12：替換（保留彈性）
    return len(tails)            # 行 13：回傳長度
```

### 行 2：`tails = []`

| 語法 | 意義 |
|------|------|
| `[]` | 空的串列（list） |
| `tails = []` | 建立一個空陣列，之後逐步填 |

### 行 3：`for v in nums`

| 語法 | 意義 |
|------|------|
| `for v in nums` | **直接遍歷串列元素**，不用索引 |

`for v in nums` 和 `for i in range(len(nums))` 的差別：

| 寫法 | v 拿到什麼 | 需要索引時 |
|------|-----------|-----------|
| `for v in nums` | 每個元素的值 | 不方便（要用 enumerate） |
| `for i in range(len(nums))` | 索引 0,1,2... | 用 `nums[i]` 取值 |

這支函式只用到「值」，不需要索引 → 用 `for v in nums` 最簡潔。

### 行 4：`lo, hi = 0, len(tails)`

這行是**元組指派（Tuple Unpacking）**，一次設定兩個變數：

```python
lo, hi = 0, len(tails)
#   ↓        ↓
# lo=0    hi=len(tails)
```

等於：

```python
lo = 0
hi = len(tails)
```

| 變數 | 意義 |
|------|------|
| `lo` | 二元搜尋的下界（lower） |
| `hi` | 二元搜尋的上界（upper） |

### 行 5：`while lo < hi:`

| 語法 | 意義 |
|------|------|
| `while` | 迴圈，條件成立就一直重複 |
| `lo < hi` | 下界還沒追上上界就繼續 |

**while 迴圈 vs for 迴圈**：

| 型態 | 適用時機 |
|------|----------|
| `for` | 知道要跑幾次 |
| `while` | 不知道幾次，看條件決定 |

二元搜尋不知道要幾次，用 `while` 最自然。

### 行 6：`mid = (lo + hi) // 2`

| 語法 | 意義 |
|------|------|
| `//` | **整數除法**（不是浮點數除法 `/`） |
| `(lo + hi) // 2` | 取中間點（無條件捨去小數） |

`//` 和 `/` 的差別：

```python
print(7 / 2)    # 3.5  ← 浮點數
print(7 // 2)   # 3    ← 整數，小數直接捨去

# 索引必須是整數！所以用 //
print([10, 20, 30][7 // 2])   # [10,20,30][3] = 30 ✓
print([10, 20, 30][7 / 2])    # TypeError! 索引不能用 3.5
```

### 行 7：`if tails[mid] < v:`

| 語法 | 意義 |
|------|------|
| `tails[mid]` | 用索引 mid 取出中間位置的元素 |
| `< v` | 中間值比目前的數字小 |

**意義**：中間值小於 v → v 應該在右半邊，往右找。

### 行 8：`lo = mid + 1`

往右半邊找：把下界提高到 mid 右邊一格。

### 行 9：`hi = mid`

往左半邊找：把上界降到 mid（含），因為 `tails[mid] >= v`。

> 注意這裡是 `hi = mid` 而不是 `hi = mid - 1`！
> 因為 `tails[mid] >= v` 時，mid 本身可能就是答案位置，不能直接跳過。

### 行 10：`if lo == len(tails):`

| 語法 | 意義 |
|------|------|
| `lo` | 二元搜尋結束後，v 應該放的位置 |
| `len(tails)` | 陣列目前長度 |
| `lo == len(tails)` | 位置在「最後一個之後」 |

### 行 11：`tails.append(v)`

| 語法 | 意義 |
|------|------|
| `.append(v)` | 串列方法（method），把 v 加到陣列**尾端** |
| `tails.append(v)` | tails 尾巴加上 v |

例：

```python
tails = [2, 3]
tails.append(7)
# tails = [2, 3, 7]
```

### 行 12：`tails[lo] = v`

| 語法 | 意義 |
|------|------|
| `tails[lo]` | 指定索引 lo 的位置 |
| `= v` | 把該位置**覆蓋**成 v |
| 組合 | 用 v 取代 tails[lo] 原本的值 |

例：

```python
tails = [2, 5]
tails[1] = 3     # 把索引 1 的位置改成 3
# tails = [2, 3]
```

### 行 13：`return len(tails)`

`len(tails)` = tails 的長度 = LIS 長度。

## 二元搜尋語法專題

### 完整走一遍 while 迴圈（v=3, tails=[2,5]）

```
初始：tails=[2,5], lo=0, hi=2

第1圈：
  mid = (0+2)//2 = 1
  tails[1] = 5, 5 < 3? 否 → hi = 1
  （現在 lo=0, hi=1）

第2圈：
  mid = (0+1)//2 = 0
  tails[0] = 2, 2 < 3? 是 → lo = 1
  （現在 lo=1, hi=1）

lo == hi → while 停止
結果：lo = 1 → tails[1] = 3 → tails = [2, 3]
```

### 每次迴圈的 lo、hi、mid 追蹤表

| 圈數 | lo | hi | mid=(lo+hi)//2 | tails[mid] | 比較 | 動作後 lo, hi |
|------|-----|-----|----------------|-----------|------|---------------|
| 1 | 0 | 2 | 1 | 5 | 5<3? 否 | hi=1 → (0,1) |
| 2 | 0 | 1 | 0 | 2 | 2<3? 是 | lo=1 → (1,1) |
| 結束 | 1 | 1 | — | — | — | lo==hi，停止 |

### while 迴圈流程圖

```
        ┌─────────────┐
        │ lo=0, hi=n  │
        └──────┬──────┘
               ▼
        ┌─────────────┐     否
        │  lo < hi ?  ├──────────┐
        └──────┬──────┘          │
               │ 是              ▼
               ▼        ┌────────────────┐
      ┌────────────┐    │ 結束，lo = 答案 │
      │ mid=(lo+hi) │    └────────────────┘
      │      //2    │
      └──────┬──────┘
             ▼
   ┌────────────────────┐
   │ tails[mid] < v ?   │
   │  是→ lo=mid+1      │
   │  否→ hi=mid        │
   └────────────────────┘
             │
             └──回到「lo < hi?」判斷
```

## 實作驗證小抄

複製到互動式環境試試：

```python
# 驗證 len
print(len([10, 9, 2, 5]))          # 4

# 驗證串列重複
print([1] * 4)                     # [1, 1, 1, 1]

# 驗證 range(i) 隨 i 改變
for i in range(4):
    print(i, list(range(i)))
# 0 []
# 1 [0]
# 2 [0, 1]
# 3 [0, 1, 2]

# 驗證整數除法
print(7 // 2)                      # 3
print(7 / 2)                       # 3.5

# 驗證串列取值與覆蓋
tails = [2, 5]
print(tails[1])                    # 5
tails[1] = 3
print(tails)                       # [2, 3]

# 驗證 append
tails.append(7)
print(tails)                       # [2, 3, 7]

# 驗證 max
print(max([1, 1, 1, 2, 2, 3]))    # 3

# 自己跑 LIS DP
def lis_dp(nums):
    dp = [1] * len(nums)
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)

print(lis_dp([10, 9, 2, 5, 3, 7, 101, 18]))   # 4
```

## 常見語法錯誤檢查表

| 錯誤 | 後果 | 修正 |
|------|------|------|
| `mid = (lo + hi) / 2` 用 `/` | mid 是浮點數，`tails[mid]` TypeError | 用 `//` 整數除法 |
| `if nums[j] < nums[i]` 寫成 `<=` | 非嚴格遞增（相等也算），答案錯 | 嚴格遞增用 `<` |
| `return dp[n-1]` | LIS 不一定以最後位置結尾 | 用 `return max(dp)` |
| `dp = [1] * n` 寫成 `[0] * n` | 全部是 0，答案變 0 | 初始值設 1 |
| while 裡 `hi = mid - 1` | 跳過候選位置，答案錯 | `hi = mid`（含） |
| `tails[lo] = v` 忘了寫 | 只判斷不更新，白跑 | 別忘了覆蓋 |
| `for v in nums` 需要索引時用了它 | 拿不到索引 | 改用 `range(len(nums))` 或 `enumerate` |
