## 一、APCS 檢測基本資訊

### 1. 官網與檢測內容（新制）

| 選測科目 | 題數 | 時間 | 題本 |

## 三、10 天學習計畫

### Day 1｜認識檢測 + 環境與輸入輸出基本功

- **學習目標**：了解題目結構、得分規則；能流利使用 Python 讀取各種輸入並輸出。
- **語法重點**：`input()`、`.split()`、`int()`、`map(int, ...)`、`for i in range(n)`、`print()`、`sys.stdin`。
- **重點筆記**：
  - 實作題範例：先看「輸入格式」→「輸出格式」→「測資範圍」。
  - 用測資範圍推複雜度：Python 每秒約 10^7 次運算，超過容易逾時（TLE）。
  - 每題都要把「輸入輸出」先寫對再想演算法，格式錯誤 = 直接 0 分。
- **練習習題**：
  1. 寫一個程式：第一列 n，接下來 n 列各含 3 個數字，輸出每列的總和。
  2. ZeroJudge a001 哈囉、a002 簡易加法（熟悉 ZJ 上傳流程）。
  3. 學習資源：下載「PythAPCS123」（吳邦一）開頭第一章，照做範例。
- **自我評量**：不查筆記，10 分鐘內寫出「n 個數加總」與「多列輸入」各一版。

### Day 2｜條件判斷與迴圈：攻下第 1 題

- **學習目標**：能一次寫對 if/elif/else 與巢狀迴圈，處理「第 1 題」級模擬。
- **語法重點**：`if / elif / else`、`and or not`、巢狀 `for`、`range`、`%`（取餘數）、`//`（整數除法）。
- **重點筆記**：APCS 第 1 題通常「看懂題目就送分」，但要小心邊界條件（如 0、負數、相等時優先哪個）。
- **練習習題**（ZJ 題號，括號為主題）：
  1. q836 小心陷阱（2025/6，基礎模擬）
  2. q181 等紅綠燈（2025/1，條件＋迴圈）
  3. m931 遊戲選角（2024/1，排序＋條件）
  4. g275 七言對聯（2021/9，條件判斷）
  5. b964 成績指標（2016/3，迴圈＋陣列＋排序）
- **自我評量**：限時 30 分鐘做 q836 + q181，兩題皆一次通過。

### Day 3｜陣列與矩陣模擬：攻下第 2 題

- **學習目標**：熟練 1D/2D 陣列讀入、走訪、方向移動、累加統計。
- **語法重點**：`[[0]*m for _ in range(n)]`、`for i in range(n)`、`dirs = [(0,1),(0,-1),(1,0),(-1,0)]`、越界檢查。
- **重點筆記**：矩陣模擬題常見三招：① 直接照題目步驟模擬；② 用方向陣列走格子；③ 邊界檢查放進迴圈條件。先把「讀入矩陣」寫對。
- **練習習題**：
  1. o712 蒐集寶石（2024/10，陣列模擬）
  2. o077 電子畫布（2024/6，矩陣操作）
  3. m932 蜜蜂觀察（2024/1，矩陣走訪）
  4. k732 特殊位置（2023/6，矩陣統計）
  5. g596 動線安排（2021/11，模擬＋陣列）
- **自我評量**：限時 40 分鐘做 o712 + m932。

### Day 4｜字串處理

- **學習目標**：熟練字串的拆解、計數、比對、查表轉換。
- **語法重點**：`s[i]`、`len(s)`、`s.split()`、`''.join()`、`s.count()`、`ord()`/`chr()`、字串可走訪或轉成 list。
- **重點筆記**：字串題常結合「陣列計數」（用長度 26 的 list 數字母出現次數）。
- **練習習題**：
  1. q182 字串操作（2025/1，字串）
  2. o078 缺字問題（2024/6，字串＋集合）
  3. i400 字串解碼（2022/6，字串模擬）
  4. c290 秘密差（2017/3，字元處理）
  5. c462 交錯字串（2017/10，字串＋陣列）
- **自我評量**：限時 40 分鐘做 q182 + i400。

### Day 5｜排序、前綴和與查詢

- **學習目標**：用排序＋前綴和把「區間/查詢」問題變 O(1) 回答。
- **語法重點**：`list.sort()`、`sorted(list)`、`reverse=True`、前綴和陣列 `p[i]=p[i-1]+a[i]`、`bisect`/自寫二分。
- **重點筆記**：看到「多次查詢區間和」→ 想到前綴和；看到「很多對」→ 想到排序後兩指針。
- **練習習題**：
  1. g277 幸運數字（2021/9，前綴和）
  2. f581 圓環出口（2020/7，前綴和＋二分）
  3. g597 生產線（2021/11，排序＋差分）
  4. m370 機械鼠（2023/10，排序＋找規律）
- **自我評量**：限時 40 分鐘做 g277 + f581。

### Day 6｜暴力法、枚舉與二分搜尋

- **學習目標**：先能寫「暴力解」拿部分分，再學二分搜把複雜度降下來。
- **語法重點**：巢狀迴圈列舉、遞迴枚舉（選/不選）、`while l < r:` 二分模板、`mid = (l+r)//2`。
- **重點筆記**：APCS 採部分給分，**先寫暴力再優化**是重要策略；「最小化最大值」類題幾乎都是二分＋驗證。
- **練習習題**：
  1. j125 蓋步道（2022/10，二分＋BFS）★★
  2. i401 雷射測試（2022/6，二分＋模擬）★★
  3. h084 牆上海報（2022/1，二分搜）★★
  4. d007 子集合的和（2018/10，遞迴枚舉）
- **自我評量**：限時 50 分鐘做 i401；看題解前先自己寫出二分框架。

### Day 7｜貪心演算法（greedy）

- **學習目標**：學會「排序後照規則取」的典型貪心套路，並能說明為什麼可行。
- **語法重點**：`sorted(items, key=lambda x: x[1])`、自訂排序規則。
- **重點筆記**：常見套路＝區間排程（照結束時間排）、加權排序（照比值排）、覆蓋問題（照起點排）。
- **練習習題**：
  1. q838 貪心闖關（2025/6，貪心）
  2. c471 物品堆疊（2017/10，加權排序＋貪心）★★
  3. b966 線段覆蓋長度（2016/3，排序＋貪心）★★
  4. c575 基地台（2017/3，貪心＋二分）★★★
- **自我評量**：限時 50 分鐘做 q838 + b966。

### Day 8｜遞迴、DFS / BFS、樹與圖

- **學習目標**：看懂遞迴；能寫 DFS（含樹上走訪）與 BFS（含佇列）；判斷題目是樹還是圖。
- **語法重點**：`def dfs(u): ... 遞迴呼叫`、`visited` 陣列、`collections.deque`、`while queue:`、`queue.popleft()`。
- **重點筆記**：樹＝無環連通圖，用 DFS 從根走一遍；圖用 BFS 找最短步數；「連鎖反應/擴散」類題 = DFS 或 BFS。
- **練習習題**：
  1. o713 連鎖反應（2024/10，遞迴/DFS）
  2. m933 邏輯電路（2024/1，拓樸/DFS）★★
  3. j124 石窟探險（2022/10，樹＋DFS）★★
  4. c463 樹狀圖分析（2017/10，樹＋DFS）★★
  5. b967 血緣關係（2016/3，樹＋DFS）
  6. f166/d094 闖關路線（2019/10，BFS＋佇列）★★
- **自我評量**：限時 60 分鐘做 o713 + j124。

### Day 10｜綜合模擬考 + 考場策略

- **學習目標**：在 120 分鐘內完成一整份最近期考卷，練習時間分配。
- **模擬考**（擇一，全程計時、不中斷）：
  1. 2025/6 全卷：q836（小心陷阱）、q837（轉盤得分）、q838（貪心闖關）、q839（分組遊戲）
  2. 2024/10 全卷：o711（裝飲料）、o712（蒐集寶石）、o713（連鎖反應）、o714（搭到終點）
  3. 2024/6 全卷：o076（特技表演）、o077（電子畫布）、o078（缺字問題）、o079（最佳選擇）
- **考場策略 Checklist**：
  - [ ] 先花 5 分鐘掃過所有題目，決定作答順序（簡單先拿）。
  - [ ] 每題先寫暴力版拿部分分，再考慮優化。
  - [ ] 時間分配：第 1、2 題各 25 分鐘，第 3、4 題各 35 分鐘，留 10 分鐘檢查。
  - [ ] 提交前檢查：輸出格式（空白/換行）、邊界（0、最大值、負數）、變數型別。
  - [ ] 卡關超過 15 分鐘就跳過，回頭再做。
- **自我評量**：統計模擬考各題得分，找出弱點主題，回到 Day 2～Day 9 對應章節複習。
