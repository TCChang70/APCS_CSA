# APCS 動態規劃練習說明（含推導過程與完整解法）

本文件搭配 [APCS動態規劃_練習程式.py](APCS動態規劃_練習程式.py) 使用。

## 使用流程

1. 先看題目敘述，**不看解法先自己寫**。
2. 對照「狀態 State / 轉移 Transition / 初始化 Base Case / 複雜度」。
3. 完成後做「動手練習」變體題。
4. 最後做「快速複習檢核」。

> 建議計時：初級 5 分鐘、中級 10 分鐘、中高級 15 分鐘

## DP 通用解題模板（四步法）

遇到任何 DP 題目，先依序回答以下四個問題：

| 步驟 | 問題 | 說明 |
|------|------|------|
| 1. 狀態 | `dp[i]` 代表什麼？ | 用一句話定義每個狀態的意義 |
| 2. 轉移 | `dp[i]` 怎麼算？ | 從哪些前驅狀態推導出來 |
| 3. 初始 | 邊界條件是什麼？ | `dp[0]`、`dp[1]` 等初始值 |
| 4. 順序 | 迴圈怎麼跑？ | 確保算 `dp[i]` 時，依賴的狀態都已經算好 |

### 題目 1：爬樓梯 Climbing Stairs

**題目**：一次可走 1 或 2 階，問到第 n 階共有幾種方法？

```
輸入：n = 5
輸出：8
解釋：1+1+1+1+1, 1+1+1+2, 1+1+2+1, 1+2+1+1, 2+1+1+1, 1+2+2, 2+1+2, 2+2+1
```

**推導過程**：

```
手算小規模：
  n=1: 1 種  {1}
  n=2: 2 種  {1+1, 2}
  n=3: ? 從第 2 階走 1 步 + 從第 1 階走 2 步 = dp[2] + dp[1] = 2+1 = 3
  n=4: dp[3] + dp[2] = 3+2 = 5

結論：dp[i] = dp[i-1] + dp[i-2]
本質就是費氏數列！
```

| 項目 | 內容 |
|------|------|
| **狀態** | dp[i] = 到第 i 階的方法數 |
| **轉移** | dp[i] = dp[i-1] + dp[i-2] |
| **初始** | dp[1]=1, dp[2]=2 |
| **時間** | O(N) |
| **空間** | O(1)（只保留前兩項） |

完整解法：`p1_climb_stairs`，空間壓縮只用兩個變數 `a, b`。

**常見錯誤**：
- n=0 時應回傳 1（或依題意），別忘了邊界
- 忘了處理 n<=2 的情況

### 題目 2：最少硬幣數 Coin Change

**題目**：給定硬幣面額 coins 和金額 amount，求湊出 amount 的最少硬幣數。無法湊出回傳 -1。

```
輸入：coins = [1, 2, 5], amount = 11
輸出：3（5 + 5 + 1）
```

**推導過程**：

```
手算小規模（coins=[1,2,5]）：
  dp[0] = 0   （0 元用 0 個硬幣）
  dp[1] = 1   （用 1 個 1 元）
  dp[2] = 1   （用 1 個 2 元）
  dp[3] = 2   （2+1 或 1+1+1，最少 2 個）
  dp[4] = 2   （2+2）
  dp[5] = 1   （1 個 5 元）
  dp[6] = 2   （5+1）
  dp[11] = dp[11-5]+1 = dp[6]+1 = 3

關鍵：每算 dp[x]，嘗試所有硬幣 c：
  dp[x] = min(dp[x-c] + 1) for c in coins
```

| 項目 | 內容 |
|------|------|
| **狀態** | dp[x] = 湊出金額 x 的最少硬幣數 |
| **轉移** | dp[x] = min(dp[x-c] + 1) for c in coins |
| **初始** | dp[0]=0，其餘設 INF（不可達） |
| **時間** | O(amount x len(coins)) |
| **空間** | O(amount) |

**常見錯誤**：
- 初始值設成 0 會導致 min 判斷永遠是 0
- 忘記最後判斷 `dp[amount] == INF` 時回傳 -1

### 題目 3：最大連續子陣列和 Kadane

**題目**：找連續子陣列的最大總和。

```
輸入：[-2, 1, -3, 4, -1, 2, 1, -5, 4]
輸出：6（子陣列 [4, -1, 2, 1]）
```

**推導過程**：

```
關鍵問題：以位置 i 結尾的最大和是多少？

  i=0: [-2]            -> -2（只能選自己）
  i=1: [-2,1] 或 [1]   -> max(-2+1, 1) = 1
  i=2: [1,-3] 或 [-3]  -> max(1-3, -3) = -2
  i=3: [-2,4] 或 [4]   -> max(-2+4, 4) = 4
  ...

轉移：dp[i] = max(nums[i], dp[i-1] + nums[i])
意義：「延續前一段」vs「從自己重新開始」
     前者代表把當前元素接在之前的子陣列後
     後者代表之前的子陣列負擔太重，不要了
```

| 項目 | 內容 |
|------|------|
| **狀態** | dp[i] = 以 i 結尾的最大和 |
| **轉移** | dp[i] = max(nums[i], dp[i-1] + nums[i]) |
| **初始** | dp[0] = nums[0] |
| **時間** | O(N) |
| **空間** | O(1) |

**進階**：`p3b_kadane_with_indices` 同時追蹤起訖索引。關鍵是在 `cur` 重設時更新 `temp_start`。

### 題目 4：0/1 背包 Knapsack

**題目**：N 個物品各有重量和價值，背包容量 W，每個物品最多選一次，求最大價值。

```
輸入：weights=[2,3,4,5], values=[3,4,5,6], capacity=5
輸出：7（選物品 1(w=2,v=3) 和物品 2(w=3,v=4)）
```

**推導過程**：

```
先想 2D 版本：
  dp[i][w] = 前 i 個物品、容量 w 時的最大價值
  dp[i][w] = max(dp[i-1][w],                    不選第 i 個
                 dp[i-1][w-w[i]] + v[i])        選第 i 個

空間壓縮為 1D：
  dp[w] 只依賴「上一列」的 dp 值
  關鍵：從大到小更新 w！
  如果從小到大：dp[w] 會用到「本輪」的 dp[w-w[i]]，等於物品被重複選

  w=5, w[0]=2:
    倒序：dp[5] 用 dp[3]（上一輪的舊值） -> 正確 ✓
    正序：dp[5] 用 dp[3]（本輪可能已更新）-> 錯誤 ✗
```

| 項目 | 內容 |
|------|------|
| **狀態** | dp[w] = 容量 w 時的最大價值 |
| **轉移** | dp[w] = max(dp[w], dp[w-w[i]] + v[i]) |
| **初始** | 全部 0 |
| **時間** | O(N x W) |
| **空間** | O(W) |
| **順序** | 0/1 背包**倒序**、無限背包**正序** |

**0/1 vs 無限背包的差異**：

```
0/1 背包（每物品最多一次）：
  for w in range(W, weights[i]-1, -1):  # 倒序

無限背包（每物品可無限次）：
  for w in range(weights[i], W+1):      # 正序
```

### 題目 5：最長遞增子序列 LIS

**題目**：找最長嚴格遞增子序列長度（不要求連續）。

```
輸入：[10, 9, 2, 5, 3, 7, 101, 18]
輸出：4（例如 [2, 3, 7, 101] 或 [2, 5, 7, 101]）
```

**推導過程（O(N^2) DP）**：

```
dp[i] = 以 nums[i] 結尾的 LIS 長度

  nums:  10   9   2   5   3   7  101  18
  dp:     1   1   1   2   2   3    4   4

  dp[4]=3：nums[4]=5，前面有 2<5，dp[4]=dp[2]+1=2
  dp[6]=7：nums[6]=7，前面 2<7(dp=1+1=2), 3<7(dp=2+1=3), 5<7(dp=2+1=3) -> max=3
  dp[7]=101：前面所有 <101 的都能接 -> max(dp[j])+1 = 4
```

**推導過程（O(N log N) tails + 二分搜）**：

```
tails[k] = 長度 k+1 的遞增子序列中，最小的結尾值

逐個處理 nums：
  10: tails = [10]
   9: tails = [9]          （替換，9 比 10 小，未來更容易延伸）
   2: tails = [2]          （替換）
   5: tails = [2, 5]       （延伸，長度 2）
   3: tails = [2, 3]       （替換 5，3<5 更好）
   7: tails = [2, 3, 7]    （延伸，長度 3）
 101: tails = [2, 3, 7, 101]（延伸，長度 4）
  18: tails = [2, 3, 7, 18] （替換 101）

答案 = len(tails) = 4
```

| 項目 | O(N^2) DP | O(N log N) tails |
|------|-----------|-------------------|
| **時間** | O(N^2) | O(N log N) |
| **空間** | O(N) | O(N) |
| **适用** | N <= 5000 | N <= 10^5 |

**陷阱**：tails 不是 LIS 本身！tails 只是用來維持「最小結尾」狀態。

### 題目 6：最長共同子序列 LCS

**題目**：給兩字串 a, b，求最長共同子序列長度（不要求連續）。

```
輸入：a = "ABCBDAB", b = "BDCAB"
輸出：4（例如 "BCAB" 或 "BDAB"）
```

**推導過程**：

```
2D DP 表（列=a, 行=b）：

      ""  B  D  C  A  B
  ""   0  0  0  0  0  0
   A   0  0  0  0  1  1
   B   0  1  1  1  1  2
   C   0  1  1  2  2  2
   B   0  1  1  2  2  3
   D   0  1  2  2  2  3
   A   0  1  2  2  3  3
   B   0  1  2  2  3  4

規則：
  若 a[i-1] == b[j-1]：dp[i][j] = dp[i-1][j-1] + 1  （對角線+1）
  否則：dp[i][j] = max(dp[i-1][j], dp[i][j-1])       （取上或左的最大值）
```

| 項目 | 內容 |
|------|------|
| **狀態** | dp[i][j] = a[:i] 與 b[:j] 的 LCS 長度 |
| **轉移** | 相同→對角線+1；不同→max(上, 左) |
| **初始** | dp[0][*] = dp[*][0] = 0 |
| **時間** | O(N x M) |
| **空間** | O(min(N,M))（1D 壓縮） |

**1D 壓縮的關鍵**：用 `prev_diag` 暫存左上角的舊值，避免被覆蓋。

**常見混淆**：
- LCS（子序列）不等於最長共同子字串（子字串必須連續）
- 若要回傳 LCS 字串本身，需用 2D 表從右下角回溯

### 題目 7：編輯距離 Edit Distance

**題目**：將 word1 轉換成 word2，每次可插入、刪除或替換一個字元，求最少操作數。

```
輸入：word1 = "horse", word2 = "ros"
輸出：3
解釋：h→(刪除)r→(刪除)o→(替換為)r→(刪除)s → 3 步
```

**推導過程**：

```
dp[i][j] = word1[:i] 轉為 word2[:j] 的最少步數

      ""  r  o  s
  ""   0  1  2  3
   h   1  1  2  3
   o   2  2  1  2
   r   3  2  2  2
   s   4  3  3  2
   e   5  4  4  3

轉移（三種操作取最小）：
  dp[i][j] = dp[i-1][j-1]              若 word1[i-1] == word2[j-1]
  dp[i][j] = 1 + min(
      dp[i-1][j],      // 刪除 word1[i-1]
      dp[i][j-1],      // 插入 word2[j-1]
      dp[i-1][j-1]     // 替換 word1[i-1] 為 word2[j-1]
  )

初始：dp[i][0] = i（全刪），dp[0][j] = j（全插）
```

| 項目 | 內容 |
|------|------|
| **狀態** | dp[i][j] = word1[:i] 轉為 word2[:j] 的最少操作數 |
| **轉移** | 相同→不操作；不同→1 + min(刪除, 插入, 替換) |
| **初始** | dp[i][0]=i, dp[0][j]=j |
| **時間** | O(N x M) |
| **空間** | O(min(N,M))（1D 壓縮） |

### 題目 8a：分割等和子集 Partition Equal Subset Sum

**題目**：判斷能否將 nums 分成兩個總和相等的子集。

```
輸入：[1, 5, 11, 5]
輸出：True（[1, 5, 5] 和 [11]，總和都是 11）
```

**推導過程**：

```
本質是子集和問題：
  總和為 total，若 total 為奇數直接 False
  否則找能否湊出 total/2

dp[s] = 能否用某些元素湊出總和 s

  nums=[1,5,11,5], target=11

  初始：dp[0]=True
  加入 1：dp[1]=True
  加入 5：dp[1]=T, dp[5]=T, dp[6]=T（1+5）
  加入 11：dp[11]=T
  加入 5：dp[5]=T, dp[6]=T, dp[10]=T(5+5), dp[11]=T, dp[12]=T(1+5+5+1)...(略)

  dp[11] = True -> 可以分割
```

| 項目 | 內容 |
|------|------|
| **狀態** | dp[s] = 能否湊出總和 s |
| **轉移** | dp[s] = dp[s] or dp[s - num] |
| **初始** | dp[0]=True，其餘 False |
| **時間** | O(N x sum/2) |
| **空間** | O(sum/2) |

**注意**：必須倒序更新 s，否則同一個 num 會被重複使用（和 0/1 背包一樣）。

## 動手練習

做完上面的基本題後，嘗試以下變體：

| # | 題目 | 關鍵提示 |
|---|------|----------|
| 1 | 爬樓梯：一次走 1、2、3 階 | dp[i] = dp[i-1] + dp[i-2] + dp[i-3] |
| 2 | 零錢組合數（不限個數） | 注意迴圈順序：先物品後金額 |
| 3 | 回傳 Kadane 的起訖索引 | 追蹤 temp_start |
| 4 | 無限背包 | 改為正序更新 |
| 5 | 回傳 LCS 字串 | 2D 表 + 回溯 |
| 6 | 分割兩子集最小差 | 湊到最接近 total/2 的 s，回傳 total-2s |

## APCS 考場速查表

```
看到「最值」、「方案數」、「可行性」+ 「重疊子問題」？
  -> 可能是 DP

1. 1D DP：爬樓梯、硬幣、Kadane
   -> dp[i] 依賴前 1~2 個

2. 2D DP：背包、LCS、編輯距離
   -> dp[i][j] 依賴 dp[i-1][j], dp[i][j-1], dp[i-1][j-1]

3. 特殊技巧：LIS 用 tails + 二分搜
   -> O(N^2) 先寫對，再升級 O(N log N)
```
