## 讀題三步驟

拿到任何一題，先照這個順序看，不要急著寫：

1. **輸入格式**：有幾列？每列幾個數字？是整數還是字串？要不要先讀 n（數量）？
2. **輸出格式**：印一列還是多列？用空格隔開還是換行？有沒有特殊格式要求？
3. **測資範圍**：數字最多多大？n 最多多少？→ 用這個推演算法要多快。

> 金句：**「輸入輸出」先寫對再想演算法。輸出格式錯一題就是整題 0 分，比想不出演算法還冤枉。**

### 測資範圍 → 複雜度判斷表

| n 的最大值 | 複雜度最多到 | 代表算法 |
| --- | --- | --- |
| ≤ 1000 | O(N²) | 雙層迴圈 |
| ≤ 10^5 | O(N log N) | 排序、二分 |
| ≤ 10^6 | O(N) 或 O(N log N) | 單層迴圈、前綴和 |
| ≤ 10^9 | O(log N) | 二分搜、數學公式 |

Python 每秒約能跑 10^7 次運算，超過就容易「逾時」（TLE）。

## Python 輸入輸出語法速覽

### 1. `input()` 讀一列（含換行）

```python
# input() 讀一整列文字（包含使用者按 Enter），回傳的一定是「字串」
s = input()
# 例：螢幕輸入 42，s 拿到的是 "42"（字串），不是數字 42
# 之後要做數學運算，必須先 int(s) 轉成整數才行
```

### 2. `split()` 把一列切成多段

```python
# input().split()：把剛讀進來的那一列，依「空白」切成一格一格
# 回傳的是「字串串列」（每個元素仍是字串，不是數字）
row = input().split()
# 例：輸入 "10 20 30" → row = ['10', '20', '30']
```

### 3. `int()` 把字串轉整數

```python
# int()：把「字串」轉成「整數」，才能做加減乘除
x = int(input())          # 例：輸入 "42" → x = 42（整數）
a = int("10")             # 字串 "10" → 整數 10
```

### 4. `map(int, ...)` 一次轉一整列

```python
# map(int, ...)：把串列裡的「每個字串」依序轉成整數
# list(...)：把轉好的結果打包成「整數串列」才能存取
nums = list(map(int, input().split()))
# 執行過程：input().split() → ['5','8','13'] → map(int,...) → [5,8,13]

# 若這一列「剛好只有兩個數」，可以直接拆給兩個變數（不用 list）
a, b = map(int, input().split())
# 例：輸入 "3 7" → a = 3、b = 7
```

### 5. 先讀 n，再用迴圈讀 n 列

```python
n = int(input())           # 第一列的 n：告訴你「等一下還有 n 列輸入」
for i in range(n):         # 迴圈重複 n 次，i 依序等於 0,1,2,...,n-1
    line = input()         # 每次迴圈讀「一列」，存進 line
                           # 這就是「多列輸入」的標準骨架
```

### 6. 加速讀法：`sys.stdin`

測資很大時，`input()` 會偏慢，改用：

```python
import sys
# sys.stdin.read()：一次讀「整份測資」（所有列），不分列
# .split()：把所有空白（含換行）當分隔，切成一串文字
# 結果 data = ['5', '8', '13', ...]（整份測資的全部數字）
data = sys.stdin.read().split()
# 之後依序拿：data[0]、data[1]、...
# 要用數字時再轉型：int(data[i])
# 優點：只呼叫一次 I/O，測資很大時比逐列 input() 快很多，避免 TLE
```

### 7. `print()` 輸出

```python
print(x)              # 印出 x 的值，印完自動換行
print(x, y)           # 同時印兩個值，兩者中間自動用「一個空格」隔開
print(x, end=' ')     # end 參數決定「結尾」；預設是 '\n'（換行），改成 ' ' 就不換行
```

### 語法速查表

| 想做的事 | 寫法 |
| --- | --- |
| 讀一個整數 | `int(input())` |
| 讀一列整數串列 | `list(map(int, input().split()))` |
| 讀兩個整數 | `a, b = map(int, input().split())` |
| 讀 n 列 | `for _ in range(n): input()` |
| 印出並換行 | `print(x)` |
| 印出用空格隔開 | `print(*arr)` |

## 三個標準範例逐行拆解

### 範例 1：n 個數加總

> 輸入：第一列 n，第二列有 n 個數字。輸出：這 n 個數的總和。

```python
# 行1：讀 n（第一列只有一個數，代表有幾個數字要加）
n = int(input())              # int() 把字串 "5" 轉成整數 5

# 行2：把第二列整列讀進來，切成字串、逐個轉 int，存成整數串列
nums = list(map(int, input().split()))
# 例：輸入 "1 2 3 4 5" → nums = [1, 2, 3, 4, 5]
# （n 已經告訴我們有 5 個數，但實務上直接整列讀進來即可）

# 行3：sum(nums) 用內建函式把串列全部加總，再 print 印出
print(sum(nums))              # → 15
```

| 行 | 語法 | 意義 |
| --- | --- | --- |
| 1 | `int(input())` | 第一列只有一個數 n，直接轉 int |
| 2 | `input().split()` | 把第二列切開成字串 |
| 2 | `map(int, ...)` | 每個字串轉 int |
| 2 | `list(...)` | 轉成串列才能存 |
| 3 | `sum(nums)` | 內建加總函式 |

### 範例 2：n 列，每列 3 個數字，輸出每列總和

> 這是「多列輸入」最常見的長相，一定要練熟。

```python
n = int(input())                  # 行1：讀 n，代表「接下來共有 n 列」
for i in range(n):                # 行2：迴圈執行 n 次，i = 0,1,...,n-1
    # 行3：每列剛好 3 個數 → 用 map 轉成整數後，直接拆給 a、b、c
    a, b, c = map(int, input().split())
    # 例：這列輸入 "1 2 3" → a=1、b=2、c=3
    print(a + b + c)              # 行4：這 3 個數相加後印出（自動換行）
```

### 範例 3：讀入 n × m 矩陣

> 輸入：第一列 n、m，接著 n 列、每列 m 個數字。存進二維串列 `grid`。

```python
n, m = map(int, input().split())         # 行1：第一列兩個數 → n 列、m 行
grid = []                                # 行2：先準備一個「空的二維串列」來裝每一列
for i in range(n):                       # 行3：迴圈跑 n 次，逐列讀入
    row = list(map(int, input().split()))   # 行4：這一列 m 個數讀成一個一維串列 row
    grid.append(row)                     # 行5：把 row 掛到 grid 的「最後面」
# 讀完後：grid = [第一列, 第二列, ..., 第 n-1 列]
# 之後要用哪一格，就寫 grid[i][j] → 第 i 列、第 j 行的數字（0 起算）
```

| 語法 | 意義 |
| --- | --- |
| `grid.append(row)` | 把 row 加進 grid 最後面 |
| `grid[i][j]` | 二維索引：先取第 i 列，再取第 j 行 |

### 重要陷阱：二維串列別這樣建！

```python
# ❌ 錯誤寫法：n 列「共用同一條」串列，改一格全部跟著變！
# 原因：[0]*m 先做出 1 條，再 *n 只是把「同一條」的參考重複 n 次
grid = [[0] * m] * n

# ✅ 正確寫法：用「產生器寫法」，每一列都是獨立建出來的新串列
# for _ in range(n)：產生器重複 n 次，每次各自做 [0]*m
grid = [[0] * m for _ in range(n)]
# 例：n=2、m=3 → [[0,0,0],[0,0,0]]，改 grid[0][0]=5 不會影響 grid[1]
```

> 用 `[0]*m` 建立一列很安全；但再用 `* n` 複製會讓 n 列都指向「同一條」串列。要各列獨立，用「產生器寫法」`[[0]*m for _ in range(n)]`。

## 常見錯誤檢查表

| # | 錯誤 | 為什麼錯 | 修正 |
| --- | --- | --- | --- |
| 1 | `nums = input().split()` 後直接算 | split 出來是字串，不能做數學 | 先 `map(int, ...)` |
| 2 | 只寫一個 `input()` 在迴圈外面 | 只讀到第一列 | 用 `for` 迴圈讀滿 n 列 |
| 3 | 忘了讀 n 就直接假設列數 | 每列內容長度可能不同 | 依題目要求先讀 n 或 `sys.stdin` |
| 4 | `[[0]*m]*n` 建矩陣 | n 列共用同一條串列 | 用 `[[0]*m for _ in range(n)]` |
| 5 | `print(x, y)` 想要他們在同一欄 | 預設會用空格隔開 | 預期就是空格就用它；要分行就分兩次 print |
| 6 | 測資很大還用 `input()` | 慢 → TLE | 用 `sys.stdin.read().split()` |

### 練習 1：n 個數加總（上傳練習）

> 輸入：第一列 n；第二列 n 個整數。輸出：總和。

```python
n = int(input())                             # 第一列 n：告訴我們有幾個數字
nums = list(map(int, input().split()))       # 第二列整列讀成整數串列
print(sum(nums))                             # 內建 sum() 加總後印出
```

### 練習 2：每列三數總和

> 輸入：第一列 n；接下來 n 列，每列 3 個整數。輸出：每列總和，一列一個。

```python
n = int(input())                 # n 列輸入
for i in range(n):               # 逐列處理，共 n 次
    a, b, c = map(int, input().split())   # 每列 3 個數拆給 a、b、c
    print(a + b + c)             # 印出這列的總和
```

### 練習 4：矩陣最大值與位置

> 輸入：第一列 n、m；接下來 n 列、每列 m 個整數。輸出：最大值 與 它所在的列、行（0 起算）。

```python
n, m = map(int, input().split())   # 讀列數 n、行數 m
best = -10**18                     # 目前最大值先設成「極小值」，保證第一次比較就會更新
                                   # -10**18 約等於 -1000000000000000000（比任何測資都小）
bi = bj = 0                        # 記錄最大值所在位置（先給個預設值）
for i in range(n):                 # 走訪每一列
    row = list(map(int, input().split()))   # 讀這一列的 m 個數字
    for j in range(m):             # 走訪這一列每一行
        if row[j] > best:          # 發現「更大的數」就更新最大值與位置
            best = row[j]
            bi, bj = i, j          # 記下所在「列 i、行 j」（0 起算）
print(best, bi, bj)                # 依序印出：最大值、所在列、所在行
```

作答完再對照下方解答。

<details>
<summary>解答（先自己寫再打開）</summary>

```python
# 題1：n 個數加總（一行寫法）
n = int(input())                              # 第一列 n（此處其實沒用到，只是照題目讀）
print(sum(map(int, input().split())))         # 第二列直接轉 int、加總、印出
                                              # sum() 吃「迭代器」即可，不一定要 list()

# 題2：主對角線（grid[i][i]）總和
n = int(input())                              # 讀 n：n×n 方形矩陣
grid = []                                     # 空的二維串列
for i in range(n):                            # 逐列讀入
    grid.append(list(map(int, input().split())))   # 每列讀成串列，掛進 grid
ans = 0                                       # 總和初始為 0
for i in range(n):                            # 主對角線：第 0 列第 0 行、第 1 列第 1 行……
    ans += grid[i][i]                         # 累加「列號 = 行號」的那一格
print(ans)                                    # 印出主對角線總和
```
