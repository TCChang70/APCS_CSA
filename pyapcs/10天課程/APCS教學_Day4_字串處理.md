## 字串的基礎操作

```python
s = "hello"          # 用雙引號建立字串（單引號 'hello' 也可以）

s[0]                 # 用索引取值：'h'（索引 0 起算，就像 list 一樣）
s[-1]                # 負索引取最後一個：'o'
len(s)               # 長度（有幾個字元）：5
"he" in s            # in 運算子：子字串「he」是否存在於 s → True
s + "!"              # + 是「接合」：產生新字串 "hello!"（原字串不變）
```

| 操作 | 語法 | 例子 |
| --- | --- | --- |
| 取字元 | `s[i]` | `"abc"[1]` → `'b'` |
| 長度 | `len(s)` | `len("abc")` → 3 |
| 切片 | `s[a:b]` | `"abcde"[1:4]` → `"bcd"` |
| 拆開 | `s.split()` | `"a b c".split()` → `['a','b','c']` |
| 拆指定字元 | `s.split(',')` | `"1,2,3".split(',')` → `['1','2','3']` |
| 接起來 | `''.join(list)` | `''.join(['a','b'])` → `"ab"` |
| 數次數 | `s.count('a')` | `"banana".count('a')` → 3 |
| 反轉 | `s[::-1]` | `"abc"[::-1]` → `"cba"` |

> **字串不可改**：`s[0] = 'x'` 會報錯。要「修改」字串，改成轉成 list 再改，最後 join 回來：

```python
arr = list(s)       # 把字串拆成「字元串列」："abc" → ['a','b','c']
arr[0] = 'x'        # 串列可以修改：arr → ['x','b','c']
s2 = ''.join(arr)   # ''.join()：把串列元素「用空字串接起來」還原成字串 → "xbc"
                    # （若用 ' ' 就是「用空格接」、用 '-' 就是「用 - 接」）
```

## 走訪字串的三種方式

```python
# 方式1：直接拿字元（最常用）
for ch in s:          # ch 依序等於 s 的每個字元
    print(ch)         # 依序印出 h e l l o

# 方式2：拿「位置」，再用位置取字元（需要前後比對時用）
for i in range(len(s)):   # i = 0,1,...,len(s)-1
    print(i, s[i])        # 印出「位置 i」和「該位置的字元」

# 方式3：位置＋字元一起拿（enumerate）
for i, ch in enumerate(s):   # enumerate 同時回傳「位置 i」與「字元 ch」
    print(i, ch)
```

> 需要「前後比對」時用方式 2；只需要依序處理每個字元時用方式 1。

### 前後比對的經典骨架

```python
# 檢查「相鄰」兩字元是否相同
for i in range(len(s) - 1):   # 只跑到倒數第二個位置，這樣 i+1 才不會超界
    if s[i] == s[i + 1]:      # 目前字元 與 下一個字元 比較
        print("相同", i, i + 1)
# 例：s = "aabb" → i=1 時 s[1]=='a'、s[2]=='b' 不相同；i=2 時 s[2]=='b'、s[3]=='b' 相同
```

## 字母計數：長度 26 陣列

「每個英文字母出現幾次」是超常見的子題。用長度 26 的整數陣列當計數器：

```python
cnt = [0] * 26                 # 長度 26 的計數器：cnt[0] 記 a 幾次、cnt[1] 記 b 幾次……
for ch in s:                   # 走訪字串的每個字元
    idx = ord(ch) - ord('a')   # 把 'a'~'z' 換算成 0~25 的編號
                               # 例：ord('a')-ord('a')=0、ord('b')-ord('a')=1、ord('z')-ord('a')=25
    cnt[idx] += 1              # 對應的計數器加 1
# 印出 a~z 各出現幾次：
for i in range(26):
    print(chr(ord('a') + i), cnt[i])   # chr 把編號還原成字母（0→'a'、1→'b'…）
```

| 語法 | 意義 |
| --- | --- |
| `ord(ch)` | 字元 → 數字（'a' 是 97） |
| `ord('a')` | 97 |
| `ord(ch) - ord('a')` | 把 'a'~'z' 變成 0~25 |
| `chr(n)` | 數字 → 字元（97 → 'a'） |
| `chr(ord('a') + i)` | i → 對應字母 |

> 記憶口訣：**`ord` 進數字、`chr` 出字元，`ord(ch) - ord('a')` 做編號。**

### 常用變化

```python
cnt[ord(c) - ord('A')]        # 大寫字母版：改用 ord('A') 當基準，'A'→0、'B'→1……
cnt[int(c)]                   # 當 c 是數字字元（'0'~'9'）時，直接 int(c) 轉成 0~9 當索引
```

## 字元與數字的轉換

```python
x = int("42")       # int()：字串 → 整數 → 42
s = str(42)         # str()：整數 → 字串 → "42"
d = ord('a')        # ord()：字元 → 它在 Unicode 的編號 → 97
c = chr(98)         # chr()：編號 → 對應的字元 → 'b'
# 記憶：字元→數字用 ord；數字→字元用 chr（跟「字母計數」那節是同一個技巧）
```

> 數字的「字元」和「數值」要分清楚：`"5"` 是字元，`5` 是數值。要算術就轉 int，要比對就看題目要求。

## 範例逐行拆解

### 範例 1：秘密差（ZJ c290，2017/3 第 1 題）概念

> 題目大意：一個十進位整數，把「奇數位數字的和」與「偶數位數字的和」相減取絕對值。位數從 1 開始數（最左邊是奇數位）。
> 提示：題目用「從左往右數第 1、3、5... 位」。用索引 i（0 起算），i 為偶數時是「奇數位」。

```python
s = input()                        # 行1：整數很大，直接當「字串」讀進來
odd_sum = 0                        # 行2：奇數位數字總和（左數第 1、3、5... 位）
even_sum = 0                       # 行3：偶數位數字總和
for i, ch in enumerate(s):         # 行4：i = 位置（0 起算）、ch = 該位置的字元
    d = int(ch)                    # 行5：把字元 '3' 轉成數值 3 才能相加
    if i % 2 == 0:                 # 行6：i=0 是「第 1 位」（奇數位）→ 偶數索引是奇數位
        odd_sum += d               #      i=0、2、4... 都是奇數位
    else:                          # 行7：i 是奇數 → 對應「偶數位」
        even_sum += d
print(abs(odd_sum - even_sum))     # 行8：abs() 取絕對值，印出兩者差
```

| 行 | 語法 | 意義 |
| --- | --- | --- |
| 4 | `enumerate(s)` | 同時拿到位置與字元 |
| 5 | `int(ch)` | 把數字字元轉成數值 |
| 6 | `i % 2 == 0` | i=0,2,4 是奇數位 |
| 8 | `abs(x)` | 絕對值 |

> 重點：**位置奇偶** 用 `% 2` 判斷；題目 1 起算，Python 0 起算，換算後記得對齊。

### 範例 2：缺字問題（ZJ o078，2024/6 第 3 題）概念

> 題目大意：給一些字串，找出「沒有出現過」的字母，照字母順序輸出。
> 核心：用長度 26 計數器，把所有字串掃過一遍後，看哪些字母還是 0。

```python
n = int(input())                   # 讀有幾行字串
cnt = [0] * 26                     # 行1：長度 26 的計數器（cnt[0]=a 的次數……）
for _ in range(n):                 # 逐行讀入 n 行字串
    s = input()
    for ch in s:                   # 走訪這一行每個字元
        if 'a' <= ch <= 'z':       # 行2：過濾——只處理「小寫字母」（跳過其他字元）
            cnt[ord(ch) - ord('a')] += 1   # 對應編號的計數器加 1
for i in range(26):                # 行3：照字母順序（a→z）逐一檢查
    if cnt[i] == 0:                # 行4：計數是 0 → 這個字母從沒出現過
        print(chr(ord('a') + i))   # 行5：把編號 i 還原成字母印出來
```

| 行 | 意義 |
| --- | --- |
| 2 | 過濾：只算小寫字母（題目有含其他字元時） |
| 4 | `cnt[i] == 0` = 字母從沒出現 |
| 5 | 編號還原成字母 |

## 常見錯誤檢查表

| # | 錯誤 | 為什麼錯 | 修正 |
| --- | --- | --- | --- |
| 1 | `s[0] = 'x'` | 字串不可變 | 轉 `list(s)` 再改，`''.join` 接回 |
| 2 | 用 `==` 比「字串內容相同與否」 | 其實可以，但新手常拿來比位置 | 內容比對用 `s1 == s2` |
| 3 | 忘記 `int(ch)` 就做算術 | 字元和數值混用 | 先轉型 |
| 4 | 索引搞混 1 起算／0 起算 | 題目位數從 1 開始 | 用 `i % 2` 時先確認對應 |
| 5 | 只對小寫字元做 `ord('a')` 卻有大小寫 | 大寫會算出負索引 | 統一轉小寫 `s.lower()` 或分開處理 |
| 6 | `s.split()` 分不出「連續字元」 | 那是切「整段」 | 走訪字元用 `for ch in s:` |
| 7 | `chr(ord('a') + i)` 寫錯方向 | 想由編號找字母卻用 ord | 字母→編號用 `ord`，編號→字母用 `chr` |

```python
# 題1：統計大寫/小寫/數字各有幾個
s = input()                        # 讀字串
upper = lower = digit = 0          # 三個計數器一起歸零
for ch in s:                       # 走訪每個字元
    if 'A' <= ch <= 'Z':           # 用「字元範圍比較」判斷是否大寫字母
        upper += 1
    elif 'a' <= ch <= 'z':         # 小寫字母
        lower += 1
    elif '0' <= ch <= '9':         # 數字字元
        digit += 1
print(upper, lower, digit)         # 依序印出三個數量（空格隔開）
```

```python
# 題2：凱薩加密（每個小寫字母往後推 3 個，z 繞回 a）
s = input()
out = []                                 # 收集加密後的字元
for ch in s:
    if 'a' <= ch <= 'z':                 # 只加密小寫字母
        # (ord(ch)-ord('a')) 先轉成 0~25 編號，+3 往後推，% 26 讓 z(25) 繞回 a(0)
        n = (ord(ch) - ord('a') + 3) % 26
        out.append(chr(ord('a') + n))    # 編號還原成字母，加入結果
    else:                                # 非小寫字母（空格、標點等）原封不動
        out.append(ch)
print(''.join(out))                      # 把字元串列接回字串印出
```
