## DP 是什麼？一句話

> **動態規劃 = 把大問題拆成「有順序的小問題」，小問題的答案存起來重複用。**

關鍵字：**重複子問題**（同樣的小問題被問很多次）＋ **儲存**（算過就記下來）。

| 對比 | 遞迴（窮舉） | 動態規劃 |
| --- | --- | --- |
| 做法 | 每次都重算 | 算一次存起來 |
| 速度 | 指數級（很慢） | 多項式級（快） |
| 例子 | fib(n) 遞迴 | fib 用陣列存 |

```python
# 遞迴版：純遞迴算 fib(40) 會重複計算到爆炸
# 陣列版：把算過的答案「存起來重用」，O(N) 一秒算完
f = [0, 1]                     # 初始值：f[0] = 0、f[1] = 1
for i in range(2, 41):         # 從第 2 項開始一路往上算
    f.append(f[i - 1] + f[i - 2])   # 第 i 項 = 前兩項相加（直接用已算好的答案）
print(f[40])                   # 直接查陣列拿答案 → f[40]
# 這就是 DP 的核心精神：重複子問題 + 儲存重用
```

## 三步驟：狀態、轉移、初始

寫 DP 一律問自己三件事：

| 步驟 | 問題 | 例：爬樓梯 |
| --- | --- | --- |
| 1. 狀態 | `dp[i]` 代表什麼？ | `dp[i]` = 走到第 i 階有幾種方法 |
| 2. 轉移式 | 小問題怎麼拼成大問題？ | `dp[i] = dp[i-1] + dp[i-2]` |
| 3. 初始值 | 最小問題是多少？ | `dp[0]=1`、`dp[1]=1` |

> 三步寫完 → 再想「答案要哪一格、迴圈怎麼跑」，程式就出來了。

### 四步法（本資料夾教材的標準流程）

1. 讀題：誰是「輸入」，誰是「答案」
2. 定義狀態 `dp[...]`
3. 找轉移式
4. 設初始值

## 五個基礎模型速覽

| 模型 | 狀態 | 轉移式 | 題型特徵 |
| --- | --- | --- | --- |
| 爬樓梯 | `dp[i]` = 走到 i 的方法數 | `dp[i] = dp[i-1] + dp[i-2]` | 每次走 1～k 步 |
| 一維最大值 | `dp[i]` = 到 i 的最佳值 | `dp[i] = max(dp[i-1], dp[i-2]+...)` | 選或不選 |
| 零錢 | `dp[c]` = 湊 c 元的方法數/最少數 | `dp[c] += dp[c - coin]` | 硬幣組合 |
| 背包 | `dp[w]` = 容量 w 最大價值 | 0-1：由大到小；無限：由小到大 | 容量限制選物 |
| LIS / LCS | `dp[i]` 前 i 個的最長 | `dp[i] = max(dp[j]+1)` / 雙層 | 子序列 |

## 範例：爬樓梯逐行拆解

> 問題：每次走 1 或 2 階，走到第 n 階有幾種走法？

```python
n = int(input())
# 行1：dp[i] = 走到第 i 階有幾種方法；長度 n+1 是為了能放 dp[n]
dp = [0] * (n + 1)
# 行2：初始值——「站在地面」算 1 種（基準）
dp[0] = 1
# 行3：初始值——到第 1 階（走 1 階）算 1 種
dp[1] = 1
# 行4：從第 2 階開始，利用前面「已經算好」的答案往上推
for i in range(2, n + 1):
    # 行5：轉移式——到第 i 階 = 最後一步「走 1 階」從 i-1 來 ＋「走 2 階」從 i-2 來
    dp[i] = dp[i - 1] + dp[i - 2]
print(dp[n])                # 行6：答案就是走到第 n 階的方法數
# 三步驟拆解：狀態 = dp[i]；轉移 = dp[i]=dp[i-1]+dp[i-2]；初始 = dp[0]=dp[1]=1
```

| 行 | 意義 |
| --- | --- |
| 1 | 陣列長度 n+1（要能放 dp[n]） |
| 2 | 初始值：地面算 1 種走法 |
| 3 | 初始值：第 1 階 1 種 |
| 5 | **轉移式**：到 i 的方法 = 從 i-1 走 1 階 ＋ 從 i-2 走 2 階 |

### 用表追蹤（n = 5）

| i | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| dp[i] | 1 | 1 | 2 | 3 | 5 | 8 |

- dp[2] = dp[1]+dp[0] = 1+1 = 2（走法：1+1、2）
- dp[3] = dp[2]+dp[1] = 2+1 = 3
- dp[5] = dp[4]+dp[3] = 5+3 = **8**

> 看到「前一步的答案被後面一直重用」了嗎？這就是 DP 的核心。

## 常見錯誤檢查表

| # | 錯誤 | 為什麼錯 | 修正 |
| --- | --- | --- | --- |
| 1 | 陣列開太短（`[0]*n` 要 `dp[n]`） | 索引超界 | 開 `n+1` |
| 2 | 初始值設錯 | 第一格就錯，全盤皆錯 | 最小問題單獨驗證 |
| 3 | 轉移式方向錯 | 用還沒算的格子 | 迴圈順序要「先算依賴的」 |
| 4 | 0-1 背包迴圈方向錯 | 用「由大到小」卻寫成由小到大 | 0-1 由大到小、無限由小到大 |
| 5 | 忘了答案取哪一格 | 回傳錯位置 | 再讀題確認答案定義 |
| 6 | 遞迴式 DP 沒記憶化 | 超慢 | 用字典記算過的，或改迴圈 |
| 7 | 題目要「最少」卻用 max | 求錯極值 | 先決定是 max 還是 min |

<summary>解答（先自己寫再打開）</summary>

```python
# 題1：爬樓梯（走 1 或 2 階）
n = int(input())
dp = [0] * (n + 1)          # dp[i] = 到第 i 階的方法數
dp[0] = 1                   # 初始：地面 1 種
dp[1] = 1                   # 初始：第 1 階 1 種
for i in range(2, n + 1):   # 由小到大依序算
    dp[i] = dp[i - 1] + dp[i - 2]   # 轉移式：最後一步走 1 階或走 2 階
print(dp[n])                # 答案：走到第 n 階的方法數
```

```python
# 題2：不取相鄰元素的最大和（經典一維 DP）
n = int(input())
a = list(map(int, input().split()))
dp = [0] * n                    # dp[i] = 前 i+1 個元素中，符合規則的最大和
dp[0] = a[0]                    # 只有一個元素 → 就是它
if n >= 2:
    dp[1] = max(a[0], a[1])     # 兩個元素：不能相鄰取 → 只能二選一
for i in range(2, n):           # 從第 3 個開始推
    # 兩個選擇取較大：
    #  ① 不取 a[i] → 答案維持 dp[i-1]
    #  ② 取 a[i]   → 因為不能相鄰，只能接 dp[i-2]，再加 a[i]
    dp[i] = max(dp[i - 1], dp[i - 2] + a[i])
print(dp[n - 1])                # 答案 = 考慮完全部元素的最佳解
```
