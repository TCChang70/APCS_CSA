## 貪心是什麼？什麼時候能用？

貪心策略：**每一步選「當下看起來最好」的，不回頭改**。

什麼時候能用？題目要有「貪心選擇性質」——每次選最好的，最後就是全域最好。常見證據：

| 題型 | 為什麼貪心可行 |
| --- | --- |
| 區間排程（最多場次） | 結束越早，留下越多時間給後面 |
| 零錢（特定幣值） | 先用大幣值一定不虧 |
| 背包的「每單位價值」 | 照 CP 值排，先裝划算的 |

> 小心：不是每個題目都能貪心。例如「0-1 背包」用貪心是錯的，要用 DP（Day 9）。
> 判斷方法：試著想一個「貪心會出錯」的反例，想不出來才敢用。

## 套路一：區間排程（照結束時間排）

題目：「很多活動，每個有開始時間與結束時間，最多能安排幾個不衝突的活動？」

```python
acts = [(1, 3), (2, 4), (3, 5), (4, 6)]   # 每個活動 = (開始時間, 結束時間)
# 照「結束時間」由早到晚排（key 指定用第 1 欄 x[1] 當排序依據）
acts.sort(key=lambda x: x[1])

last_end = 0       # 上一次「選中」的活動結束時間（一開始是 0）
count = 0          # 已安排的活動數量
for s, e in acts:  # 依序看每個活動
    if s >= last_end:   # 這個活動的「開始時間」不早於上一個結束 → 不衝突、可接
        count += 1      # 安排它：數量 +1
        last_end = e    # 更新「目前最後的結束時間」
print(count)             # 印出最多能排幾個不衝突的活動
# 為什麼照結束時間排？結束越早，留下越多空檔給後面的活動
```

| 重點 | 說明 |
| --- | --- |
| 排序 key | 結束時間 `x[1]` |
| 選取規則 | 只要 `s >= last_end` 就選 |
| 為什麼對 | 結束越早，越不會擋到後面 |

> 記法：**區間排程 = 照結束時間排，結束早的先選。**

## 套路二：加權排序（照比值排）

題目：「n 個東西，每個有重量與價值，但只能選 k 個（或照某比例取），怎麼選最划算？」

```python
# 例：依「價值 ÷ 重量」的 CP 值由大到小選
items = [(3, 5), (1, 9), (2, 7)]   # 每個物品 = (重量, 價值)
# key=lambda x: x[1] / x[0]：排序依據 = 每單位重量的價值
#   x[1] 是價值、x[0] 是重量；例：(3,5) 的 CP 值 = 5/3
# reverse=True：CP 值高的排前面、先被選
items.sort(key=lambda x: x[1] / x[0], reverse=True)
```

| 重點 | 說明 |
| --- | --- |
| key | `x[1] / x[0]` = 單位重量價值 |
| reverse=True | 越高越先選 |

> 記法：**算比值、照比值排、由高到低取。**
> 注意：這只適用「可以分割的背包／取前 k 名」類；0-1 背包不能這樣解。

## 套路三：覆蓋問題（照起點排）

題目：「用最少數量蓋住目標」——例如電塔半徑 R 蓋住所有房子、基地台蓋點。

```python
# 例：座標線上的點，每個基地台半徑 R，用最少的基地台罩住所有點
pos = [1, 2, 5, 8, 10]   # 房子的座標
R = 2                    # 基地台服務半徑
pos.sort()               # 先照座標由小到大排
stations = 0             # 蓋了幾座基地台
i = 0                    # 目前指到「最左邊還沒被罩住」的房子
while i < len(pos):
    stations += 1        # 一定要為 pos[i] 蓋一座基地台
    cover = pos[i] + R   # 把基地台放在 pos[i]+R（能罩到最右邊），一次罩最多房子
    # 從 pos[i] 開始，把所有座標 ≤ cover 的房子都標記為「已被罩住」→ 跳過
    while i < len(pos) and pos[i] <= cover:
        i += 1
print(stations)          # 印出最少需要幾座基地台
```

| 重點 | 說明 |
| --- | --- |
| 排好後 | 從最左沒被罩的開始 |
| 放的位置 | 放在「起點＋R」最右邊，一次罩最多 |
| while 跳過 | 把被罩住的點全部跳過 |

> 記法：**覆蓋問題 = 照位置排，盡量往右放，把被罩住的跳過。**

## 如何用 lambda 自訂排序

| 想排的方式 | 寫法 |
| --- | --- |
| 照第二欄由小到大 | `data.sort(key=lambda x: x[1])` |
| 照第二欄由大到小 | `data.sort(key=lambda x: x[1], reverse=True)` |
| 照比值由大到小 | `data.sort(key=lambda x: x[1]/x[0], reverse=True)` |
| 照結束時間排（區間） | `acts.sort(key=lambda x: x[1])` |
| 先大後小、再第二欄 | `data.sort(key=lambda x: (-x[0], x[1]))` |

> `key` 只決定「用哪個值比大小」，不影響資料本身的長相。

## 範例逐行拆解

### 範例 1：線段覆蓋長度（ZJ b966，2016/3 第 3 題）概念

> 題目大意：數線上 n 條線段 [l, r]，被蓋住的長度總和是多少（重疊只算一次）。

```python
n = int(input())
segs = [list(map(int, input().split())) for _ in range(n)]   # 讀入 n 條線段 [l, r]
segs.sort()                          # 行1：照「起點 l」由小到大排，重疊的才會相鄰

total = 0                            # 累計「合併後」的覆蓋總長度
cur_l, cur_r = segs[0]               # 行2：先拿第一段當「目前合併段」
for l, r in segs[1:]:                # 從第二段開始逐段處理
    if l > cur_r:                    # 行3：這段的起點 > 目前段的終點 → 完全不重疊
        total += cur_r - cur_l       # 行4：把目前這一段「結算」進總長度
        cur_l, cur_r = l, r          #     開始新的合併段
    else:                            # 行5：有重疊 → 合併，右邊界延伸取較大者
        cur_r = max(cur_r, r)
total += cur_r - cur_l               # 行6：別忘了結算「最後一段」
print(total)
# 重點：重疊的線段先合併成一大段再算長度，避免同一段被重複計算
```

| 行 | 意義 |
| --- | --- |
| 1 | 照起點排序，合併才有效率 |
| 3 | 完全分開 → 結算前一段 |
| 5 | 有重疊 → 延伸右邊界 |
| 6 | 記得結算最後一段 |

#### 測試資料

輸入：
```
4
1 3
2 5
6 7
8 10
```
輸出：`7`

#### 表格追蹤

排序後：[(1,3), (2,5), (6,7), (8,10)]

| 步驟 | 線段 (l,r) | l > cur_r ? | 結果 | cur_l | cur_r | total |
| --- | --- | --- | --- | --- | --- | --- |
| 初始 | (1,3) | — | 取為初始 | 1 | 3 | 0 |
| 1 | (2,5) | 2>3? ✗ | 合併 | 1 | 5 | 0 |
| 2 | (6,7) | 6>5? ✓ | 結算+新段 | 6 | 7 | 4 |
| 3 | (8,10) | 8>7? ✓ | 結算+新段 | 8 | 10 | 5 |
| 結算 | — | — | 最後一段 | — | — | 5+(10-8)=7 |

答案 = 7（[1,5] 長度 4 + [6,7] 長度 1 + [8,10] 長度 2）

> 重點：把「重疊線段」合併成一大段再算長度，避免重複計算。這是「區間合併」題的標準做法。

### 範例 2：物品堆疊（ZJ c471，2017/10 第 4 題）

> 題目大意：n 個物品要堆疊，每個有重量與承重（上面能再放多少）。找最佳順序讓堆得最高（最多物品）。
> 關鍵思路：誰「該放下面」？——能承受「上面總重 + 自己」能力越強的放下面。
> 這類「兩個物品誰先誰後」的題目，用「交換比較」排序。

**排序規則**：承重（strength）由大到小排，承重強的放下面。

#### 完整程式

```python
n = int(input())                         # 讀入物品數量
items = []                               # 存放每個物品的 (重量, 承重)
for _ in range(n):
    w, s = map(int, input().split())     # 讀入一對 (重量, 承重)
    items.append((w, s))
# 排序規則：承重大的放下面（由大到小排）
# x[1] 是承重，承重越強越該放最底，才能扛住上面全部的重量
items.sort(key=lambda x: x[1], reverse=True)
total_w = 0                              # 目前「已堆物品」的總重量（上面的人要扛這些）
count = 0                                # 已堆了幾個物品
for w, s in items:                       # 依序嘗試每個物品
    if total_w <= s:                     # 關鍵判斷：目前總重 <= 這個物品的承重？
        count += 1                       #   是 → 可以堆，數量 +1
        total_w += w                     #   更新總重量（這個物品的重量加進去）
    # 若 total_w > s → 這個物品扛不住上面的重量，跳過不堆
print(count)                             # 印出最多能堆幾個
```

#### 測試資料

輸入：
```
3
2 5
1 3
3 4
```
輸出：`2`

#### 表格追蹤

排序後：[(2,5), (3,4), (1,3)]

| 步驟 | 物品 (w,s) | total_w <= s ? | 結果 | total_w | count |
| --- | --- | --- | --- | --- | --- |
| 1 | (2, 5) | 0 <= 5 ✓ | 堆 | 2 | 1 |
| 2 | (3, 4) | 2 <= 4 ✓ | 堆 | 5 | 2 |
| 3 | (1, 3) | 5 <= 3 ✗ | 跳過 | 5 | 2 |

答案 = 2（物品 (2,5) 在最底，物品 (3,4) 在上面；物品 (1,3) 扛不住所以不堆）

#### 為什麼照承重排序？

> 想像兩個人 A(承重10) 和 B(承重3)。A 在下面時可以扛更多，B 在下面很快就不夠扛。
> 所以承重強的先放下面，能留出更多空間給後面的物品。

## 常見錯誤檢查表

| # | 錯誤 | 為什麼錯 | 修正 |
| --- | --- | --- | --- |
| 1 | 以為所有最佳化都能貪心 | 0-1 背包等會錯 | 先想反例；不行就用 DP |
| 2 | 區間排程照「開始時間」排 | 開始早未必結束早 | 照**結束時間**排 |
| 3 | 比值用 `x[0]/x[1]` 算反 | 單位重量價值反了 | 是「價值/重量」 |
| 4 | 覆蓋問題「蓋」的位置沒往最右 | 罩住太少 → 數量太多 | 放在 `pos[i]+R` |
| 5 | 最後一段/最後一組忘了結算 | 少算一段 | 迴圈結束後補結算 |
| 6 | lambda 比錯欄位 | 排序規則錯 | 先印出排序結果確認 |
| 7 | 貪心規則「感覺對」就送 | 沒驗證反例 | 手算一個小反例 |

### 題 1：貪心闖關（ZJ q838，2025/6 第 3 題）★

**題目大意**：依某順序闖關，每次決策取「當下最優」，求最大收益。

**提示**：讀懂「當下最優」的規則 = 直接翻譯成貪心取法，通常排序後依序做即可。

#### 完整程式

```python
n = int(input())                         # 讀入關卡數量
items = []                               # 存放每關的資訊
for _ in range(n):
    items.append(tuple(map(int, input().split())))  # 讀入每關資料
# 關鍵：照題目指定的「當下最優」規則排序
# 例如：照收益由大到小（reverse=True），先處理收益高的關卡
items.sort(key=lambda x: x[1], reverse=True)
total = 0                                # 累計總收益
count = 0                                # 已通過的關卡數
for item in items:                       # 依序處理每關
    # 每關的通過條件與收益，依題目規則判斷
    total += item[1]                     # 累加收益
    count += 1                           # 通過關卡數 +1
print(total)                             # 印出最大總收益
```

> **注意**：本題需依照實際題目規則調整排序 key 與通過條件。上述為框架，實際比賽時先讀清楚「當下最優」的定義再下筆。

### 題 4：基地台（ZJ c575，2017/3 第 4 題）★★★

**提示**：半徑 R 用二分搜（Day 6），can(R) 內用貪心「最左放一座、罩住就往右跳」。貪心＋二分組合題。

#### 完整程式

```python
def can(R, pos):
    """判斷：半徑 R 時，最少需要幾座基地台才能罩住所有房子"""
    n = len(pos)                         # 房子數量
    stations = 0                         # 需要的基地台數量
    i = 0                                # 目前指到「最左邊還沒被罩住」的房子
    while i < n:                         # 還有房子沒被罩住
        stations += 1                    # 為 pos[i] 蓋一座基地台
        cover = pos[i] + R               # 基地台放在 pos[i]+R 處，最右能罩到 pos[i]+R
        # 把所有座標 <= cover 的房子都跳過（已被罩住）
        while i < n and pos[i] <= cover:
            i += 1                       # 這棟已被罩住，跳過看下一棟
    return stations                      # 回傳需要的基地台數

def solve():
    n, k = map(int, input().split())     # n = 房子數, k = 最多能蓋幾座
    pos = list(map(int, input().split()))# 讀入所有房子的座標
    pos.sort()                           # 先排序（貪心的前提）
    lo, hi = 0, pos[-1] - pos[0]         # 二分搜範圍：最小半徑 0，最大半徑 = 全距
    while lo < hi:                       # 二分搜：找最小的可行半徑 R
        mid = (lo + hi) // 2             # 取中間值
        if can(mid, pos) <= k:           # 用 mid 半徑時，需要的基地台數 <= k？
            hi = mid                     #   可行 → 嘗試更小的半徑
        else:
            lo = mid + 1                 #   不可行 → 半徑要更大
    print(lo)                            # 答案：最小可行半徑

solve()
```

#### 測試資料

輸入：
```
5 2
1 2 8 10 12
```
輸出：`4`

#### 表格追蹤（can(R) 追蹤）

以 R=3 為例，pos=[1,2,8,10,12]：

| 步驟 | 房子 i | pos[i] | cover = pos[i]+3 | 被罩住的房子 | stations |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | 1 | 4 | 1,2 (都<=4) | 1 |
| 2 | 2 | 8 | 11 | 8,10 (都<=11) | 2 |
| 3 | 4 | 12 | 15 | 12 (<=15) | 3 |

R=3 需要 3 座 > k=2，不可行 → R 要更大。

以 R=4 為例：

| 步驟 | 房子 i | pos[i] | cover = pos[i]+4 | 被罩住的房子 | stations |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | 1 | 5 | 1,2 (都<=5) | 1 |
| 2 | 2 | 8 | 12 | 8,10,12 (都<=12) | 2 |

R=4 需要 2 座 <= k=2，可行。二分搜收斂，最小可行半徑 = **4**。

#### 題 1：最多不衝突活動（區間排程套路）

```python
n = int(input())                         # 讀入活動數量
acts = [tuple(map(int, input().split())) for _ in range(n)]   # 讀入 n 個 (開始, 結束)
acts.sort(key=lambda x: x[1])           # 照「結束時間」由早到晚排
last_end = 0                            # 目前最後選中的活動結束時間
count = 0                               # 已選的活動數
for s, e in acts:                       # 依序檢查每個活動
    if s >= last_end:                   # 開始時間不早於上一個結束 → 可接
        count += 1                      # 數量 +1
        last_end = e                    # 更新結束時間
print(count)                            # 印出最多能排幾個
```
