## 條件判斷語法

### if / elif / else

```python
if 條件1:                # 條件1 為 True 才進來
    做事情 A             # 只執行 A，跳過後面所有分支
elif 條件2:              # 條件1 不成立，再看條件2
    做事情 B             # 條件2 為 True 才執行 B
else:                    # 前面所有條件都不成立
    做事情 C             # 一定要接在 if/elif 的最後面，且只能有一個
# 三個重點：
#  1. 條件後面「一定要有冒號 :」
#  2. 區塊內的程式要「縮排」（Tab 或 4 個空格），Python 靠縮排判斷範圍
#  3. 檢查順序「從上到下」：第一個成立的條件就執行，之後的都不再檢查
```

> 三個重點：
> 1. 條件後面**一定要冒號 `:`**。
> 2. 裡面的程式**要縮排**（Tab 或 4 個空格），Python 靠縮排分區塊。
> 3. 檢查順序是「從上到下」，第一個成立的就會執行，**else 會接上一個 if**。

### 比較與邏輯運算子

| 運算子 | 意義 | 例子 |
| --- | --- | --- |
| `==` | 相等（比較） | `x == 5` |
| `!=` | 不相等 | `x != 5` |
| `>` `<` `>=` `<=` | 大小比較 | `x >= 0` |
| `and` | 兩個都要成立 | `a > 0 and b > 0` |
| `or` | 至少一個成立 | `a > 0 or b > 0` |
| `not` | 反過來 | `not (x > 3)` |

> 新手最常犯：把「比較相等」寫成 `=`。`=` 是「指派」（把值存進去），`==` 才是「比較」。

## 迴圈語法

### for 迴圈（次數固定）

```python
for i in range(5):     # range(5)：i 依序 = 0,1,2,3,4（只給終點，起點預設 0）
    print(i)           # 印出 0 1 2 3 4（注意到 4 為止，不含 5）

for i in range(1, 6):  # range(起點, 終點)：i = 1,2,3,4,5
    print(i)           # 印出 1 2 3 4 5（含起點、不含終點）

for i in range(0, 10, 2):  # range(起點, 終點, 步長)：每步加 2
    print(i)               # 印出 0 2 4 6 8（一樣不含 10）
```

| 寫法 | 行為 |
| --- | --- |
| `range(n)` | 0 到 n-1 |
| `range(a, b)` | a 到 b-1 |
| `range(a, b, c)` | a 開始，每次加 c，不超過 b-1 |

### while 迴圈（條件為真就一直跑）

```python
x = 10
while x > 0:        # 條件成立（x>0）就重複執行，條件變假就結束
    print(x)        # 印出目前的 x：10 9 8 ... 1
    x = x - 1       # 每次把 x 減 1，讓 x 慢慢接近 0（否則條件永遠為真 → 無限迴圈！）
```

### 巢狀迴圈（迴圈裡有迴圈）

```python
for i in range(3):        # 外層迴圈：i = 0,1,2
    for j in range(3):    # 內層迴圈：每次外層迭代，內層都完整跑一遍 j = 0,1,2
        print(i, j)       # 依序印出 (0,0)(0,1)(0,2)(1,0)(1,1)(1,2)(2,0)(2,1)(2,2)
# 可以想成「先水平跑（j 內層），再垂直換列（i 外層）」，
# 這正是走訪二維矩陣的基本骨架。
```

內層會完整跑一遍，外層才會進下一次。可以想成「先水平跑，再垂直換列」。

## % 和 // ：餘數與整除

| 運算子 | 名稱 | 例子 | 結果 |
| --- | --- | --- | --- |
| `%` | 取餘數 | `17 % 5` | 2 |
| `//` | 整數除法（無條件捨去） | `17 // 5` | 3 |
| `**` | 次方 | `2 ** 3` | 8 |

常見用法：

```python
x % 2 == 0    # 除以 2 餘 0 → x 是「偶數」
x % 2 == 1    # 除以 2 餘 1 → x 是「奇數」
n % 10        # 除以 10 的餘數 → 得到 n 的「個位數」（例：123 % 10 = 3）
n // 10       # 除以 10 整除 → 等於「去掉個位數」（例：123 // 10 = 12）
x % 7         # 除以 7 的餘數 → 得到「星期幾」的循環位置（0～6）
              # 例：x=0 是星期日，x=7 也是星期日（因為 7 % 7 = 0）
```

> 「每到一個週期就重來」的題目（時鐘、日曆、紅綠燈、圓桌），十之八九會用到 `%`。

## 第 1 題的常見長相與邊界陷阱

APCS 第 1 題常出現的形式：

1. **多條件分數判斷**（像成績等級）→ if/elif/else
2. **照表格做決定**（哪個條件選哪個）→ if
3. **簡單模擬**（跟著步驟走，n 很小）→ for + if
4. **找規律/算術**（用 %、// 直接算）→ 公式

### 邊界條件陷阱（最常出錯的地方）

| 陷阱 | 例子 | 對策 |
| --- | --- | --- |
| 0 或負數 | 分數 = 0 時該歸哪一級？ | 先把 0、最大、負數各測一筆 |
| 「相等時」選誰 | `>= 60 及格` 那正好 60？ | 看清楚題目寫 `>=` 還是 `>` |
| 多個條件誰先檢查 | 同時符合 A 和 B 要哪個？ | 照題目規定的順序寫 elif |
| 最後一筆資料 | 迴圈 i = n-1 時會怎樣 | 用題目邊界測一次 |

> 通則：寫完後自己用「題目給的範例 ＋ 一筆最小測資 ＋ 一筆最大測資」跑一遍再交。

## 範例逐行拆解

### 範例 1：成績指標（ZJ b964，2016/3 第 1 題）

> 輸入：第一列 n；第二列 n 個成績。輸出：先印由小到大的成績（空格隔開），再依「全部及格→best case／全部不及格→worst case／否則印出最高不及格分數與最低及格分數」輸出。

```python
# 行1：讀 n（共有幾個成績）
n = int(input())
# 行2：把第二列成績讀成整數串列，例："61 58 90 45 60" → [61,58,90,45,60]
scores = list(map(int, input().split()))
# 行3：原地由小到大排序 → [45,58,60,61,90]
scores.sort()
# 行4：print(*scores) 的「*」把串列展開成多個參數，印成「空格隔開」的一列
print(*scores)                                # → 45 58 60 61 90

# 行5：串列推導式——把 scores 中「< 60」的挑出來，組成新串列 fail
fail = [s for s in scores if s < 60]          # → [45, 58]
# 行6：把「>= 60」的挑出來，組成新串列 pass_
pass_ = [s for s in scores if s >= 60]        # → [60, 61, 90]

# 行7：fail 是空串列 [] 時，not [] 為 True →「全部及格」
if not fail:
    print("best case")
elif not pass_:                               # 行8：pass_ 為空 →「全部不及格」
    print("worst case")
else:                                         # 行9：兩邊都有
    print(fail[-1])                           # 行10：fail 已排序，最後一個 = 最高不及格分數
    print(pass_[0])                           # 行11：pass_ 已排序，第一個 = 最低及格分數
```

| 行 | 語法 | 意義 |
| --- | --- | --- |
| 3 | `scores.sort()` | 原地由小到大排序 |
| 4 | `print(*scores)` | `*` 把串列展開，印成「空格隔開」 |
| 5 | `[s for s in scores if s < 60]` | 串列推導式：把不及格的挑出來 |
| 7 | `if not fail:` | fail 是空串列（`[]`）時，`not []` 為 True |
| 10 | `fail[-1]` | 串列最後一個（索引 -1） |

> 重點：先排序，後面答案自然浮現。「最高不及格」= fail 最後一個；「最低及格」= pass 第一個。

### 範例 2：等紅綠燈（ZJ q181，2025/1 第 1 題）概念拆解

> 題目大意：紅綠燈以「週期」循環，輸入某個時間點與週期參數，判斷該時刻燈號狀態。核心就是用 `%` 算出「這個時刻落在一週期裡的哪一階段」，再用 if 判斷階段對應哪個燈號。

```python
t, cycle = map(int, input().split())   # 行1：t = 目前時間點、cycle = 一個週期的長度
pos = t % cycle                        # 行2：把時間「摺」進週期裡
                                       # 不管時間過了幾個週期，只看「落在週期內哪一格」
if pos < 10:                           # 行3：例：週期前 10 單位是紅燈
    print("red")
elif pos < 20:                         # 行4：接下來 10 單位是黃燈
    print("yellow")
else:                                  # 行5：剩下的都是綠燈
    print("green")
# 記住套路：週期問題 → % 求出「階段位置」→ if 判斷該階段對應的燈號/狀態
```

| 行 | 意義 |
| --- | --- |
| 2 | 把時間「摺」進週期裡，只看剩下的位置 |
| 3～5 | 判斷這個位置落在哪段燈號 |

> 記住套路：**週期問題 → `%` 求出階段位置 → if 判燈號/狀態**。

## 常見錯誤檢查表

| # | 錯誤 | 為什麼錯 | 修正 |
| --- | --- | --- | --- |
| 1 | `if x = 5:` | `=` 是指派不是比較 | 用 `if x == 5:` |
| 2 | if 後面忘了冒號 | 語法錯誤 | 條件後加 `:` |
| 3 | 縮排不一致 | 區塊判斷錯亂 | 統一用 4 個空格 |
| 4 | elif 寫成 else if | Python 沒有 else if | 直接寫 `elif` |
| 5 | while 沒改條件變數 | 無限迴圈 → TLE | 迴圈內更新變數 |
| 6 | 用 `and`/`or` 卻寫 `&&`/`||` | 那是 C 語言的寫法 | Python 用 `and`/`or` |
| 7 | 分數 60 的邊界判錯 | `>` 和 `>=` 搞混 | 對照題目原文 |
| 8 | 忘了 `%` 可能算出 0 | 第一個階段被漏掉 | 先用 `pos == 0` 測一筆 |

```python
# 題1：成績等級
x = int(input())                 # 讀一個 0～100 的分數
if x >= 90:                      # 90 分以上 → A
    print("A")
elif x >= 80:                    # 不到 90 但 80 以上 → B
    print("B")
elif x >= 70:                    # 不到 80 但 70 以上 → C

    print("E")
```

```python

```
