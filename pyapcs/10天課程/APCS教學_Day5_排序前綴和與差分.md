## 排序語法全整理

```python
a = [3, 1, 2]
a.sort()              # sort()「原地」由小到大排序，直接修改 a → a = [1, 2, 3]
b = sorted(a)         # sorted() 回傳「排序好的新串列」，原本的 a 不變
a.sort(reverse=True)  # reverse=True 改為由大到小 → [3, 2, 1]
a.sort()              # 字串串列也行：照「字典順序」（英文字母順序）排
```

| 需求 | 寫法 |
| --- | --- |
| 由小到大 | `a.sort()` |
| 由大到小 | `a.sort(reverse=True)` |
| 保留原串列 | `sorted(a)` |
| 照「第二欄」排 | `a.sort(key=lambda x: x[1])` |
| 照「倒數」排 | `a.sort(key=lambda x: x[-1], reverse=True)` |
| 同時多把鑰匙 | `a.sort(key=lambda x: (x[1], x[0]))` |

> `key=lambda x: ...` 的意思：排序時不看整筆資料，只看這個函式算出來的值。
> `(x[1], x[0])` 表示「先比第二欄，相同再比第一欄」。

```python
# 例：每筆資料是 (分數, 名字)，照「分數」由高到低排
records = [(85, "Amy"), (92, "Bob"), (85, "Cindy")]
# key=lambda r: r[0]：排序時只看「每筆資料的第 0 欄」（分數）
# reverse=True：分數高的排前面
records.sort(key=lambda r: r[0], reverse=True)
# 結果：[(92,"Bob"), (85,"Amy"), (85,"Cindy")]
```

### 排序後「相鄰差距最小」常用

```python
a.sort()   # 先排序：相鄰的兩數差距一定最小，排序後「最近的兩數」必相鄰
# 產生器：對每個 i，算 a[i+1]-a[i]（相鄰差距），min() 取最小的一個
# range(len(a)-1)：只跑到倒數第二個，避免 a[i+1] 超界
best = min(a[i + 1] - a[i] for i in range(len(a) - 1))
```

## 前綴和：區間和查詢

情境：陣列 a，被問很多次「a[l] 到 a[r] 的和」。每次都加一遍很慢，先把「前 i 個的和」算好。

```python
n = int(input())
# [0] + 串列：在最前面補一個 0，讓 a[1] 對應第一個輸入的數字（1 起算較好寫公式）
a = [0] + list(map(int, input().split()))
# p[i] = a[1] + a[2] + ... + a[i]（前 i 個數的總和）
p = [0] * (n + 1)                            # 長度 n+1（要能放 p[n]）
for i in range(1, n + 1):                    # 從 1 開始往前推
    p[i] = p[i - 1] + a[i]                   # 遞推式：前 i 個的和 = 前 i-1 個的和 + 第 i 個
# 例：a=[0,1,2,3] → p=[0,1,3,6]
#    p[1]=a[1]=1、p[2]=1+2=3、p[3]=1+2+3=6
```

| 位置 | p 值 |
| --- | --- |
| p[0] | 0 |
| p[1] | a[1] |
| p[2] | a[1]+a[2] |
| p[3] | a[1]+a[2]+a[3] |
| … | … |

### 查詢區間和

```python
def range_sum(l, r):      # 回傳 a[l] 到 a[r] 的總和（l、r 都是 1 起算）
    return p[r] - p[l - 1]
    # 口訣：p[r] - p[l-1]
    # p[r] = 前 r 個的和；扣掉 p[l-1] = 前 l-1 個的和 → 剩下的正好是 a[l]~a[r]
    # 例：a=[0,1,2,3,4]，問 a[2]+a[3] → p[3]-p[1] = 6-1 = 5（2+3=5 ✓）
```

> 口訣：**p[r] - p[l-1]**。畫個數線：p[r] 是「前 r 個」，扣掉 p[l-1] 的「前 l-1 個」，剩下就是 a[l]~a[r]。

```
a:        [a1][a2][a3][a4][a5]
p:     p0  p1  p2  p3  p4  p5
       └─ p[l-1] 區段 ─┘        ← 要扣掉的
       └──── p[r] 區段 ────┘    ← 全都要
       差 = a[l]~a[r]
```

### 應用：找「總和恰好 = 0 的連續區間個數」

```python
# 用 dict 記「每個 p 值出現過幾次」
# 原理：若 p[i] == p[j]，代表 a[i+1]~a[j] 這段的和 = p[j]-p[i] = 0
cnt = {0: 1}         # 先放 {0:1}：p 值 0 已出現過一次（對應「虛擬的 p[0]」）
ans = 0              # 統計「總和為 0 的連續區間」有幾個
for i in range(1, n + 1):      # 逐一處理每個前綴和
    if p[i] in cnt:            # 這個 p 值以前出現過 → 中間那段和為 0
        ans += cnt[p[i]]       # 出現幾次，就代表能配出幾個總和 0 的區間
    cnt[p[i]] = cnt.get(p[i], 0) + 1   # 把這次的 p 值計數加 1（沒出現過就從 0 開始）
```

## 二維前綴和

矩陣版：`p[i][j]` = 「第 0~i 列、第 0~j 行」這個左上角矩形總和。

```python
n, m = map(int, input().split())
g = [list(map(int, input().split())) for _ in range(n)]   # 讀入 n×m 矩陣
# p 開 (n+1)×(m+1)：多一圈 0，方便公式不用另外處理邊界
p = [[0] * (m + 1) for _ in range(n + 1)]
for i in range(n):                    # 走每一列
    for j in range(m):                # 走每一行
        # p[i+1][j+1] = 左上角矩形總和（第 0~i 列、第 0~j 行）
        # = 這格自己 g[i][j]
        #   + 上面的矩形 p[i][j+1]
        #   + 左邊的矩形 p[i+1][j]
        #   - 左上角被上面和左邊「重複加了一次」的 p[i][j]
        p[i + 1][j + 1] = g[i][j] + p[i][j + 1] + p[i + 1][j] - p[i][j]
```

| p[i+1][j+1] | 等於 |
| --- | --- |
| `g[i][j]` | 這格自己 |
| `+ p[i][j+1]` | 上面的矩形 |
| `+ p[i+1][j]` | 左邊的矩形 |
| `- p[i][j]` | 左上角被加了兩次，扣掉 |

矩形查詢 (r1,c1)~(r2,c2)（0 起算）：

```python
# 二維區間查詢：求「第 r1~r2 列、第 c1~c2 行」的矩形總和（座標 0 起算）
# 用「大的矩形」剪掉「上面多餘的」與「左邊多餘的」，再加回「被剪兩次的左上角」
s = p[r2+1][c2+1] - p[r1][c2+1] - p[r2+1][c1] + p[r1][c1]
# 對照一維的「p[r] - p[l-1]」：二維就是把「右下的前綴和」三剪一加
```

## 差分：多次區間加值

情境：對陣列的某個區間「同時加上一個值」，做很多次，最後才問每個位置是多少。

暴力：每次把區間每個位置都加 → O(區間長度 × 次數)，太慢。
差分：只改「起點＋值、終點後一格－值」，最後前綴和還原。

```python
n, q = map(int, input().split())    # n 個位置、q 次區間加值
diff = [0] * (n + 2)                # 差分陣列多開 2 格：diff[r+1] 最多到 n+1，不會超界
for _ in range(q):
    l, r, v = map(int, input().split())   # 這筆操作：把 [l, r]（1 起算）每個位置都加 v
    diff[l] += v                    # 頭：從 l 開始，累積量多 v
    diff[r + 1] -= v                # 尾：到 r+1 時扣回 v，之後恢復原狀
    # 整個區間加值只需「改兩個位置」，這就是差分省時間的關鍵

# 還原成每個位置最後的值（做一次前綴和）
cur = 0                             # 目前的累積量
for i in range(1, n + 1):
    cur += diff[i]                  # 一路累加，把區間效果「展開」回每個位置
    print(cur, end=' ')             # 印出第 i 個位置最後的值（不換行，空格隔開）
```

| 動作 | 意義 |
| --- | --- |
| `diff[l] += v` | 從 l 開始多 v |
| `diff[r+1] -= v` | 到 r+1 就恢復（扣回來） |
| `cur += diff[i]` | 一路累加還原 |

> 口訣：**頭加尾減，最後前綴和還原。**

## 何時該用哪招：決策表

| 題目症狀 | 用哪招 |
| --- | --- |
| 多次問「區間和」 | 前綴和 |
| 多次做「區間加值」最後才查 | 差分 |
| 要「最大/最小」「第 k 大」 | 排序 |
| 找「和 = 0 的區間」「最近相同元素」 | 排序 或 前綴和＋dict |
| 區間查詢＋會修改值 | 前綴和不行，用更進階結構（少見） |

## 範例逐行拆解

### 範例 1：幸運數字（ZJ g277，2021/9 第 3 題）概念

> 題目大意：陣列中每個位置，定義「某範圍內的最大值」……多次查詢。
> 這類題多用前綴和（或預處理最大值表）一次算好、查詢 O(1)。

### 範例 2：圓環出口（ZJ f581，2020/7 第 3 題）概念

> 題目大意：圓環上有一圈數字，每次從某起點出發走 k 步，問走到哪。
> 提示：圓環→把陣列重複兩次（或對總和取 `%`）；走幾步的累積用前綴和＋二分找「累積和 ≥ 目標」的第一個位置。

### 範例 3：前綴和標準範例（完整可跑）

> 輸入：第一列 n、q；第二列 n 個整數（1 起算）；接下來 q 列每列 (l, r)。輸出每個區間和。

```python
n, q = map(int, input().split())
# 行1：補一個 0 在最前面，讓 a[1] 對應第一個輸入的數（1 起算）
a = [0] + list(map(int, input().split()))
# 行2：前綴和陣列，長度 n+1（要能存 p[n]）
p = [0] * (n + 1)
# 行3：從第 1 個數開始往前推
for i in range(1, n + 1):
    p[i] = p[i - 1] + a[i]                     # 行4：遞推式：前 i 個 = 前 i-1 個 + 第 i 個
for _ in range(q):                             # 行5：處理每一筆查詢
    l, r = map(int, input().split())           #     讀區間起點 l、終點 r
    print(p[r] - p[l - 1])                     # 行6：O(1) 回答區間和，不用重算
```

| 行 | 意義 |
| --- | --- |
| 1 | `[0] + ...` 讓 a[1] 對應第一個數，索引好算 |
| 4 | 前綴和遞推式 |
| 6 | 區間和公式 `p[r] - p[l-1]` |

## 常見錯誤檢查表

| # | 錯誤 | 為什麼錯 | 修正 |
| --- | --- | --- | --- |
| 1 | 前綴和陣列長度開錯 | p[n] 超界 | 開 `n+1` |
| 2 | 區間和寫成 `p[r] - p[l]` | 會漏掉 a[l] | 用 `p[r] - p[l-1]` |
| 3 | 差分沒開 `n+2` | `diff[r+1]` 超界 | 開 `n+2` |
| 4 | 差分後忘了「前綴和還原」 | 印出的是 diff 不是答案 | `cur += diff[i]` |
| 5 | `sort()` 忘了 `reverse=True` 就由大到小 | 排序方向反了 | 依題意檢查 |
| 6 | key 用 lambda 但比錯欄位 | 自訂排序規則錯 | 先印一筆驗證 |
| 7 | 每次查詢都重新加一遍 | 太慢 TLE | 前綴和先算好 |
