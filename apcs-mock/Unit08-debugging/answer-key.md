## FRQ 解答

**錯誤 1：** `product = 0` 應為 `product = 1`（累乘初始化錯誤）
**錯誤 2：** `i < n` 應為 `i <= n`（Off-by-one，漏乘了 n）

```java
public static int factorial(int n) {
    int product = 1;      // 修正 1：從 1 開始
    for (int i = 1; i <= n; i++) {  // 修正 2：<= n
        product *= i;
    }
    return product;
}
```

**要點：** 累乘初始化為 1，條件用 `<=` 確保包含 n。
