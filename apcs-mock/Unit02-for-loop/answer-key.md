## FRQ 解答

```java
public static int alternatingSquareSum(int n) {
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        if (i % 2 == 1) {
            sum += i * i;      // 奇數項：正號
        } else {
            sum -= i * i;      // 偶數項：負號
        }
    }
    return sum;
}
```

**要點：** 奇數索引 (1,3,5...) 用加法，偶數索引 (2,4,6...) 用減法。
