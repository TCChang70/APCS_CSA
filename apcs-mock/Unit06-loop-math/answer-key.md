## FRQ 解答

```java
public static void primeFactors(int n) {
    int d = 2;
    while (n > 1) {
        if (n % d == 0) {
            System.out.print(d + " ");
            n /= d;
        } else {
            d++;
        }
    }
}
```

**要點：** 從 2 開始試除，若能整除則印出並除到不能再除，否則遞增除數。
