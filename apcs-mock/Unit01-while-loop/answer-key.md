## 選擇題解答

| 題號 | 答案 | 解析 |
|------|------|------|
| 1 | **B** | i=5→count=1, i=3→count=2, i=1→count=3, i=-1 停止。共 3 次。 |
| 2 | **C** | C 的 x 從 0 遞增到 9 後條件 `x<10` 變 false 而終止。其餘皆無限迴圈。 |
| 3 | **A** | 哨兵值必須是正常資料中不會出現的值（如輸入正數時用 -1 做哨兵）。 |
| 4 | **B** | 逐位取出相加：5+4+3+2+1 = **15**。`n%10` 取個位數，`n/=10` 去掉個位數。 |
| 5 | **A** | i 從 10 遞減到 1，印出能被 3 整除的：9, 6, 3。 |

## FRQ 解答

```java
public static int digitSum(int n) {
    int sum = 0;
    while (n > 0) {
        sum += n % 10;   // 取出個位數加入總和
        n /= 10;         // 去掉個位數
    }
    return sum;
}
```

**要點：** `n % 10` 取出最後一位數，`n / 10` 去掉最後一位數，重複直到 n=0。
