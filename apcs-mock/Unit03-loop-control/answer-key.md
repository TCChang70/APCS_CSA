## FRQ 解答

```java
public static int sumOddInRange(int start, int end) {
    int sum = 0;
    for (int i = start; i <= end; i++) {
        if (i % 2 == 1) {
            sum += i;
        }
    }
    return sum;
}
```

**要點：** 使用 `<=` 確保含 end 值。`i % 2 == 1` 判斷奇數。
