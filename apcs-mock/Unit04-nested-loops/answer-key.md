## FRQ 解答

```java
public static void printMultiplicationTable(int n) {
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            System.out.print((i * j) + " ");
        }
        System.out.println();
    }
}
```

**要點：** 外層 i 代表被乘數，內層 j 代表乘數，`i*j` 為乘積。
