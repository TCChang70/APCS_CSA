# Unit 02：`for` 迴圈基礎

## 學習目標
- 理解 `for` 迴圈的三段結構
- 能與 `while` 迴圈互相轉換
- 掌握迴圈計數的各種方向

---

## 概念說明

`for` 迴圈將**初始化、條件、更新**整合在一行，適合已知次數的迴圈。

```java
for (初始化; 條件; 更新) {
    // 迴圈主體
}
```

### 三段執行時機
- **初始化** (`int i = 0`)：執行一次，設定起始值
- **條件** (`i < 10`)：每次迴圈前檢查
- **更新** (`i++`)：每次迴圈結束後執行

---

## 程式碼範例

### 範例 1：基本遞增計數
```java
for (int i = 1; i <= 5; i++) {
    System.out.print(i + " ");
}
// 輸出：1 2 3 4 5
```

### 範例 2：遞減計數
```java
for (int i = 5; i >= 1; i--) {
    System.out.print(i + " ");
}
// 輸出：5 4 3 2 1
```

### 範例 3：步進 2（印偶數）
```java
for (int i = 0; i <= 10; i += 2) {
    System.out.print(i + " ");
}
// 輸出：0 2 4 6 8 10
```

### 範例 4：乘法表
```java
for (int i = 1; i <= 9; i++) {
    System.out.println("7 x " + i + " = " + (7 * i));
}
```

---

## `for` vs `while` 對照

| 項目 | `for` 迴圈 | `while` 迴圈 |
|------|-----------|-------------|
| 語法 | `for (init; cond; update)` | `while (cond)` |
| 適用 | 已知次數 | 條件驅動 |
| 控制變數 | 集中在第一行 | 分散各處 |

### 等價轉換
```java
// for 寫法
for (int i = 0; i < 5; i++) { System.out.println(i); }

// while 寫法
int i = 0;
while (i < 5) { System.out.println(i); i++; }
```

---

## 常見錯誤

| 錯誤 | 範例 | 正確 |
|------|------|------|
| 分隔符號錯誤 | `for (int i=0, i<5, i++)` | 用分號 `;` |
| 作用域問題 | 在迴圈外使用 `i` | `i` 只在 for 區塊內有效 |
| 無窮迴圈 | `for (int i=0; i<5; i--)` | 更新方向與條件一致 |
